# 2026-10-04 검사 점수·실행 제어·일반 도형 검출

사용자 요청: 커스텀 형상 두 방식의 추가 윤곽 무감점 문제 수정, 속도 조절 및 실제 GPU 모드, 삼각형·십자가·원·사각형 검출. OpenCV NCC 점수식은 유지한다.

1. 학습 윤곽만 확인하는 방향 점수와 학습 마스크 안의 설명 불가 윤곽을 분리한다. 최종 점수에는 사용자 조절 감점 비중을 적용하며 원래 방향 점수와 추가 윤곽비율을 함께 표시한다. 축소 후보에서는 감점하지 않고 최종 원본 pose에서 계산한다. 마스크 밖 배경은 감점하지 않는다.
2. 방식별 빠르게/균형/정밀/사용자 설정을 제공한다. 프리셋은 후보·검증·정밀화 예산만 변경한다. 합격 점수·출력 개수·학습 모델은 보존한다. CPU 병렬도와 검사 시간 상한은 별도 제어한다. 시간 초과는 불완전 검사 경고이고 OK/NG가 아니다.
3. CPU와 GPU 전처리 모드를 명시적으로 구분한다. 독립 DX12 compute 장치에서 Gaussian 평활화를 실행하고 방향·윤곽 검증은 기존 CPU 계약을 유지한다. GPU 미지원/실패를 CPU 성공으로 위장하지 않는다. 장치명과 실제 처리량을 기록하고 전송을 포함한 실측으로 비교한다. VisionAlgorithm에는 DX12 참조를 넣지 않는다.
4. 학습 없는 일반 도형 검출은 별도 서비스·ViewModel·패널로 구성한다. 이진화 및 윤곽 기반으로 네 도형을 분류하고 크기·극성·윤곽 오차·점수 조건을 제공한다. 원본의 제한된 창으로 검색하며 잘림·출력 제한을 경고한다. 결과는 공급자 비의존 닫힌 윤곽 overlay로 게시한다.
5. 패턴/일반 도형 검사는 동시에 실행하지 않는다. 이미지 세대·설정 변경·취소·늦은 결과·원본 reader 소유권·기존 편집 이력을 유지한다.

검증 순서: 점수 재현 RED/GREEN → CPU 설정 및 모드 독립성 → 일반 도형 양성/음성/회전/크기/ROI/잘림 → GPU CPU 동등성 및 실제 장치 실행 → 전체 회귀·포맷·배포 앱 화면 확인. 합성 검증을 현장 검출률 또는 실시간 FPS 달성으로 표현하지 않는다. 원칙 예외는 적용하지 않는다.
