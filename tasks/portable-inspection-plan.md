# 플랫폼 독립 검사와 검출 예산 개선

2026-10-04 사용자 승인: 검사에서 DX12를 제거하고 Windows·Linux 공통 엔진과 선택형 ILGPU 가속을 구성한다. 화면 렌더링은 기존 WPF·DX12를 유지한다. 검출 손실이 큰 `빠르게 · 후보 축소`는 재현 후 개선하거나 삭제한다.

1. **공통 실행 경계:** 기존 원본 영상 I/O를 `VisionImaging`, 검사 서비스·타일 검색을 `VisionInspection`의 `net10.0` 라이브러리로 이동한다. 기존 namespace와 원본·ROI·취소·예산 계약을 보존한다. VisionAlgorithm은 Core/Canvas/WPF를 참조하지 않는다. 실제 재사용 대상만 옮기고 범용 플러그인 체계를 만들지 않는다.
2. **후보 예산:** 기존 빠른 정책의 후보/검증 예산 축소와 정밀화 생략 영향을 어려운 재현 입력으로 비교한다. 최소 점수 완화로 검출력을 위장하지 않는다. 정확성을 해치는 프리셋은 제거하고 기존 고급 예산 설정과 정상 기본값은 유지한다.
3. **GPU 교체:** 검사용 DX12 구현을 제거한다. 중립 전처리 계약과 별도 ILGPU 모듈에서 CUDA 평활화·gradient 연속 구간을 실행한다. 중간 결과의 CPU 왕복을 줄이며 실제 처리 단계·장치·전송 포함 시간을 보고한다. 전체 GPU 매칭이나 속도 향상을 사전에 주장하지 않는다.
4. **헤드리스 검사:** 같은 서비스를 호출하는 `VisionInspection.Cli`에서 JSON 레시피로 파일 학습/검사 또는 일반 도형 검출을 수행한다. OS별 native 패키지는 실행 호스트가 선택한다. Windows/Linux 공통 테스트와 재현 명령을 제공한다.
5. **검증:** 후보 손실 재현, CPU/GPU 수치·최종 검출 동등성, 원본 타일/도형/시간 초과 회귀, 참조 그래프, 전체 테스트/포맷, 별도 배포 앱 실제 검사를 확인한다. Linux 실실행과 cross-publish는 별도 상태로 기록한다.

환경 확인: 현재 Windows 호스트에 실행 가능한 WSL 배포판과 Docker/Podman이 없다. Linux 바이너리·검증 절차는 준비하되 실제 Linux 실행 결과를 만들거나 Windows 검사로 대체하지 않는다. OS 구성 변경이 필요한 설치는 준비된 결과와 함께 별도 확인한다. 설계 원칙 예외는 적용하지 않는다.
