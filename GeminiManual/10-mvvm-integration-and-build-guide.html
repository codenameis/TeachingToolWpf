      파인만 학습법 (Feynman Analogy)

      🛗 비유 1 · 엘리베이터 문 닫힘 타이머 = 비동기 디바운싱(Debouncing)

      엘리베이터가 사람 1명 탈 때마다 즉시 출발했다가 다시 돌아오면 건물이 마비되겠죠? 대신 사람이 계속 타는 동안(사용자가 필터 슬라이더를 드래그하는 동안)에는 출발 타이머를 계속 취소·연기(CancellationTokenSource.Cancel)했다가, 마지막 입력 후 12ms 동안 조용해졌을 때 딱 한 번만 필터 계산을 출발시키는 것이 바로 디바운싱입니다!

      🔒 비유 2 · 박물관 유리 진열장 관람 모드 = 검사 화면 입력 잠금(NavigationOnly)

      공장에서 자동 검사가 돌아가는 도중에 작업자가 실수로 마우스를 건드려 ROI 상자가 옆으로 밀리면 큰 사고가 납니다.
      그렇다고 화면 전체를 아예 먹통(IsEnabled = false)으로 만들면 불량 부위를 확대해서 볼 수조차 없습니다! 그래서 도형 이동·삭제 같은 편집은 잠그되, 화면 확대/축소(Zoom)와 화면 밀기(Pan) 관람만 허용하는 모드가 바로 NavigationOnly입니다.

      Step 2 · 필수 사전지식 먼저 다지기

      규칙 1 · 역할 분담 ViewModel에는 마우스 픽셀 계산을 넣지 않는다!

      MainWindowViewModel은 EditorSession과 InteractionController를 생성해 들고 있으면서 툴바 명령(사각형 그리기, 1억 ROI 추가, Undo/Redo)과 키보드 단축키(HandleKey)만 조율하고, 초당 120번 들어오는 마우스 드래그와 렌더링은 InteractionController와 Dx12Viewport가 직접 처리합니다.

      규칙 2 · 입력 잠금 2단계 IsEnabled(전체 차단) vs NavigationOnly(편집만 잠금)

      캔버스가 잠기는 순간에는 기존에 진행 중이던 드래그 프리뷰(ActivePreview)와 마우스 캡처를 즉시 취소해 반쯤 옮겨진 유령 도형이 남지 않게 정리합니다.

      • IsEnabled = false: 마우스·키보드·휠 모든 입력 차단
      • NavigationOnly = true: ROI 편집(그리기/이동/리사이즈/삭제)은 차단하고 마우스 휠 줌 & 우클릭 패닝만 허용!

      규칙 3 · 외부 목록 연동 선택·Undo 이력을 안 바꾸는 FocusRoi와 FitImage

      오른쪽 사이드바의 ROI 목록에서 항목을 클릭해 화면을 그 도형 위치로 맞출 때(FocusRoi / FocusBounds / FitImage), 카메라 뷰포트(Zoom, PanX, PanY)만 부드럽게 이동시키며 기존 문서의 Undo/Redo 이력은 절대 오염시키지 않습니다!

      규칙 4 · 비동기 제어 CancellationTokenSource 12ms 디바운싱

      FilterPreviewViewModel.cs는 사용자가 단순히 화면만 패닝·줌할 때(IsViewOnlyNavigation)는 불필요한 필터 재계산을 건너뛰고, ROI의 위치·크기나 필터 파라미터가 바뀌었을 때만 백그라운드 작업을 예약(Schedule)합니다.

      공식 1 · 변경 여부 판정 논리식 뷰포트 네비게이션 불변 조건(IsViewOnlyNavigation)과 필터 재계산 트리거
      (식 10.1)
      ✏️ 한 걸음씩 유도하기:
      1) 이미지 필터(가우시안 블러, 이진화 등)는 원본 사진 픽셀(It)과 선택된 ROI의 원본 사진 좌표(Dt)에 대해서만 계산됩니다.
      2) 따라서 사용자가 마우스 휠로 화면을 확대하거나 우클릭으로 화면을 옆으로 밀더라도, ① 문서 편집 버전(Version)이 그대로이고, ② 선택된 ROI ID(SelectedRoiId)가 그대로이며, ③ 원본 사진 참조(sourceImage)가 그대로라면 필터 결과 이미지는 이전과 100% 똑같습니다!
      3) 이 세 조건이 모두 같을 때(&&)를 IsViewOnlyNavigation = true로 판정해 무거운 필터 계산을 즉시 건너뜁니다.

      SOLID 원칙 GRASP 패턴
      GRASP · Controller & Facade

      MainWindowViewModel은 앱 단축키/명령 분배만, 마우스 좌표 계산은 InteractionController에게!

      ViewModel 안에 마우스 픽셀 계산을 넣지 않습니다. ViewModel은 EditorSession과 InteractionController를 생성해 들고 있으면서 툴바 버튼(사각형 그리기, 1억 ROI 추가, Undo)과 단축키(HandleKey)만 연결합니다.

      SOLID · SRP (단일 책임 원칙)

      캔버스 편집(MainWindowViewModel)과 실시간 필터 계산(FilterPreviewViewModel) 분리

      도형 편집 상태와 비동기 이미지 필터링(디바운싱, 스레드 취소) 책임을 별도 ViewModel로 분리하여 MainWindowViewModel이 비대해지는 것을 막았습니다.

      GRASP · Low Coupling (낮은 결합도)

      EditorSession.StateChanged 이벤트 하나로 UI 상태와 필터 프리뷰 자동 동기화

      MoveGesture나 DrawGesture가 FilterPreviewViewModel을 직접 알 필요가 없습니다. 세션 상태가 바뀌면 이벤트를 통해 느슨하게 알림을 받아 필터가 갱신됩니다.

      SOLID · DIP (의존성 역전 원칙)

      창(Window)을 안 띄워도 단위 테스트에서 모든 단축키·그리기·이동 100% 검증

      MainWindowViewModel과 InteractionController가 구체적인 WPF Window에 의존하지 않으므로, 테스트 코드에서 마우스 클릭과 키 입력을 시뮬레이션해 0.001초 만에 검증할 수 있습니다.

// [01장] 힙 할당(GC)이 전혀 없는 2D 점/벡터 불변 값 타입
public readonly record struct PointD(double X, double Y)
{
    public static PointD operator +(PointD a, PointD b) => new(a.X + b.X, a.Y + b.Y);
    public static PointD operator -(PointD a, PointD b) => new(a.X - b.X, a.Y - b.Y);
    public static PointD operator *(PointD a, double s) => new(a.X * s, a.Y * s);
    public static PointD operator /(PointD a, double s) => new(a.X / s, a.Y / s);

    public double LengthSquared => (X * X) + (Y * Y);
    public double Length => Math.Sqrt(LengthSquared);

    public static double Dot(PointD a, PointD b) => (a.X * b.X) + (a.Y * b.Y);
    public static double Cross(PointD a, PointD b) => (a.X * b.Y) - (a.Y * b.X);

    public PointD Normalize()
    {
        double len = Length;
        return len > 1e-12 ? new PointD(X / len, Y / len) : new PointD(1.0, 0.0);
    }
}

// [02장] 축 정렬 경계 상자 (AABB: Axis-Aligned Bounding Box)
public readonly record struct BoundsD(double Left, double Top, double Right, double Bottom)
{
    public double Width => Math.Max(0.0, Right - Left);
    public double Height => Math.Max(0.0, Bottom - Top);
    public PointD Center => new((Left + Right) * 0.5, (Top + Bottom) * 0.5);

    public static BoundsD FromCenterSize(PointD center, double width, double height) =>
        new(center.X - (width * 0.5), center.Y - (height * 0.5),
            center.X + (width * 0.5), center.Y + (height * 0.5));

    public bool Contains(PointD pt) =>
        pt.X >= Left && pt.X <= Right && pt.Y >= Top && pt.Y <= Bottom;

    public bool Contains(BoundsD other) =>
        other.Left >= Left && other.Right <= Right && other.Top >= Top && other.Bottom <= Bottom;

    public bool Intersects(BoundsD other) =>
        Left <= other.Right && Right >= other.Left && Top <= other.Bottom && Bottom >= other.Top;

    public BoundsD Union(BoundsD other) =>
        new(Math.Min(Left, other.Left), Math.Min(Top, other.Top),
            Math.Max(Right, other.Right), Math.Max(Bottom, other.Bottom));

    public BoundsD Inflate(double margin) =>
        new(Left - margin, Top - margin, Right + margin, Bottom + margin);
}

// [01장] 2D 강체 변환 (회전 행렬 Cos, Sin + 평행이동 Tx, Ty)
public readonly record struct RigidTransform2D(double Cos, double Sin, double Tx, double Ty)
{
    public static RigidTransform2D Identity { get; } = new(1.0, 0.0, 0.0, 0.0);

    public static RigidTransform2D FromAngle(double radians, PointD translation) =>
        new(Math.Cos(radians), Math.Sin(radians), translation.X, translation.Y);

    // 로컬 좌표 -> 월드(이미지) 좌표 정변환
    public PointD Apply(PointD local) =>
        new((local.X * Cos) - (local.Y * Sin) + Tx,
            (local.X * Sin) + (local.Y * Cos) + Ty);

    // 월드(이미지) 좌표 -> 로컬 좌표 역변환 (전치 행렬 R^T 적용)
    public PointD ApplyInverse(PointD world)
    {
        double dx = world.X - Tx;
        double dy = world.Y - Ty;
        return new PointD((dx * Cos) + (dy * Sin), (-dx * Sin) + (dy * Cos));
    }

    public static PointD RotateAround(PointD pt, PointD pivot, double deltaRadians)
    {
        double cos = Math.Cos(deltaRadians);
        double sin = Math.Sin(deltaRadians);
        double dx = pt.X - pivot.X;
        double dy = pt.Y - pivot.Y;
        return new PointD(pivot.X + (dx * cos) - (dy * sin), pivot.Y + (dx * sin) + (dy * cos));
    }
}

// [02장] 뷰포트 변환 (Image 픽셀 좌표 <-> Screen DIP 좌표 & 커서 고정 줌)
public readonly record struct ViewportTransform(double Scale, double OffsetX, double OffsetY)
{
    public static ViewportTransform Identity { get; } = new(1.0, 20.0, 20.0);

    public PointD ImageToScreen(PointD img) =>
        new((img.X * Scale) + OffsetX, (img.Y * Scale) + OffsetY);

    public PointD ScreenToImage(PointD scr) =>
        new((scr.X - OffsetX) / Scale, (scr.Y - OffsetY) / Scale);

    public BoundsD ScreenToImage(BoundsD scrBounds)
    {
        PointD tl = ScreenToImage(new PointD(scrBounds.Left, scrBounds.Top));
        PointD br = ScreenToImage(new PointD(scrBounds.Right, scrBounds.Bottom));
        return new BoundsD(tl.X, tl.Y, br.X, br.Y);
    }

    public ViewportTransform Pan(double dxDip, double dyDip) =>
        new(Scale, OffsetX + dxDip, OffsetY + dyDip);

    // (식 2.3) 마우스 커서 아래 이미지 좌표(anchorImg)가 화면에서 1픽셀도 밀리지 않는 ZoomAt
    public ViewportTransform ZoomAt(PointD cursorScreenDip, double factor)
    {
        double nextScale = Math.Clamp(Scale * factor, 0.02, 64.0);
        PointD anchorImg = ScreenToImage(cursorScreenDip);
        double nextOffsetX = cursorScreenDip.X - (anchorImg.X * nextScale);
        double nextOffsetY = cursorScreenDip.Y - (anchorImg.Y * nextScale);
        return new ViewportTransform(nextScale, nextOffsetX, nextOffsetY);
    }

    public static ViewportTransform Fit(double imgW, double imgH, double viewW, double viewH, double pad = 24.0)
    {
        if (imgW <= 0 || imgH <= 0 || viewW <= 0 || viewH <= 0) return Identity;
        double availW = Math.Max(1.0, viewW - (pad * 2.0));
        double availH = Math.Max(1.0, viewH - (pad * 2.0));
        double scale = Math.Clamp(Math.Min(availW / imgW, availH / imgH), 0.02, 64.0);
        double ox = (viewW - (imgW * scale)) * 0.5;
        double oy = (viewH - (imgH * scale)) * 0.5;
        return new ViewportTransform(scale, ox, oy);
    }

    public static ViewportTransform FocusBounds(BoundsD target, double viewW, double viewH, double pad = 40.0)
    {
        double w = Math.Max(16.0, target.Width);
        double h = Math.Max(16.0, target.Height);
        double availW = Math.Max(1.0, viewW - (pad * 2.0));
        double availH = Math.Max(1.0, viewH - (pad * 2.0));
        double scale = Math.Clamp(Math.Min(availW / w, availH / h), 0.02, 64.0);
        PointD c = target.Center;
        return new ViewportTransform(scale, (viewW * 0.5) - (c.X * scale), (viewH * 0.5) - (c.Y * scale));
    }
}

      using System;
using System.Collections.Generic;
using System.Collections.Immutable;

namespace MiniVisionCanvas;

public enum RoiShapeKind
{
    Rectangle,
    Circle,
    Polygon
}

// [03장] 사각형·원·다각형을 단일 정규화 로컬 공간 (u, v) in [-0.5, +0.5]^2로 통합한 기하 클래스
public sealed record RoiGeometry(
    RoiShapeKind Shape,
    PointD Center,
    double Width,
    double Height,
    double RotationRadians,
    ImmutableArray<PointD> NormalizedVertices)
{
    public static RoiGeometry CreateRectangle(PointD center, double width, double height, double rotationRad = 0.0) =>
        new(RoiShapeKind.Rectangle, center, Math.Max(4.0, width), Math.Max(4.0, height), rotationRad, ImmutableArray<PointD>.Empty);

    public static RoiGeometry CreateCircle(PointD center, double width, double height, double rotationRad = 0.0) =>
        new(RoiShapeKind.Circle, center, Math.Max(4.0, width), Math.Max(4.0, height), rotationRad, ImmutableArray<PointD>.Empty);

    // 정규화 로컬 좌표 (u, v) in [-0.5, +0.5]^2 -> 이미지 월드 좌표
    public PointD ToWorld(double u, double v)
    {
        RigidTransform2D pose = RigidTransform2D.FromAngle(RotationRadians, Center);
        return pose.Apply(new PointD(u * Width, v * Height));
    }

    // 이미지 월드 좌표 -> 정규화 로컬 좌표 (u, v)
    public PointD ToLocalNormalized(PointD worldPt)
    {
        RigidTransform2D pose = RigidTransform2D.FromAngle(RotationRadians, Center);
        PointD unrotated = pose.ApplyInverse(worldPt);
        return new PointD(
            Width > 1e-9 ? unrotated.X / Width : 0.0,
            Height > 1e-9 ? unrotated.Y / Height : 0.0);
    }

    // [03장 식 3.1] 역회전 후 로컬 부등식 하나로 회전 도형 포함 여부 즉시 판정
    public bool Contains(PointD worldPt, double extraMarginPx = 0.0)
    {
        RigidTransform2D pose = RigidTransform2D.FromAngle(RotationRadians, Center);
        PointD localPx = pose.ApplyInverse(worldPt);
        double halfW = (Width * 0.5) + extraMarginPx;
        double halfH = (Height * 0.5) + extraMarginPx;

        if (Math.Abs(localPx.X) > halfW || Math.Abs(localPx.Y) > halfH)
        {
            return false;
        }

        if (Shape == RoiShapeKind.Rectangle)
        {
            return true;
        }

        if (Shape == RoiShapeKind.Circle)
        {
            double nx = localPx.X / Math.Max(1e-6, halfW);
            double ny = localPx.Y / Math.Max(1e-6, halfH);
            return (nx * nx) + (ny * ny) <= 1.0;
        }

        // Polygon: 정규화 꼭짓점에 대한 Ray-Casting (홀수 번 교차하면 내부)
        PointD uv = new(localPx.X / Math.Max(1e-6, Width), localPx.Y / Math.Max(1e-6, Height));
        return ContainsInPolygon(NormalizedVertices, uv);
    }

    private static bool ContainsInPolygon(ImmutableArray<PointD> poly, PointD pt)
    {
        if (poly.IsDefaultOrEmpty || poly.Length < 3) return false;
        bool inside = false;
        for (int i = 0, j = poly.Length - 1; i < poly.Length; j = i++)
        {
            PointD a = poly[i];
            PointD b = poly[j];
            bool crossesY = (a.Y > pt.Y) != (b.Y > pt.Y);
            if (crossesY)
            {
                double intersectX = ((b.X - a.X) * (pt.Y - a.Y) / (b.Y - a.Y)) + a.X;
                if (pt.X < intersectX) inside = !inside;
            }
        }
        return inside;
    }

    // [03장 식 3.2] 임의 방향 dir로 중심에서 가장 멀리 튀어나온 거리 h(dir) (Support 함수)
    public double Support(PointD worldDir)
    {
        double cos = Math.Cos(RotationRadians);
        double sin = Math.Sin(RotationRadians);
        // 월드 방향 벡터를 도형의 회전 로컬 축으로 투영
        double lx = (worldDir.X * cos) + (worldDir.Y * sin);
        double ly = (-worldDir.X * sin) + (worldDir.Y * cos);
        double halfW = Width * 0.5;
        double halfH = Height * 0.5;

        if (Shape == RoiShapeKind.Circle)
        {
            return Math.Sqrt((halfW * halfW * lx * lx) + (halfH * halfH * ly * ly));
        }

        if (Shape == RoiShapeKind.Polygon && !NormalizedVertices.IsDefaultOrEmpty && NormalizedVertices.Length >= 3)
        {
            double maxProj = 0.0;
            foreach (PointD uv in NormalizedVertices)
            {
                double proj = (uv.X * Width * lx) + (uv.Y * Height * ly);
                if (proj > maxProj) maxProj = proj;
            }
            return maxProj;
        }

        return (halfW * Math.Abs(lx)) + (halfH * Math.Abs(ly));
    }

    // Support 함수를 이용해 회전된 도형의 바깥 경계 상자(AABB)를 O(1)에 계산
    public BoundsD WorldBounds
    {
        get
        {
            double ex = Support(new PointD(1.0, 0.0));
            double ey = Support(new PointD(0.0, 1.0));
            return new BoundsD(Center.X - ex, Center.Y - ey, Center.X + ex, Center.Y + ey);
        }
    }

    public PointD[] GetWorldCorners() =>
    [
        ToWorld(-0.5, -0.5),
        ToWorld(+0.5, -0.5),
        ToWorld(+0.5, +0.5),
        ToWorld(-0.5, +0.5)
    ];

    public PointD[] GetWorldSamplePoints()
    {
        if (Shape == RoiShapeKind.Polygon && !NormalizedVertices.IsDefaultOrEmpty && NormalizedVertices.Length >= 3)
        {
            var pts = new PointD[NormalizedVertices.Length];
            for (int i = 0; i < pts.Length; i++)
            {
                pts[i] = ToWorld(NormalizedVertices[i].X, NormalizedVertices[i].Y);
            }
            return pts;
        }

        if (Shape == RoiShapeKind.Circle)
        {
            var pts = new PointD[16];
            for (int i = 0; i < 16; i++)
            {
                double ang = (Math.PI * 2.0 * i) / 16.0;
                pts[i] = ToWorld(0.5 * Math.Cos(ang), 0.5 * Math.Sin(ang));
            }
            return pts;
        }

        return GetWorldCorners();
    }

    public RoiGeometry Translate(PointD delta) =>
        this with { Center = Center + delta };

    public RoiGeometry WithRotation(double newRadians) =>
        this with { RotationRadians = newRadians };
}

// [03장] 폴리곤 그리기 중 8자 꼬임(자기교차)을 외적(Cross Product)으로 차단하는 검증기
public static class PolygonClosure
{
    public static bool SegmentsIntersect(PointD a, PointD b, PointD c, PointD d)
    {
        PointD r = b - a;
        PointD s = d - c;
        double denom = PointD.Cross(r, s);
        if (Math.Abs(denom) < 1e-9) return false;

        double t = PointD.Cross(c - a, s) / denom;
        double u = PointD.Cross(c - a, r) / denom;
        return t > 1e-5 && t < 1.0 - 1e-5 && u > 1e-5 && u < 1.0 - 1e-5;
    }

    public static bool CanAddPoint(IReadOnlyList<PointD> existing, PointD candidate)
    {
        if (existing.Count < 2) return true;
        PointD last = existing[^1];
        for (int i = 0; i < existing.Count - 2; i++)
        {
            if (SegmentsIntersect(existing[i], existing[i + 1], last, candidate))
            {
                return false;
            }
        }
        return true;
    }

    public static bool TryCreateClosedPolygon(IReadOnlyList<PointD> worldPts, out RoiGeometry geometry)
    {
        geometry = RoiGeometry.CreateRectangle(new PointD(0, 0), 10, 10);
        if (worldPts.Count < 3) return false;

        // 마지막 점과 첫 점을 잇는 닫기 선분이 기존 변과 교차하는지 검사
        for (int i = 1; i < worldPts.Count - 2; i++)
        {
            if (SegmentsIntersect(worldPts[i], worldPts[i + 1], worldPts[^1], worldPts[0]))
            {
                return false;
            }
        }

        double minX = double.MaxValue, minY = double.MaxValue;
        double maxX = double.MinValue, maxY = double.MinValue;
        foreach (PointD p in worldPts)
        {
            if (p.X < minX) minX = p.X;
            if (p.Y < minY) minY = p.Y;
            if (p.X > maxX) maxX = p.X;
            if (p.Y > maxY) maxY = p.Y;
        }

        double w = Math.Max(8.0, maxX - minX);
        double h = Math.Max(8.0, maxY - minY);
        PointD center = new((minX + maxX) * 0.5, (minY + maxY) * 0.5);

        var normBuilder = ImmutableArray.CreateBuilder<PointD>(worldPts.Count);
        foreach (PointD p in worldPts)
        {
            normBuilder.Add(new PointD((p.X - center.X) / w, (p.Y - center.Y) / h));
        }

        geometry = new RoiGeometry(RoiShapeKind.Polygon, center, w, h, 0.0, normBuilder.MoveToImmutable());
        return true;
    }
}

      using System;

namespace MiniVisionCanvas;

// [04장] 자식 ROI가 부모 ROI 경계 밖으로 나가지 않도록 막고 벽을 따라 미끄러뜨리는 충돌 엔진
public static class RoiMotionBounds
{
    public static bool ContainsGeometry(RoiGeometry parent, RoiGeometry child)
    {
        foreach (PointD pt in child.GetWorldSamplePoints())
        {
            if (!parent.Contains(pt))
            {
                return false;
            }
        }
        return true;
    }

    // [04장 식 4.1 & 4.2] 40회 이분법 + 부모 벽면 정사영(Wall Sliding)
    public static PointD ClampTranslation(RoiGeometry parent, RoiGeometry child, PointD rawDelta)
    {
        if (ContainsGeometry(parent, child.Translate(rawDelta)))
        {
            return rawDelta;
        }

        // 1단계: 40회 이분법으로 부모 벽에 부딪히기 직전의 최대 비율 t in [0, 1] 탐색
        double t = FindMaxFreeTranslationFactor(parent, child, rawDelta);
        PointD safeDelta = rawDelta * t;
        RoiGeometry atWall = child.Translate(safeDelta);

        // 2단계: 남은 이동량(rawDelta - safeDelta)을 부모의 회전 축 방향(벽면)으로 정사영해 미끄러짐 적용
        PointD remaining = rawDelta - safeDelta;
        PointD slideDelta = ProjectAlongParentWall(parent, atWall, remaining);
        return safeDelta + slideDelta;
    }

    private static double FindMaxFreeTranslationFactor(RoiGeometry parent, RoiGeometry child, PointD delta)
    {
        double low = 0.0;
        double high = 1.0;
        for (int iter = 0; iter < 40; iter++)
        {
            double mid = (low + high) * 0.5;
            if (ContainsGeometry(parent, child.Translate(delta * mid)))
            {
                low = mid;
            }
            else
            {
                high = mid;
            }
        }
        return low;
    }

    private static PointD ProjectAlongParentWall(RoiGeometry parent, RoiGeometry childAtWall, PointD remaining)
    {
        double cos = Math.Cos(parent.RotationRadians);
        double sin = Math.Sin(parent.RotationRadians);
        PointD axisU = new(cos, sin);
        PointD axisV = new(-sin, cos);

        // 가로축(axisU) 방향 미끄러짐 성분과 세로축(axisV) 방향 미끄러짐 성분을 각각 이분법으로 안전 적용
        PointD projU = axisU * PointD.Dot(remaining, axisU);
        double tU = FindMaxFreeTranslationFactor(parent, childAtWall, projU);
        PointD appliedU = projU * tU;

        RoiGeometry afterU = childAtWall.Translate(appliedU);

    public static double ClampRotation(RoiGeometry parent, RoiGeometry child, double rawDeltaRadians)
    {
        if (ContainsGeometry(parent, child.WithRotation(child.RotationRadians + rawDeltaRadians)))
        {
            return rawDeltaRadians;
        }

        double low = 0.0;
        double high = 1.0;
        for (int iter = 0; iter < 40; iter++)
        {
            double mid = (low + high) * 0.5;
            if (ContainsGeometry(parent, child.WithRotation(child.RotationRadians + (rawDeltaRadians * mid))))
            {
                low = mid;
            }
            else
            {
                high = mid;
            }
        }
        return rawDeltaRadians * low;
    }

// [05장 RoiSpatialIndex.cs] 일반 ROI와 대량 격자 ROI를 O(log N)에 검색하는 BVH(Bounding Volume Hierarchy) 이진 공간 트리
public sealed class RoiSpatialIndex
{
    public readonly record struct Entry(Guid Id, BoundsD Bounds);

    private sealed record Node(BvhNodePath Path, BoundsD Bounds, Node? Left, Node? Right, Guid? LeafId);

    private readonly Node? _root;

    private RoiSpatialIndex(Node? root) => _root = root;

    public static RoiSpatialIndex Empty { get; } = new(null);

    public static RoiSpatialIndex Build(IReadOnlyList<Entry> entries)
    {
        if (entries.Count == 0) return Empty;
        var mutable = new List<Entry>(entries);
        return new RoiSpatialIndex(BuildNode(mutable, 0, mutable.Count, BvhNodePath.Root));
    }

    private static Node BuildNode(List<Entry> items, int start, int count, BvhNodePath path)
    {
        if (count == 1)
        {
            Entry leaf = items[start];
            return new Node(path, leaf.Bounds, null, null, leaf.Id);
        }

        BoundsD total = items[start].Bounds;
        for (int i = start + 1; i < start + count; i++)
        {
            total = total.Union(items[i].Bounds);
        }

        // 가장 긴 축(가로 vs 세로)을 기준으로 정렬해 반씩 분할
        bool splitX = total.Width >= total.Height;
        items.Sort(start, count, Comparer<Entry>.Create((a, b) =>
            splitX ? a.Bounds.Center.X.CompareTo(b.Bounds.Center.X)
                   : a.Bounds.Center.Y.CompareTo(b.Bounds.Center.Y)));

        int mid = count / 2;
        Node left = BuildNode(items, start, mid, path.LeftChild());
        Node right = BuildNode(items, start + mid, count - mid, path.RightChild());
        return new Node(path, total, left, right, null);
    }

    public List<Guid> QueryPoint(PointD pt)
    {
        var results = new List<Guid>();
        QueryPointRecursive(_root, pt, results);
        return results;
    }

    private static void QueryPointRecursive(Node? node, PointD pt, List<Guid> results)
    {
        if (node is null || !node.Bounds.Contains(pt)) return;
        if (node.LeafId is { } id)
        {
            results.Add(id);
            return;
        }
        QueryPointRecursive(node.Left, pt, results);
        QueryPointRecursive(node.Right, pt, results);
    }
}

// [05장 식 5.1] 10,001 x 10,001 = 100,020,001개 셀의 좌표를 계산하는 격자 수식 구조체
public readonly record struct RepeatedRoiGrid(
    PointD Origin,
    double CellWidth,
    double CellHeight,
    double StepX,
    double StepY,
    int Columns,
    int Rows)
{
    public long TotalCellCount => (long)Columns * Rows;

    public BoundsD TotalBounds => new(
        Origin.X,
        Origin.Y,
        Origin.X + ((Columns - 1) * StepX) + CellWidth,
        Origin.Y + ((Rows - 1) * StepY) + CellHeight);

    public BoundsD GetCellBounds(int row, int col)
    {
        double left = Origin.X + (col * StepX);
        double top = Origin.Y + (row * StepY);
        return new BoundsD(left, top, left + CellWidth, top + CellHeight);
    }

    // 나눗셈 단 2번(O(1))으로 1억 개 중 마우스가 클릭한 (row, col) 셀 번호 역산
    public bool TryHitCell(PointD worldPt, out int row, out int col, out long cellIndex)
    {
        row = 0;
        col = 0;
        cellIndex = -1;
        if (Columns <= 0 || Rows <= 0) return false;

        col = (int)Math.Floor((worldPt.X - Origin.X) / StepX);
        row = (int)Math.Floor((worldPt.Y - Origin.Y) / StepY);
        if (col < 0 || col >= Columns || row < 0 || row >= Rows) return false;

        BoundsD cellBounds = GetCellBounds(row, col);
        if (!cellBounds.Contains(worldPt)) return false;

        cellIndex = ((long)row * Columns) + col;
        return true;
    }

    public (int r0, int r1, int c0, int c1) GetVisibleRange(BoundsD visibleWorld)
    {
        int c0 = Math.Clamp((int)Math.Floor((visibleWorld.Left - Origin.X - CellWidth) / StepX), 0, Columns - 1);
        int c1 = Math.Clamp((int)Math.Ceiling((visibleWorld.Right - Origin.X) / StepX), 0, Columns - 1);
        int r0 = Math.Clamp((int)Math.Floor((visibleWorld.Top - Origin.Y - CellHeight) / StepY), 0, Rows - 1);
        int r1 = Math.Clamp((int)Math.Ceiling((visibleWorld.Bottom - Origin.Y) / StepY), 0, Rows - 1);
        return (r0, r1, c0, c1);
    }
}

// [05장] 순수 WPF DrawingContext 환경에서도 1억 셀 + 개별 셀 편집/삭제를 즉시 체험할 수 있는 가상 격자 슬라이스
public sealed record VirtualGridSlice(
    Guid Id,
    string Name,
    RepeatedRoiGrid Grid,
    ImmutableDictionary<long, CellOverride> CellOverrides,
    ImmutableHashSet<long> DeletedCells)
{
    public long ActiveCellCount => Grid.TotalCellCount - DeletedCells.Count;

    public RoiGeometry GetCellGeometry(long cellIndex)
    {
        int row = (int)(cellIndex / Grid.Columns);
        int col = (int)(cellIndex % Grid.Columns);
        BoundsD baseBounds = Grid.GetCellBounds(row, col);
        PointD center = baseBounds.Center;
        double w = Grid.CellWidth;
        double h = Grid.CellHeight;
        double rot = 0.0;

        if (CellOverrides.TryGetValue(cellIndex, out CellOverride ov))
        {
            center += ov.Offset;
            w = Math.Max(2.0, w + ov.WidthDelta);
            h = Math.Max(2.0, h + ov.HeightDelta);
            rot = ov.RotationRadians;
        }
        return RoiGeometry.CreateRectangle(center, w, h, rot);
    }

    public bool TryHit(PointD worldPt, out long hitCellIndex)
    {
        // 1순위: 개별 이동/회전된 Override 셀 먼저 확인
        foreach (var kv in CellOverrides)
        {
            if (!DeletedCells.Contains(kv.Key) && GetCellGeometry(kv.Key).Contains(worldPt))
            {
                hitCellIndex = kv.Key;
                return true;
            }
        }

        // 2순위: O(1) 격자 수식 역산
        if (Grid.TryHitCell(worldPt, out _, out _, out long idx)
            && !DeletedCells.Contains(idx)
            && !CellOverrides.ContainsKey(idx))
        {
            hitCellIndex = idx;
            return true;
        }

        hitCellIndex = -1;
        return false;
    }
}

        PointD upDir = (tm - bm).Normalize();
        PointD rot = tm + (upDir * 24.0);

        return
        [
            (RoiHandleKind.Rotate, rot),
            (RoiHandleKind.TopLeft, tl),
            (RoiHandleKind.Top, tm),
            (RoiHandleKind.TopRight, tr),
            (RoiHandleKind.Right, rm),
            (RoiHandleKind.BottomRight, br),
            (RoiHandleKind.Bottom, bm),
            (RoiHandleKind.BottomLeft, bl),
            (RoiHandleKind.Left, lm)
        ];
    }

    public static Guid? HitRoi(DocumentState doc, ViewportTransform vp, PointD screenDip)
    {
        PointD imgPt = vp.ScreenToImage(screenDip);
        double marginImg = 3.0 / Math.Max(0.01, vp.Scale);

        List<Guid> candidates = doc.SpatialIndex.QueryPoint(imgPt);
        var hits = new List<Roi>();
        foreach (Guid id in candidates)
        {
            if (doc.Rois.TryGetValue(id, out Roi? roi) && roi.Geometry.Contains(imgPt, marginImg))
            {
                hits.Add(roi);
            }
        }

        if (hits.Count == 0) return null;

        // 작은 면적(자식 핀 ROI)이 큰 면적(부모 그룹 ROI)보다 먼저 선택되도록 정렬
        hits.Sort((a, b) => (a.Geometry.Width * a.Geometry.Height).CompareTo(b.Geometry.Width * b.Geometry.Height));
        return hits[0].Id;
    }

    public static (Guid BatchId, long CellIndex)? HitRepeatedCell(DocumentState doc, ViewportTransform vp, PointD screenDip)
    {
        PointD imgPt = vp.ScreenToImage(screenDip);
        for (int i = doc.RepeatedBatches.Length - 1; i >= 0; i--)
        {
            VirtualGridSlice batch = doc.RepeatedBatches[i];
            if (batch.TryHit(imgPt, out long cellIdx))
            {
                return (batch.Id, cellIdx);
            }
        }
        return null;
    }
}

public sealed class MoveGesture(EditorSession session, PointD startImg, ImmutableHashSet<Guid> movingIds) : IGesture
{
    public void Update(PointD currentDip)
    {
        PointD curImg = session.Viewport.ScreenToImage(currentDip);
        PointD delta = ClampGroupTranslation(session.Document, movingIds, curImg - startImg);
        session.SetPreview(new RoiTransformPreview(movingIds, delta, 0.0));
    }

    public void Commit()
    {
        if (session.ActivePreview is not { } preview || preview.TranslationDelta.LengthSquared < 1e-9)
        {
            session.SetPreview(null);
            return;
        }
        var builder = session.Document.Rois.ToBuilder();
        foreach (Guid id in preview.TargetIds)
        {
            if (builder.TryGetValue(id, out Roi? r))
            {
                builder[id] = preview.ApplyTo(r);
            }
        }
        session.CommitDocument(session.Document.WithUpdatedRois(builder.ToImmutable()));
    }

    public void Cancel() => session.SetPreview(null);

    public static PointD ClampGroupTranslation(DocumentState doc, ImmutableHashSet<Guid> movingIds, PointD rawDelta)
    {
        PointD clamped = rawDelta;
        foreach (Guid id in movingIds)
        {
            if (doc.Rois.TryGetValue(id, out Roi? child)
                && child.ParentId is { } pid
                && !movingIds.Contains(pid)
                && doc.Rois.TryGetValue(pid, out Roi? parent))
            {
                clamped = RoiMotionBounds.ClampTranslation(parent.Geometry, child.Geometry, clamped);
            }
        }
        return clamped;
    }
}

public sealed class RotateGesture(EditorSession session, Guid roiId, PointD startImg) : IGesture
{
    private readonly Roi _initialRoi = session.Document.Rois[roiId];
    private readonly double _startAngle = Math.Atan2(
        startImg.Y - session.Document.Rois[roiId].Geometry.Center.Y,
        startImg.X - session.Document.Rois[roiId].Geometry.Center.X);

    public void Update(PointD currentDip)
    {
        PointD curImg = session.Viewport.ScreenToImage(currentDip);
        PointD c = _initialRoi.Geometry.Center;
        double curAngle = Math.Atan2(curImg.Y - c.Y, curImg.X - c.X);
        double deltaRad = curAngle - _startAngle;

        if (_initialRoi.ParentId is { } pid && session.Document.Rois.TryGetValue(pid, out Roi? parent))
        {
            deltaRad = RoiMotionBounds.ClampRotation(parent.Geometry, _initialRoi.Geometry, deltaRad);
        }
        session.SetPreview(new RoiTransformPreview(ImmutableHashSet.Create(roiId), default, deltaRad));
    }

    public void Commit()
    {
        if (session.ActivePreview is not { } preview || Math.Abs(preview.RotationDeltaRad) < 1e-9)
        {
            session.SetPreview(null);
            return;
        }
        Roi updated = preview.ApplyTo(_initialRoi);
        session.CommitDocument(session.Document.WithUpdatedRois(session.Document.Rois.SetItem(roiId, updated)));
    }

    public void Cancel() => session.SetPreview(null);
}

public sealed class ResizeGesture(EditorSession session, Guid roiId, RoiHandleKind handle) : IGesture
{
    private readonly Roi _initialRoi = session.Document.Rois[roiId];

    public void Update(PointD currentDip)
    {
        PointD curImg = session.Viewport.ScreenToImage(currentDip);
        RoiGeometry g = _initialRoi.Geometry;
        PointD local = RigidTransform2D.FromAngle(g.RotationRadians, g.Center).ApplyInverse(curImg);

        double left = -g.Width * 0.5, right = g.Width * 0.5;
        double top = -g.Height * 0.5, bottom = g.Height * 0.5;

        if (handle is RoiHandleKind.Left or RoiHandleKind.TopLeft or RoiHandleKind.BottomLeft) left = Math.Min(right - 8.0, local.X);
        if (handle is RoiHandleKind.Right or RoiHandleKind.TopRight or RoiHandleKind.BottomRight) right = Math.Max(left + 8.0, local.X);
        if (handle is RoiHandleKind.Top or RoiHandleKind.TopLeft or RoiHandleKind.TopRight) top = Math.Min(bottom - 8.0, local.Y);
        if (handle is RoiHandleKind.Bottom or RoiHandleKind.BottomLeft or RoiHandleKind.BottomRight) bottom = Math.Max(top + 8.0, local.Y);

        PointD localCenterOffset = new((left + right) * 0.5, (top + bottom) * 0.5);
        PointD newWorldCenter = RigidTransform2D.FromAngle(g.RotationRadians, g.Center).Apply(localCenterOffset);
        RoiGeometry candidate = g with { Center = newWorldCenter, Width = right - left, Height = bottom - top };

        if (_initialRoi.ParentId is { } pid
            && session.Document.Rois.TryGetValue(pid, out Roi? parent)
            && !RoiMotionBounds.ContainsGeometry(parent.Geometry, candidate))
        {
            return;
        }

        session.SetPreview(new RoiTransformPreview(ImmutableHashSet.Create(roiId), default, 0.0, candidate));
    }

    public void Commit()
    {
        if (session.ActivePreview?.ResizedSingleGeometry is not { } resized)
        {
            session.SetPreview(null);
            return;
        }
        Roi updated = _initialRoi with { Geometry = resized };
        session.CommitDocument(session.Document.WithUpdatedRois(session.Document.Rois.SetItem(roiId, updated)));
    }

    public void Cancel() => session.SetPreview(null);
}

public sealed class DrawShapeGesture(EditorSession session, PointD startImg, RoiShapeKind shape, bool asGroup, Guid? parentId) : IGesture
{
    private RoiGeometry? _draft;

    public void Update(PointD currentDip)
    {
        PointD curImg = session.Viewport.ScreenToImage(currentDip);
        PointD center = (startImg + curImg) * 0.5;
        double w = Math.Max(12.0, Math.Abs(curImg.X - startImg.X));
        double h = Math.Max(12.0, Math.Abs(curImg.Y - startImg.Y));
        _draft = shape == RoiShapeKind.Circle
            ? RoiGeometry.CreateCircle(center, w, h)
            : RoiGeometry.CreateRectangle(center, w, h);

        if (parentId is { } pid && session.Document.Rois.TryGetValue(pid, out Roi? parent)
            && !RoiMotionBounds.ContainsGeometry(parent.Geometry, _draft))
        {
            _draft = null;
        }
        session.NotifyChanged();
    }

    public RoiGeometry? DraftGeometry => _draft;

    public void Commit()
    {
        if (_draft is null) return;
        Guid id = Guid.NewGuid();
        string prefix = asGroup ? "Group" : shape.ToString();
        var roi = new Roi(id, $"{prefix}_{session.Document.Rois.Count + 1}", parentId, asGroup, _draft);
        var nextRois = session.Document.Rois.Add(id, roi);
        session.CommitDocument(session.Document.WithUpdatedRois(nextRois, ImmutableHashSet.Create(id)));
    }

    public void Cancel() => _draft = null;
}

public sealed class RepeatedCellMoveGesture(EditorSession session, Guid batchId, long cellIndex, PointD startImg) : IGesture
{
    private readonly CellOverride _initialOverride = session.Document.RepeatedBatches
        .First(b => b.Id == batchId).CellOverrides.GetValueOrDefault(cellIndex);

    public void Update(PointD currentDip)
    {
        PointD curImg = session.Viewport.ScreenToImage(currentDip);
        PointD delta = curImg - startImg;
        var nextOv = _initialOverride with { Offset = _initialOverride.Offset + delta };
        session.SetCellPreview((batchId, cellIndex, nextOv));
    }

    public void Commit()
    {
        if (session.ActiveCellPreview is not { } preview) return;
        int idx = session.Document.FindBatchIndex(batchId);
        if (idx < 0) return;

        VirtualGridSlice batch = session.Document.RepeatedBatches[idx];
        VirtualGridSlice updatedBatch = batch with
        {
            CellOverrides = batch.CellOverrides.SetItem(cellIndex, preview.Override)
        };
        session.CommitDocument(session.Document with
        {
            Version = session.Document.Version + 1,
            RepeatedBatches = session.Document.RepeatedBatches.SetItem(idx, updatedBatch)
        });
    }

    public void Cancel() => session.SetCellPreview(null);
}

// [06장 & ADR-069] 마우스/키보드 입력을 제스처로 연결하고 입력 잠금(IsEnabled / NavigationOnly)을 제어하는 컨트롤러
public sealed class InteractionController(EditorSession session)
{
    private IGesture _activeGesture = NoGesture.Instance;
    private readonly List<PointD> _polygonDraft = [];
    private bool _isEnabled = true;
    private bool _navigationOnly;

    public EditorTool Tool { get; set; } = EditorTool.Select;
    public DrawShapeGesture? CurrentDrawGesture => _activeGesture as DrawShapeGesture;

    public bool IsEnabled
    {
        get => _isEnabled;
        set
        {
            if (_isEnabled == value) return;
            _isEnabled = value;
            if (!_isEnabled) Cancel();
        }
    }

    public bool NavigationOnly
    {
        get => _navigationOnly;
        set
        {
            if (_navigationOnly == value) return;
            _navigationOnly = value;
            if (_navigationOnly) Cancel();
        }
    }

    public void PointerDown(PointD screenDip, bool rightOrMiddleButton)
    {
        if (!IsEnabled) return;

        if (rightOrMiddleButton || Tool == EditorTool.Pan || NavigationOnly)
        {
            _activeGesture = new PanGesture(session, screenDip);
            return;
        }

        PointD imgPt = session.Viewport.ScreenToImage(screenDip);

        if (Tool == EditorTool.DrawPolygon)
        {
            if (PolygonClosure.CanAddPoint(_polygonDraft, imgPt))
            {
                _polygonDraft.Add(imgPt);
                session.SetDraftPolygon(_polygonDraft.ToArray());
            }
            return;

                Guid selId = session.Document.SelectedIds.First();
                if (session.Document.Rois.TryGetValue(selId, out Roi? selRoi) && selRoi.IsGroup)
                {
                    parentId = selId;
                }
            }
            RoiShapeKind shape = Tool == EditorTool.DrawCircle ? RoiShapeKind.Circle : RoiShapeKind.Rectangle;
            _activeGesture = new DrawShapeGesture(session, imgPt, shape, Tool == EditorTool.DrawParentGroup, parentId);
            return;
        }

        // 1순위: 핸들(리사이즈 / 회전) 히트 검사
        if (RoiHitTester.HitHandle(session.Document, session.Viewport, screenDip) is { } handleHit)
        {
            _activeGesture = handleHit.Handle == RoiHandleKind.Rotate
                ? new RotateGesture(session, handleHit.RoiId, imgPt)
                : new ResizeGesture(session, handleHit.RoiId, handleHit.Handle);
            return;
        }

        // 2순위: 1억 개 반복 셀 히트 검사
        if (RoiHitTester.HitRepeatedCell(session.Document, session.Viewport, screenDip) is { } cellHit)
        {
            session.UpdateSelectionOnly(ImmutableHashSet<Guid>.Empty, cellHit);
            _activeGesture = new RepeatedCellMoveGesture(session, cellHit.BatchId, cellHit.CellIndex, imgPt);
            return;
        }

        // 3순위: 일반 ROI 히트 검사 (부모 선택 시 하위 자식 트리 전체 동반 이동)
        if (RoiHitTester.HitRoi(session.Document, session.Viewport, screenDip) is { } hitId)
        {
            session.UpdateSelectionOnly(ImmutableHashSet.Create(hitId), null);
            ImmutableHashSet<Guid> moving = session.Document.CollectSubtreeIds([hitId]);
            _activeGesture = new MoveGesture(session, imgPt, moving);
            return;
        }

        session.UpdateSelectionOnly(ImmutableHashSet<Guid>.Empty, null);
    }

    public void PointerMove(PointD screenDip)
    {
        if (!IsEnabled) return;
        _activeGesture.Update(screenDip);
    }

    public void PointerUp(PointD screenDip)
    {
        if (!IsEnabled) return;
        _activeGesture.Update(screenDip);
        _activeGesture.Commit();
        _activeGesture = NoGesture.Instance;
        if (Tool is EditorTool.DrawRectangle or EditorTool.DrawCircle or EditorTool.DrawParentGroup)
        {
            Tool = EditorTool.Select;
        }
    }

    public void MouseWheel(PointD screenDip, int wheelDelta)
    {
        if (!IsEnabled) return;
        double factor = wheelDelta > 0 ? 1.2 : (1.0 / 1.2);
        session.SetViewport(session.Viewport.ZoomAt(screenDip, factor));
    }

    public bool TryCompletePolygon()
    {
        if (_polygonDraft.Count < 3 || !PolygonClosure.TryCreateClosedPolygon(_polygonDraft, out RoiGeometry polyGeom))
        {
            return false;
        }
        _polygonDraft.Clear();
        session.SetDraftPolygon([]);
        Guid id = Guid.NewGuid();
        var roi = new Roi(id, $"Polygon_{session.Document.Rois.Count + 1}", null, false, polyGeom);
        session.CommitDocument(session.Document.WithUpdatedRois(session.Document.Rois.Add(id, roi), ImmutableHashSet.Create(id)));
        Tool = EditorTool.Select;
        return true;
    }

    // [ADR-069] 선택된 ROI(또는 1억 셀 중 선택된 셀)를 방향키 1px / Shift+방향키 10px 미세 이동
    public bool TryMoveSelectionBy(PointD deltaImg)
    {
        if (!IsEnabled || NavigationOnly) return false;

        if (session.Document.SelectedRepeatedCell is { } selCell)
        {
            int idx = session.Document.FindBatchIndex(selCell.BatchId);
            if (idx < 0) return false;
            VirtualGridSlice batch = session.Document.RepeatedBatches[idx];
            CellOverride ov = batch.CellOverrides.GetValueOrDefault(selCell.CellIndex);
            VirtualGridSlice updated = batch with
            {
                CellOverrides = batch.CellOverrides.SetItem(selCell.CellIndex, ov with { Offset = ov.Offset + deltaImg })
            };
            session.CommitDocument(session.Document with
            {
                Version = session.Document.Version + 1,
                RepeatedBatches = session.Document.RepeatedBatches.SetItem(idx, updated)
            });
            return true;
        }

        if (session.Document.SelectedIds.IsEmpty) return false;
        ImmutableHashSet<Guid> moving = session.Document.CollectSubtreeIds(session.Document.SelectedIds);
        PointD clamped = MoveGesture.ClampGroupTranslation(session.Document, moving, deltaImg);
        if (clamped.LengthSquared < 1e-9) return false;

        var builder = session.Document.Rois.ToBuilder();
        foreach (Guid id in moving)
        {
            if (builder.TryGetValue(id, out Roi? r))
            {
                builder[id] = r with { Geometry = r.Geometry.Translate(clamped) };
            }
        }
        session.CommitDocument(session.Document.WithUpdatedRois(builder.ToImmutable()));
        return true;
    }

    public void Cancel()
    {
        _activeGesture.Cancel();
        _activeGesture = NoGesture.Instance;
        _polygonDraft.Clear();
        session.SetDraftPolygon([]);
    }
}

{
    public const int TileSize = 512;

    public static int SelectPyramidLevel(double scale, int maxLevel = 6)
    {
        if (scale >= 1.0) return 0;
        int level = (int)Math.Floor(Math.Log2(1.0 / scale));
        return Math.Clamp(level, 0, maxLevel);
    }

    // Vector256<int>를 사용해 8개 픽셀의 반올림 평균 ((A + B + 1) >> 1)을 단 1클럭에 계산
    public static void AverageRowSimd(ReadOnlySpan<int> rowA, ReadOnlySpan<int> rowB, Span<int> dst)
    {
        int i = 0;
        Vector256<int> one = Vector256.Create(1);
        for (; i + 8 <= dst.Length; i += 8)
        {
            Vector256<int> va = Vector256.Create(rowA.Slice(i, 8));
            Vector256<int> vb = Vector256.Create(rowB.Slice(i, 8));
            Vector256<int> avg = (va + vb + one) >> 1;
            avg.CopyTo(dst.Slice(i, 8));
        }
        for (; i < dst.Length; i++)
        {
            dst[i] = (rowA[i] + rowB[i] + 1) >> 1;
        }
    }
}

    protected override void OnRender(DrawingContext dc)
    {
        dc.DrawRectangle(new SolidColorBrush(Color.FromRgb(11, 15, 25)), null, new Rect(0, 0, ActualWidth, ActualHeight));
        if (_session is null) return;

        DocumentState doc = _session.Document;
        ViewportTransform vp = _session.Viewport;

        // 1단계: 배경 8K 이미지 영역 및 현재 LOD 타일(512px) 격자 그리기
        DrawBackgroundTiles(dc, doc, vp);

        // 2단계: 1억 개 반복 배치(VirtualGridSlice) 가시 범위 고속 렌더링
        DrawRepeatedBatches(dc, doc, vp);

    private void DrawBackgroundTiles(DrawingContext dc, DocumentState doc, ViewportTransform vp)
    {
        PointD tl = vp.ImageToScreen(new PointD(0, 0));
        PointD br = vp.ImageToScreen(new PointD(doc.ImageWidth, doc.ImageHeight));
        Rect imgRect = new(new Point(tl.X, tl.Y), new Point(br.X, br.Y));
        dc.DrawRectangle(new SolidColorBrush(Color.FromRgb(20, 29, 47)), new Pen(Brushes.SlateGray, 1.5), imgRect);

        int lod = TilePlanner.SelectPyramidLevel(vp.Scale);
        int stepPx = TilePlanner.TileSize << lod;
        var gridPen = new Pen(new SolidColorBrush(Color.FromArgb(45, 56, 189, 248)), 1.0);

        for (double x = 0; x <= doc.ImageWidth; x += stepPx)
        {
            double sx = vp.ImageToScreen(new PointD(x, 0)).X;
            if (sx >= imgRect.Left && sx <= imgRect.Right)
                dc.DrawLine(gridPen, new Point(sx, imgRect.Top), new Point(sx, imgRect.Bottom));
        }
        for (double y = 0; y <= doc.ImageHeight; y += stepPx)
        {
            double sy = vp.ImageToScreen(new PointD(0, y)).Y;
            if (sy >= imgRect.Top && sy <= imgRect.Bottom)
                dc.DrawLine(gridPen, new Point(imgRect.Left, sy), new Point(imgRect.Right, sy));
        }
    }

    private void DrawRepeatedBatches(DrawingContext dc, DocumentState doc, ViewportTransform vp)
    {
        BoundsD visibleImg = vp.ScreenToImage(new BoundsD(0, 0, ActualWidth, ActualHeight));
        var batchPen = new Pen(new SolidColorBrush(Color.FromRgb(52, 211, 153)), 1.2);
        var cellPen = new Pen(new SolidColorBrush(Color.FromArgb(190, 52, 211, 153)), 1.0);
        var selCellPen = new Pen(Brushes.Yellow, 2.0);

        foreach (VirtualGridSlice batch in doc.RepeatedBatches)
        {
            BoundsD total = batch.Grid.TotalBounds;
            PointD btl = vp.ImageToScreen(new PointD(total.Left, total.Top));
            PointD bbr = vp.ImageToScreen(new PointD(total.Right, total.Bottom));
            dc.DrawRectangle(new SolidColorBrush(Color.FromArgb(24, 52, 211, 153)), batchPen,
                new Rect(new Point(btl.X, btl.Y), new Point(bbr.X, bbr.Y)));

            // 셀 화면 크기가 충분히 클 때는 가시 행·열 범위(GetVisibleRange)의 개별 셀을 직접 렌더링
            if (batch.Grid.StepX * vp.Scale >= 6.0)
            {
                (int r0, int r1, int c0, int c1) = batch.Grid.GetVisibleRange(visibleImg);
                int maxDraw = 2500;
                int drawn = 0;
                for (int r = r0; r <= r1 && drawn < maxDraw; r++)
                {
                    for (int c = c0; c <= c1 && drawn < maxDraw; c++)
                    {
                        long idx = ((long)r * batch.Grid.Columns) + c;
                        if (batch.DeletedCells.Contains(idx)) continue;
                        RoiGeometry g = batch.GetCellGeometry(idx);
                        if (_session?.ActiveCellPreview is { } cp && cp.BatchId == batch.Id && cp.CellIndex == idx)
                        {
                            BoundsD baseB = batch.Grid.GetCellBounds(r, c);
                            g = RoiGeometry.CreateRectangle(baseB.Center + cp.Override.Offset, batch.Grid.CellWidth, batch.Grid.CellHeight, cp.Override.RotationRadians);
                        }
                        bool isSel = doc.SelectedRepeatedCell == (batch.Id, idx);
                        DrawGeometryPolygon(dc, g, vp, isSel ? selCellPen : cellPen, null);
                        drawn++;
                    }
                }
            }
        }
    }

    private void DrawRoiOverlays(DrawingContext dc, DocumentState doc, ViewportTransform vp)
    {
        foreach (Roi rawRoi in doc.Rois.Values)
        {
            Roi roi = _session?.ActivePreview is { } prev ? prev.ApplyTo(rawRoi) : rawRoi;
            bool selected = doc.SelectedIds.Contains(roi.Id);
            Color strokeColor = selected
                ? Color.FromRgb(251, 191, 36)
                : (roi.IsGroup ? Color.FromRgb(56, 189, 248) : Color.FromRgb(244, 114, 182));
            var pen = new Pen(new SolidColorBrush(strokeColor), selected ? 2.4 : 1.8);
            var fill = new SolidColorBrush(Color.FromArgb(selected ? (byte)45 : (byte)20, strokeColor.R, strokeColor.G, strokeColor.B));
            DrawGeometryPolygon(dc, roi.Geometry, vp, pen, fill);
        }
    }

    private static void DrawGeometryPolygon(DrawingContext dc, RoiGeometry g, ViewportTransform vp, Pen pen, Brush? fill)
    {
        PointD[] pts = g.GetWorldSamplePoints();
        if (pts.Length < 3) return;
        var geom = new StreamGeometry();
        using (StreamGeometryContext ctx = geom.Open())
        {
            PointD p0 = vp.ImageToScreen(pts[0]);
            ctx.BeginFigure(new Point(p0.X, p0.Y), fill is not null, isClosed: true);
            for (int i = 1; i < pts.Length; i++)
            {
                PointD pi = vp.ImageToScreen(pts[i]);
                ctx.LineTo(new Point(pi.X, pi.Y), isStroked: true, isSmoothJoin: false);
            }
        }
        geom.Freeze();
        dc.DrawGeometry(fill, pen, geom);
    }

    private void DrawSelectionHandles(DrawingContext dc, DocumentState doc, ViewportTransform vp)
    {
        if (doc.SelectedIds.Count != 1) return;
        Guid id = doc.SelectedIds.First();
        if (!doc.Rois.TryGetValue(id, out Roi? rawRoi)) return;
        Roi roi = _session?.ActivePreview is { } prev ? prev.ApplyTo(rawRoi) : rawRoi;

        (RoiHandleKind Kind, PointD ScreenPt)[] handles = RoiHitTester.GetScreenHandles(roi.Geometry, vp);
        PointD topMid = handles[2].ScreenPt;
        PointD rotPt = handles[0].ScreenPt;
        dc.DrawLine(new Pen(Brushes.Gold, 1.5), new Point(topMid.X, topMid.Y), new Point(rotPt.X, rotPt.Y));

        foreach ((RoiHandleKind kind, PointD pt) in handles)
        {
            if (kind == RoiHandleKind.Rotate)
                dc.DrawEllipse(Brushes.Gold, new Pen(Brushes.Black, 1.0), new Point(pt.X, pt.Y), 5.5, 5.5);
            else
                dc.DrawRectangle(Brushes.White, new Pen(Brushes.RoyalBlue, 1.5), new Rect(pt.X - 4.0, pt.Y - 4.0, 8.0, 8.0));
        }
    }

    private void DrawDraftOverlays(DrawingContext dc, ViewportTransform vp)
    {
        if (_controller?.CurrentDrawGesture?.DraftGeometry is { } draft)
        {
            var pen = new Pen(Brushes.Cyan, 2.0) { DashStyle = DashStyles.Dash };
            DrawGeometryPolygon(dc, draft, vp, pen, new SolidColorBrush(Color.FromArgb(35, 0, 255, 255)));
        }

        IReadOnlyList<PointD> poly = _session?.DraftPolygonPoints ?? [];
        if (poly.Count > 0)
        {
            var pen = new Pen(Brushes.Lime, 2.0);
            for (int i = 0; i < poly.Count - 1; i++)
            {
                PointD a = vp.ImageToScreen(poly[i]);
                PointD b = vp.ImageToScreen(poly[i + 1]);
                dc.DrawLine(pen, new Point(a.X, a.Y), new Point(b.X, b.Y));
            }
            foreach (PointD p in poly)
            {
                PointD s = vp.ImageToScreen(p);
                dc.DrawEllipse(Brushes.Lime, null, new Point(s.X, s.Y), 4, 4);
            }
        }
    }

    private void DrawMinimap(DrawingContext dc, DocumentState doc, ViewportTransform vp)
    {
        if (ActualWidth < 240 || ActualHeight < 180) return;
        Rect mini = new(ActualWidth - 156, ActualHeight - 116, 140, 100);
        dc.DrawRectangle(new SolidColorBrush(Color.FromArgb(210, 15, 23, 42)), new Pen(Brushes.SlateGray, 1.0), mini);

        double sx = mini.Width / Math.Max(1.0, doc.ImageWidth);
        double sy = mini.Height / Math.Max(1.0, doc.ImageHeight);
        BoundsD vis = vp.ScreenToImage(new BoundsD(0, 0, ActualWidth, ActualHeight));
        double vx = Math.Clamp(mini.Left + (vis.Left * sx), mini.Left, mini.Right);
        double vy = Math.Clamp(mini.Top + (vis.Top * sy), mini.Top, mini.Bottom);
        double vw = Math.Clamp(vis.Width * sx, 4.0, mini.Right - vx);
        double vh = Math.Clamp(vis.Height * sy, 4.0, mini.Bottom - vy);
        dc.DrawRectangle(null, new Pen(Brushes.Cyan, 1.5), new Rect(vx, vy, vw, vh));
    }

    }

    public bool HandleKey(Key key, ModifierKeys modifiers)
    {
        if (key == Key.Escape)
        {
            Controller.Cancel();
            Status = "작업 취소됨 (Escape)";
            return true;
        }
        if (Controller.NavigationOnly) return false;

        if (key == Key.Enter && Controller.Tool == EditorTool.DrawPolygon)
        {
            CompletePolygonCommand.Execute(null);
            return true;
        }

        double step = modifiers.HasFlag(ModifierKeys.Shift) ? 10.0 : 1.0;
        PointD delta = key switch
        {
            Key.Left  => new PointD(-step, 0.0),
            Key.Right => new PointD(+step, 0.0),
            Key.Up    => new PointD(0.0, -step),
            Key.Down  => new PointD(0.0, +step),
            _ => default
        };
        if ((delta.X != 0.0 || delta.Y != 0.0) && Controller.TryMoveSelectionBy(delta))
        {
            Status = $"방향키 미세 이동: ({delta.X:+0;-0;0}, {delta.Y:+0;-0;0}) px";
            return true;
        }

        bool ctrl = modifiers.HasFlag(ModifierKeys.Control);
        bool shift = modifiers.HasFlag(ModifierKeys.Shift);
        ICommand? cmd = (key, ctrl, shift) switch
        {
            (Key.Delete, _, _) => DeleteCommand,
            (Key.Z, true, false) => UndoCommand,
            (Key.Y, true, _) or (Key.Z, true, true) => RedoCommand,
            _ => null
        };
        if (cmd is null || !cmd.CanExecute(null)) return false;
        cmd.Execute(null);
        return true;
    }
