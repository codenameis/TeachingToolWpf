      반듯한 사각형은 Left <= x <= Right로 1초 만에 판정하지만, 35도 기울어진 타원이나 다각형은 가로·세로 부등식만으로는 판정할 수 없습니다.

      🔦 비유 2 · 손전등을 비춰 도형의 가장 튀어나온 그림자 끝 재기 (Support)

      기울어진 도형이 부모 상자 오른쪽 벽에 부딪혔는지 알려면 도형의 '가장 오른쪽 끝점'이 중심에서 몇 픽셀 떨어져 있는지 알아야 합니다.
      서포트 함수(Support(d))는 방향 d 쪽으로 도형이 중심에서 최대 몇 픽셀까지 뻗어 나가는지를 재는 '마법의 줄자'입니다.

      Step 2 · 필수 사전지식 먼저 다지기

      개념 1 · 정규화 로컬 공간 모든 도형을 [-0.5, +0.5]² 정사각형 안에 통일하기!

      가로가 200이고 세로가 80인 도형이라도, 중심을 (0, 0)으로 잡고 가로 폭 W와 세로 높이 H로 나누어 주면 가로·세로가 모두 -0.5 ~ +0.5 사이인 크기 1×1 공간으로 바뀝니다. 이를 정규화 로컬 좌표 (u, v)라고 부릅니다.

      • 사각형(Rectangle): |u| <= 0.5 이고 |v| <= 0.5
      • 원/타원(Circle): 반지름이 0.5인 원이므로 u² + v² <= 0.25 (즉, (2u)² + (2v)² <= 1)
      • 삼각형(Triangle): 위 꼭짓점 (0, -0.5), 왼쪽 아래 (-0.5, +0.5), 오른쪽 아래 (+0.5, +0.5)
      • 다각형(Polygon): 꼭짓점 배열도 모두 [-0.5, +0.5] 비율로 저장! (덕분에 다각형 크기를 늘려도 배열을 새로 만들 필요가 없습니다!)

      개념 2 · 다각형 내부 판정 반직선 교차법 (Ray Casting · 홀짝 규칙)

      별 모양이나 복잡한 다각형 안에 마우스 점 P가 들어있는지 어떻게 알 수 있을까요?
      점 P에서 오른쪽(+X 방향)으로 레이저 광선을 쭉 쏘았을 때, 다각형의 변(선분)을 몇 번 뚫고 지나가는지 세어 봅니다!

      • 변을 홀수 번(1번, 3번...) 뚫고 나가면 → 점 P는 다각형 안쪽(Inside)!
      • 변을 짝수 번(0번, 2번...) 뚫고 나가면 → 점 P는 다각형 바깥쪽(Outside)!

      개념 3 · 방향별 최대 돌출 거리 서포트 함수 h(d) = Support(direction)

      회전된 도형의 가장 오른쪽 끝(Right), 왼쪽 끝(Left), 위쪽 끝(Top), 아래쪽 끝(Bottom)을 구할 때: 

      // 중심 Center에서 각 축 방향으로 얼마나 튀어나왔는지(Support)만 더하고 빼면 회전 AABB 완성!
double ex = Support(new PointD(1, 0)); // 가로(+X) 방향 최대 돌출 반폭
double ey = Support(new PointD(0, 1)); // 세로(+Y) 방향 최대 돌출 반높이
BoundsD outer = new(Center.X - ex, Center.Y - ey, Center.X + ex, Center.Y + ey);

      개념 4 · C# 패턴 매칭 switch 식(Switch Expression)과 [^1] 인덱스

      C# 최신 문법에서는 길고 복잡한 switch-case-break 대신 깔끔한 화살표(=>) switch 식을 사용하며, 배열의 맨 마지막 원소는 points[^1]로 꺼냅니다. 

      PointD lastPoint = points[^1]; // points[points.Count - 1] 과 동일!
bool isInside = Shape switch
{
    RoiShape.Rectangle => Math.Abs(u) <= 0.5 && Math.Abs(v) <= 0.5,
    RoiShape.Circle    => (u * u) + (v * v) <= 0.25,
    _                  => ContainsPolygon(u, v)
};

      3단계 · 한 걸음씩 수식 유도하기: 로컬↔월드 변환, 서포트 함수, 선분 교차 방정식

      도형의 중심을 c = (cx, cy), 가로·세로 크기를 (W, H), 회전각을 θ라고 할 때, 로컬 정규화 점 (u, v) ∈ [−0.5, +0.5]2와 월드 이미지 점 p = (x, y) 사이의 변환 수식을 한 걸음씩 유도해 봅시다.

      공식 1 · 로컬↔월드 양방향 변환 ToWorld(u, v) 정방향 변환과 ToLocal(p) 역변환
      (식 3.1)
      ✏️ 한 걸음씩 유도하기 (01장 회전 공식의 응용):
      1) 정방향(ToWorld): 정규화 비율 (u, v)에 실제 가로·세로 크기 (W, H)를 곱하면 회전 전 로컬 픽셀 오프셋 (uW, vH)가 됩니다. 이 오프셋을 01장의 (식 1.4) 회전 공식으로 θ만큼 회전시킨 뒤 중심 좌표 (cx, cy)를 더하면 월드 이미지 좌표 (x, y)가 됩니다!
      2) 역방향(ToLocal): 반대로 마우스 클릭 점 p = (x, y)가 들어왔을 때 (u, v)를 구하려면? 방금 한 순서를 완전히 거꾸로 밟으면 됩니다!
        ① 먼저 중심을 빼서 상대 벡터 d = (x − cx, y − cy)를 구합니다.
        ② 01장 (식 1.4)의 역회전(−θ)을 적용해 도형을 반듯하게 폅니다: (dx cos θ + dy sin θ,  −dx sin θ + dy cos θ).
        ③ 마지막으로 가로 W와 세로 H로 나누면 정규화 로컬 좌표 (u, v)가 튀어나옵니다!

      공식 2 · 방향별 최대 돌출 거리 방향 벡터 d 에 대한 도형별 서포트 함수 h(d) = Support(d)
      (식 3.2)
      ✏️ 한 걸음씩 유도하기 (내적 Dot의 최대값 구하기):
      1) 도형 내부의 임의의 점 (u, v)가 월드 공간에서 중심으로부터 떨어진 벡터는 (uW, vH)를 θ만큼 회전한 벡터입니다.
      2) 이 점이 측정 방향 d = (dx, dy) 쪽으로 얼마나 멀리 나갔는지는 01장에서 배운 내적(그림자 길이)으로 계산합니다.
      3) 내적 식을 (u, v)로 묶어 정리하면 u · qx + v · qy 가 됩니다. (여기서 qx = W(dx cos θ + dy sin θ), qy = H(−dx sin θ + dy cos θ)).
      4) 이제 도형 안에서 u · qx + v · qy 가 언제 최대가 되는지 찾으면 됩니다:
        • 사각형 (u, v ∈ [−0.5, +0.5]): u와 v가 각각 ±0.5 부호를 맞출 때 최대이므로 0.5 × (|qx| + |qy|)!
        • 원/타원 (u2 + v2 ≤ 0.25): 벡터 (qx, qy) 방향으로 반지름 0.5만큼 갈 때 최대이므로 피타고라스 정리에 의해 0.5 × √(qx2 + qy2)!
        • 삼각형·폴리곤: 볼록한 끝점은 항상 꼭짓점 중 하나이므로 꼭짓점들의 max(u_i * qx + v_i * qy)를 구하면 끝!
      로컬 축 투영 벡터 q = (qx, qy) qx = W · (dx cos θ + dy sin θ), qy = H · (−dx sin θ + dy cos θ)
      사각형h(d) = 12 (|qx| + |qy|) 원/타원h(d) = 12 √qx2 + qy2 폴리곤h(d) = maxi (ui qx + vi qy)

      공식 3 · 두 선분 교차 방정식 2D 외적(Cross)을 이용한 두 선분 AB 와 CD 의 교점 비율 t, u 계산
      (식 3.3)
      ✏️ 한 걸음씩 유도하기 (외적으로 미지수 소거하기):
      1) 선분 AB 위의 점은 비율 t ∈ [0, 1]을 써서 a + tr (단, r = b − a)로 쓸 수 있고, 선분 CD 위의 점은 비율 u ∈ [0, 1]을 써서 c + us (단, s = d − c)로 쓸 수 있습니다.
      2) 두 선분이 만나는 교점에서는 두 식이 같아야 하므로 a + tr = c + us 입니다.
      3) 여기서 u를 한 방에 없애는 마법: 자기 자신과의 외적은 0(s × s = 0)이라는 성질을 이용해 양변에 s를 외적(×)합니다!
      4) 그러면 우변의 u(s × s)가 0으로 사라지고, t(r × s) = (c − a) × s 만 남아서 t = ((c − a) × s) / (r × s) 가 바로 구해집니다!
      선분 1P(t) = a + t · r  (r = b − a), 선분 2Q(u) = c + u · s  (s = d − c)
      t = (c − a) × sr × s, u = (c − a) × rr × s (단, r × s ≠ 0 이고 0 ≤ t ≤ 1,  0 ≤ u ≤ 1 일 때 교차)

      c, d 및 s 이미 그려진 다각형의 i번째 변의 양 끝점 및 방향 벡터 가로·세로 숫자 쌍 (X, Y) (Image px) edgeStart, edgeEnd

      🔢 고1 학생도 3초 만에 이해하는 실제 숫자 대입 예제
      초간단 숫자 대입: 가로 선분 A(0, 5) → B(10, 5)와 세로 선분 C(5, 0) → D(5, 10)이 십자(+)로 만나는 경우:
      • r = (10, 0), s = (0, 10) 이므로 분모 외적 r × s = 10 × 10 − 0 = 100 입니다.
      • c − a = (5, −5) 이므로 t = ((5, −5) × (0, 10)) ÷ 100 = 50 ÷ 100 = 0.5, u = 0.5 가 나와서 두 선분의 정중앙(50% 지점 (5, 5))에서 정확히 교차함을 찾아냅니다!

      src/VisionGeometry/RoiGeometry.cs src/VisionGeometry/RoiShape.cs 
      using System;
using System.Collections.Immutable;
using VisionGeometry;

namespace VisionCanvas.Core.Geometry;

public enum RoiShape { Rectangle, Circle, Triangle, Polygon }

public readonly record struct RoiGeometry(
    RoiShape Shape,
    double X,
    double Y,
    double Width,
    double Height,
    double RotationRadians = 0.0,
    ImmutableArray<PointD> PolygonVertices = default)
{
    public PointD Center => new(X + (Width * 0.5), Y + (Height * 0.5));

    // (식 3.1) 정방향: 정규화 로컬 좌표 (u, v) in [-0.5, +0.5]^2 → 월드 이미지 좌표
    public PointD ToWorld(double u, double v)
    {
        PointD offset = new PointD(u * Width, v * Height).Rotate(RotationRadians);
        return Center + offset;
    }

    // (식 3.1) 역방향: 월드 이미지 좌표 p → 정규화 로컬 좌표 (u, v)
    public PointD ToLocal(PointD worldPoint)
    {
        PointD unrotated = (worldPoint - Center).InverseRotate(RotationRadians);
        return new PointD(
            unrotated.X / Math.Max(1e-6, Width),
            unrotated.Y / Math.Max(1e-6, Height));
    }

    // 마우스 점 p가 회전된 도형 내부에 들어왔는지 판정합니다.
    public bool Contains(PointD worldPoint)
    {
        PointD local = ToLocal(worldPoint);
        return Shape switch
        {
            RoiShape.Rectangle => Math.Abs(local.X) <= 0.5 && Math.Abs(local.Y) <= 0.5,
            RoiShape.Circle    => (local.X * local.X) + (local.Y * local.Y) <= 0.25,
            RoiShape.Triangle  => local.Y >= -0.5 && local.Y <= 0.5
                                  && Math.Abs(local.X) <= (local.Y + 0.5) * 0.5,
            RoiShape.Polygon   => ContainsNormalizedPolygon(local),
            _                  => false
        };
    }

    // (식 3.2) 중심 Center에서 월드 방향 d 쪽으로 도형이 가장 멀리 뻗은 거리(Support)를 반환합니다.
    public double Support(PointD direction)
    {
        PointD localDir = direction.InverseRotate(RotationRadians);
        double qx = Width * localDir.X;
        double qy = Height * localDir.Y;

        return Shape switch
        {
            RoiShape.Rectangle => 0.5 * (Math.Abs(qx) + Math.Abs(qy)),
            RoiShape.Circle    => 0.5 * Math.Sqrt((qx * qx) + (qy * qy)),
            RoiShape.Triangle  => Math.Max(-0.5 * qy, (0.5 * Math.Abs(qx)) + (0.5 * qy)),
            RoiShape.Polygon   => SupportPolygon(qx, qy),
            _                  => 0.0
        };
    }

    // Support 함수를 이용해 회전된 도형의 바깥 축 정렬 경계 상자(AABB)를 단 2줄로 구합니다!
    public BoundsD OuterBounds
    {
        get
        {
            double ex = Support(new PointD(1.0, 0.0));
            double ey = Support(new PointD(0.0, 1.0));
            PointD c = Center;
            return new BoundsD(c.X - ex, c.Y - ey, c.X + ex, c.Y + ey);
        }
    }

    // 다각형 내부 판정 (반직선 교차 홀짝 규칙 — Ray Casting)
    private bool ContainsNormalizedPolygon(PointD p)
    {
        if (PolygonVertices.IsDefaultOrEmpty || PolygonVertices.Length < 3) return false;
        bool inside = false;
        for (int i = 0, j = PolygonVertices.Length - 1; i < PolygonVertices.Length; j = i++)
        {
            PointD a = PolygonVertices[i];
            PointD b = PolygonVertices[j];
            if (((a.Y > p.Y) != (b.Y > p.Y)) &&
                (p.X < ((b.X - a.X) * (p.Y - a.Y) / (b.Y - a.Y)) + a.X))
            {
                inside = !inside;
            }
        }
        return inside;
    }

    private double SupportPolygon(double qx, double qy)
    {
        if (PolygonVertices.IsDefaultOrEmpty) return 0.0;
        double maxProj = 0.0;
        foreach (PointD v in PolygonVertices)
        {
            maxProj = Math.Max(maxProj, (v.X * qx) + (v.Y * qy));
        }
        return maxProj;
    }
}

      PolygonClosure.Find(IReadOnlyList<PointD> points, PointD candidateEnd, double snapRadius)
      Step 1 FindFirstIntersection() 마지막 꼭짓점에서 candidateEnd로 긋는 선분과 가장 먼저 만나는 기존 변을 찾습니다.
      Step 2 TryIntersectEdge() (식 3.3)의 외적(r × s)으로 선분 교차 비율 t, u ∈ [0, 1]을 계산합니다.
      Step 3 SnapToEndpoint() 교차점이 기존 꼭짓점에서 snapRadius 이내면 꼭짓점 좌표로 자석처럼 스냅합니다.
      Step 4 BuildClosedLoop() 교차된 변부터 마지막 점까지를 이어 넓이가 있는 유한한 폐다각형 꼭짓점 리스트를 반환합니다.

      public static PolygonClosureHit? Find(
    IReadOnlyList<PointD> points,
    PointD candidateEnd,
    double snapRadius = 0.0)
{
    // Guard Clause: 점이 3개 미만이면 다각형 루프를 만들 수 없음
    if (points.Count < 3)
    {
        return null;
    }

    var start = points[^1];
    if (start.DistanceTo(candidateEnd) <= Epsilon)
    {
        return null;
    }

    // Step 1: 가장 먼저 교차하는 기존 변 탐색
    if (FindFirstIntersection(points, start, candidateEnd) is not { } hit)
    {
        return null;
    }

    // Step 3 & 4: 끝점 스냅 후 닫힌 다각형 루프 조립
    var intersection = SnapToEndpoint(points, hit.EdgeIndex, hit.Point, snapRadius);
    var loop = BuildClosedLoop(points, hit.EdgeIndex, intersection);
    return loop is null ? null : new PolygonClosureHit(hit.EdgeIndex, intersection, loop);
}

// Step 2: (식 3.3) 2D 외적을 이용한 두 선분 교차 판정
private static bool TryIntersectEdge(
    PointD a, PointD b, PointD c, PointD d,
    out double t, out PointD intersection)
{
    PointD r = b - a;
    PointD s = d - c;
    double rxs = r.Cross(s);
    if (Math.Abs(rxs) <= Epsilon)
    {
        t = 0; intersection = default; return false;
    }

    PointD cma = c - a;
    t = cma.Cross(s) / rxs;
    double u = cma.Cross(r) / rxs;
    intersection = a + (r * t);
    return t >= 0.0 && t <= 1.0 && u >= 0.0 && u <= 1.0;
}
      핵심 코드 구문 무슨 역할을 하며 왜 이렇게 작성했을까요?
      ToLocal(worldPoint) (식 3.1)의 역변환입니다. 마우스 점에서 중심을 빼고 InverseRotate로 역회전한 뒤 Width, Height로 나누어 모든 도형을 [-0.5, +0.5]² 공간으로 데려옵니다.
      (local.X * local.X) + (local.Y * local.Y) <= 0.25 가로·세로 비율이 다른 타원이라도 정규화 공간에서는 반지름 0.5인 완벽한 원이 되므로, u² + v² <= 0.5²(= 0.25) 한 줄로 타원 내부 판정이 끝납니다!
      Support(new PointD(1.0, 0.0)) (식 3.2)를 이용해 회전된 도형이 가로(+X)와 세로(+Y) 방향으로 중심에서 최대 몇 픽셀까지 뻗어 있는지 구해 바깥 경계 상자(OuterBounds)를 만듭니다.
      inside = !inside; 다각형 내부 판정(Ray Casting)에서 점 오른쪽으로 쏜 반직선이 다각형 변을 지날 때마다 false ↔ true를 뒤집어 홀수 번 교차하면 true를 반환합니다.
      double rxs = r.Cross(s); (식 3.3)의 분모 r × s 입니다. 이 값이 0에 가까우면 두 선분이 서로 평행하여 교차하지 않는다는 뜻이므로 즉시 false를 반환합니다.
      t >= 0.0 && t <= 1.0 && u >= 0.0 && u <= 1.0 직선의 연장선이 허공에서 만나는 경우가 아니라, 실제로 그려진 두 선분의 시작점(0.0)과 끝점(1.0) 사이에서 만났을 때만 교차(true)로 인정합니다.

{
    var local = owner.ToLocal(world);

      💡 왜 Support(끝점 길이) 함수를 쓰면 최적화가 될까요?
      기울어진 원이나 사각형이 부모 상자 밖으로 나갔는지 검사할 때, 원을 수백 개 점으로 쪼개서 검사하면 엄청 느립니다. Support 공식을 쓰면 사칙연산 단 한 줄(O(1))로 가장 멀리 튀어나온 끝점을 즉시 구할 수 있습니다!
