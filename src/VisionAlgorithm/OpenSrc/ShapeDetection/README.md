# 일반 도형 검출

학습 없이 이진화된 외곽 윤곽으로 삼각형·직각 사각형·원·대칭 십자가를 분류한다. 기존 OpenCvSharp의 Otsu/threshold/contour/approximation 연산을 내부 어댑터로 호출하고, C#의 꼭짓점·직각·대칭·반경/면적 규칙으로 판정한다. 특정 상용 도형 검사기의 포팅이나 딥러닝 모델이 아니다.

`PrimitiveShapeDetector.Detect`는 최대2Mpx Gray8 창을 받으며 원본 좌표의 닫힌 윤곽을 반환한다. 공개 계약에 Mat이 없다. 큰 이미지 분할·원본 읽기·ROI 포함·취소/세대 검사는 앱 서비스 책임이다. 알고리즘 호출에 표시 LOD나 화면 캡처를 넣지 않는다.

채워지고 분리된 도형이 대상이다. 테두리만 있는 도형·붙은 도형·부분 가림은 지원하지 않는다. 검출 점수는 종류별 형상 적합도이며 확률이 아니다. 크기·극성·문턱·윤곽 근사·도형 종류·최소점수·출력 한도를 옵션으로 지정한다. 이미지 경계 잘림과 내부 윤곽/출력 한도는 결과에 별도 표시한다. 계약·검증 한계는 [ADR-022](../../../../docs/decisions/0022-inspection-scoring-execution-and-primitives.md) 참조.
