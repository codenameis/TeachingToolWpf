# 8K 핀 위치 회귀 픽셀

기존 `ProceduralTileSource(2048, 2048).ReadOriginalGray8`에서 추출한 Gray8 행 우선 원본이다. 헤더나 압축 없이 파일 이름의 너비×높이 바이트를 저장한다. 8K 샘플은 이 모듈이 반복된다.

- 학습: 중심(759.518, 546.178),106×129 ROI를 앱과 같은 픽셀 중심 규칙으로 추출한 `pin-template-106x129.gray`.
- `pin-crossing-256x256.gray`: 원본의(1344,416)부터256×256. 라이브러리 정답 중심(135.018,129.678),각도0°.
- `pin-lower-256x256.gray`: 원본의(448,1328)부터256×256. 라이브러리 정답 중심(131.018,127.678),각도0°.
- `pin-upper-256x256.gray`: 원본의(448,416)부터256×256. 라이브러리 정답 중심(131.018,129.678),각도0°.

라이브러리는 픽셀 인덱스, 앱은 픽셀 중심 좌표이므로 앱 좌표에서0.5를 뺀다. 정답은 생성기의 알려진 위치와 학습 ROI의 상대 위치로 정하며 검출 결과에서 만들지 않았다. 수정 전 두 경우는 각각29.822/30.072px 어긋났다. 축소 원판 표본의 높은 가짜 봉우리로 정상 후보를 먼저 억제하지 않아야 한다.
