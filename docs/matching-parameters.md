# 매칭 방식과 사용자 파라미터

2026-10-04 후속: 두 커스텀 형상의 표시 점수는 `방향 점수 × (1 − 감점 비중 × 추가 윤곽 대비 비율)`이다. 대비 비율은 에지 강도의 제곱으로 가중한 `ClutterEnergyRatio`이며, 기본 감점 비중은1이다. 결과의 **추가 윤곽 감점(대비)**와 **개수**는 서로 다른 값이다. OpenCV NCC는 그대로다. 점수는 불량 확률이나 전체 형상·픽셀 동일성을 뜻하지 않는다.

GPU의 이득은 영상·모델·장치에 따라 달라진다. 이전 DX12/CUDA 전처리 측정은 교체 전 기록이다. 현재 후보 점수 실행 정책은 [ADR-026](decisions/0026-8k-shape-search-latency.md), 검증 상태는 [작업 목록](../tasks/todo.md)을 따른다. 최초 CUDA 장치·커널 준비 시간은 검사와 별도로 표시하며 장치는 앱 세션에서 재사용한다. 후보 예산을 초과하면 우선 검증할 위치·자세를 분산하지만 생략 후보가 존재한다는 경고를 유지한다. 예산 확대도 모든 입력의 완전한 검출을 보장하지 않는다.

각 방식은 별도의 모델과 설정을 보관한다. 처음 선택한 방식에는 ROI 하나로 학습해야 한다. 다른 방식으로 갔다 돌아오면 해당 모델과 설정이 복원된다. 이미지를 바꿔도 모델은 남지만 결과는 지워진다. 앱을 종료한 뒤 보존하는 저장 기능은 아직 없다.

최소 점수와 각도·배율·허용비율 등은 소수점으로 입력할 수 있다. `0` → `0.` → `0.7` → `0.72`처럼 한 글자씩 입력해도 소수점과 후행0을 유지하며, 유효한 숫자는 즉시 설정에 반영된다. 같은 입력 방식은 일반 도형 검출의 숫자 필드에도 적용된다. 빈칸·잘못된 문자열은 입력 오류로, NaN·무한대·허용 범위 밖 값은 설정 오류로 실행을 막는다. 패턴 방식을 바꾸면 잘못 입력한 문자열은 선택한 방식의 저장된 숫자로 복원한다.

|---|---|
| OpenCV · 템플릿 매칭 | CCOEFF_NORMED 명암 상관. 학습 당시 각도·크기를 유지한 위치 검색. 회전/배율을 새로 측정하지 않음 |

## 추가 윤곽의 대비 감점과 개수 비율

작은 논문 모델은 모델 요약에 `원본 세부 획 검증`이 표시될 때 세부 설명 에너지 `D`를 추가 사용한다. 기존 최종 점수에 `(1 − 비중 × (1−D))`를 곱하며 비중 0은 이 감점도 끈다. 결과에 세부 일치도를 따로 표시한다. 한 단계만 남고 마스크 안 유효 gradient stencil이4096개 이하인 모델에 적용하며 OpenCV는 기존 정책이다. 변경 실행본에서 재학습해야 한다. [범위·실측](kensa-text-and-logs-validation.md).

대비 감점 비율은 `Σ(설명되지 않은 장면 에지 강도²) / Σ(학습 마스크 안 전체 장면 에지 강도²)`다. 위치·방향이 학습 윤곽과 대응하는지 확인하고, 조명 변화로 인한 강도 차이를 보정한 뒤 장면 에지가 학습 윤곽보다2배를 넘게 강하지 않아야 대비까지 설명된 것으로 본다. 따라서 약한 텍스처·잡음과 강한 추가 윤곽의 감점 영향이 다르다. 학습 영역 밖 에지는 계산하지 않는다.

조명 보정 배율은 강한 학습 윤곽 중 최대128개에서 위치·방향이 대응하는 장면 에지를 찾고, `장면 강도 / 학습 강도`의 중앙값으로 정한다. 대응이 없으면 배율1을 사용한다. 추가 결함 하나의 최대 강도를 조명 배율로 삼지 않으므로 강한 결함이 단순 조명 변화로 흡수되지 않도록 한다. 이 보정과2배 허용은 내부 규칙이며 별도 사용자 파라미터는 아니다.

**개수**로 표시하는 `ClutterRatio`는 전체 학습 윤곽으로 위치·방향을 설명할 수 없는 장면 에지의 개수 비율이다. 이 기존 정의는 유지하며 대비 에너지 조건을 추가하지 않는다. 최종 점수의 대비 감점과 별도로 작동하므로 두 값을 같은 기준으로 해석하지 않는다.

피라미드는 원본 ROI 크기에 따라 자동 조정하고 모델 요약에 실제 단계 수를 표시한다. 큰 학습 ROI에도 임의 단계 값을 강제로 적용하는 옵션은 제공하지 않는다.

**낮은 대비의 실제 세부까지 검사해야 하면 특징 최소 대비 비율을0으로 설정한 뒤 다시 학습하고, 해당 세부가 빠진 실제 샘플로 판정 기준을 확인한다.** 기본값.2는 강한 외곽에 비해 약한 텍스처를 방향 특징 후보에서 제외한다. 예를 들어 밝기255의 강한 사각형과 밝기35의 약한 E를 함께 학습하면 E가 방향 특징에서 빠져, 검사 이미지에 E가 없어도 점수1이 나올 수 있다. 전체 학습 윤곽을 보존하더라도 이 누락을 자동으로 완전한 형상 비교처럼 판정하지는 않는다.

값0은 최소 명암 경사를 통과한 기존 에지를 모두 **후보**에 포함한다는 의미다. 실제 방향 특징 선택에는 최대 특징 수와 공간 분산 규칙이 계속 적용된다. 선택한 특징의 검출비율과 추가 윤곽 감점은 각각 누락과 추가 형태를 일부 평가하며, 모든 세부의 존재·치수·동일성을 보장하는 검사는 아니다.

## 회전 불량 검사 (2026-10-05)

논문 방식의 **회전 불량 검사**를 켠 뒤 같은 ROI로 다시 학습하세요. 전체 방향에서 위치·각도를 찾고, **정상 최소/최대 편차**를 벗어난 검출을 빨간색NG로 표시합니다. 각도는 학습 ROI 방향을 기준으로 합니다. 탐색 각도와 정상 허용각은 다른 조건입니다. 초기 정상 범위는0~10°이며, 양방향10°를 허용하려면-10~10°로 입력합니다. 0~10°에서는-0.02°도 범위 밖입니다.

회전 검사 기본은 꺼짐입니다. 켜거나 끄면 재학습이 필요하지만 정상 허용각만 바꾸면 재검사하면 됩니다. 끈 상태에서 좁은 각도로 검색하면 대칭 부분이 뒤집힌 대상에0°로 맞을 수 있습니다. 점수만으로 방향 합격을 판단하지 마세요. ROI 자체가 대칭이면 방향 단서를 포함하도록 티칭해야 합니다. 후보/출력 잘림은 경고, 회전 관측 불가는사용자 확인으로 유지합니다. [상세 계약](decisions/0030-rotation-inspection-acceptance.md).
