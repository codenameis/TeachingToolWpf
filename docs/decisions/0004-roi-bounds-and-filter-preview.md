# ADR-004 — 이미지별 ROI, 경계 제한과 OpenCV 미리보기

2026-10-02. 사용자가 이미지 교체 시 ROI 초기화, 경계 안 생성, Figma/Fluent 느낌의 선택 표시, Binarize/Edge 미리보기와 선택 변경 시 자동 갱신을 요청했다.

같은 날 추가 요청으로 필터 세션의 전역 설정/선택 해제 정책은 [ADR-005](0005-filter-registration-and-roi-copy.md)의 ROI별 등록·재선택 자동 표시 계약으로 대체했다. 아래 기하·처리 예산·원본 보존 계약은 유지한다.

## 동작 계약

- 이미지 준비가 성공한 뒤 소스를 교체하고 ROI/선택을 비운다. 같은 파일 열기와 라이브 시작도 포함한다. 파일 읽기 실패는 기존 라이브까지 보존한다. 한 번의 Undo는 이전 이미지, ROI, 선택, 뷰를 복원한다.
- 생성은 축 정렬 드래그와 이미지의 교집합이다. 교집합이 없는 드래그는 아무것도 생성하지 않는다. 모든 편집 진입점은 `RoiImageBounds`/`RoiTransforms`의 같은 제약을 따른다. 요청 변형이 경계를 넘으면 공통 보간 비율로 제한해 다중 선택/자손을 일관되게 움직인다. 0도 초기화는 정확히 0도로 만든 뒤 필요한 경우 선택/자손 전체를 함께 이동·균일 축소해 이미지 안에 맞춘다. 이 보정까지 하나의 Undo 대상이다.
- 새 그룹은 이미지 경계로 여백을 제한하고 실제 포함 관계를 다시 검사한다. 완전히 일치하는 부모/자식 금지 규칙은 유지한다.
- 선택은 파란 1.5 DIP 윤곽, 흰 6 DIP 사각 핸들, 원형 회전 핸들이다. 두꺼운 검은 테두리·청록색 면 채색을 제거한다. WPF 오버레이 대신 DX12 장면 안에 렌더한다.
- 필터 선택만으로 원본을 바꾸지 않는다. 미리보기 버튼으로 활성화한 뒤 선택/형상/설정 변경에 갱신하고, 원본 보기/없음/소스 변경 시 결과를 제거한다. 선택 해제 중에도 활성 세션을 유지해 다음 선택을 처리한다.

## 책임과 수명

`FilterPreviewViewModel`은 UI 상태와 최신 요청 교체를 담당한다. `IRoiFilterPreview`는 취소 가능한 비파괴 처리 계약이다. `RoiFilterPreview`는 작업 스레드에서 타일 소스 또는 보유한 최신 프레임 lease를 읽는다. `RoiPixelExtractor`는 회전 ROI의 픽셀 중심 좌표를 역매핑한다. `OpenCvRoiFilter`가 OpenCV 타입을 격리하며 네이티브 Mat를 해제한다. `GpuFilterPreview`는 결과 texture만 소유하고 교체 시 fence 이후 폐기한다.

작업은 한 번에 하나, 대기 요청은 최신 하나다. 짧은 100ms 지연으로 연속 선택/드래그를 합친다. 취소할 수 없는 네이티브 호출이 끝나도 요청 버전이 다르면 게시하지 않는다. 결과 픽셀은 게시 후 변경하지 않는다. 원본 이미지·ROI 편집 이력은 필터 계산에 의해 수정하지 않는다.

정적 파일은 이미 준비된 디스크 피라미드를 별도 읽기 소스로 열어 타일 작업자의 소유권과 충돌하지 않는다. ROI 긴 축 최대 1024px, 전체 출력 약 4Mpx로 제한한다. 라이브는 프레임 참조를 보유한 동안만 읽고 최대 5회/초 갱신한다. 이것은 시각적 미리보기이며 전해상도 계측이나 8K 60FPS OpenCV 처리 보장이 아니다. Gray16은 고정 범위 0–65535를 Gray8로 변환한다.

라이브 소스의 크기/종류도 이미지 참조에 저장한다. 라이브로 이력을 복원하면 해당 합성 소스를 재시작하며 과거 영상 프레임은 저장하지 않는다. 최초 프레임 전에는 검은 대기 표면을 사용한다.

## 의존성 근거

OpenCvSharp4 및 `OpenCvSharp4.runtime.win.slim` **4.13.0.20260627**을 고정했다. Windows x64 slim의 imgproc가 필요한 Threshold/Canny/WarpAffine를 포함한다. 별도 OpenCV 창·영상 파일 수집 모듈은 사용하지 않는다. 공식 배포 패키지와 [OpenCvSharp 저장소](https://github.com/shimat/opencvsharp), [OpenCV Threshold](https://docs.opencv.org/4.13.0/d7/d1b/group__imgproc__misc.html), [영상 좌표 변환](https://docs.opencv.org/4.13.0/da/d54/group__imgproc__transform.html)을 기준으로 구현했다. 라이선스 원문은 `licenses`에 포함한다.

기존 SOLID/GRASP 원칙을 완화하는 성능 예외는 없다. 구체적 검토와 실제 동작 근거는 [품질 검토](../quality-review.md), [런타임 검증](../runtime-validation.md)을 따른다.
