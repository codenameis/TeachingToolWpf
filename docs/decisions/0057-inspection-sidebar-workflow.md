# ADR-057: 검사 패널을 작업별 탭으로 분리

- 날짜: 2026-10-16
- 상태: 적용
- 근거: 사용자가 오른쪽 패널의 긴 스크롤과 불명확한 WARN 표시 개선을 요청했다.

오른쪽 패널을 검사/영역/필터로 나눈다. 패턴 검사는 기본/상세 설정/결과/로그를 사용하고, 실행·취소와 현재 상태는 스크롤 밖 하단에 고정한다. 기본 작업은 학습 ROI, 검색 범위, 점수·결과 수, CPU 검색 각도에 집중한다. 기존 설정과 바인딩을 유지하며 상세 설정은 필요할 때 펼친다. 패널 폭은 기본360 DIP, 조절 범위320~560 DIP다.

Warning/Review는 제품 불량과 구별한다. 제목에는 상태를, 안내에는 원인과 조치할 설정 위치를 표시한다. 판정 정책·점수·검색 예산·검출 알고리즘은 바꾸지 않는다. 모든 방식의 결과 행은 같은 가상화 목록에 표시한다. OpenCV의 별도 단계별 JSON 로그 부재도 명시한다.

표시 문구와 상태는 기존 ViewModel, 레이아웃과 WPF Validation 수명은 View가 맡는다. 탭 전환으로 View가 Unloaded되어도 잘못된 숫자 초안의 실행 차단을 유지한다. 다른 DataContext로 교체할 때는 이전 연결을 해제한다. 새 서비스나 도메인 계층은 추가하지 않는다.
