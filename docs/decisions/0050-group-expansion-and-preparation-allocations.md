# ADR-050 기존 그룹 확장과 변환 준비 할당

날짜: 2026-10-15. 상태: 사용자 동작 결정 승인, 로컬 구현·검증.

## 동작

기존 ROI 그룹 하나와 부모 없는 ROI를 그룹화하면 기존 부모의 테두리를 확장한다. 새 ROI나 생성 번호를 만들지 않고 기존 자식과 편입 ROI의 위치·형상을 유지한다. 명시적 부모 편입도 같은 규칙이다. 사용자 답변에 따라 원·삼각형·오목 다각형 부모도 필요한 경우 사각형으로 확장할 수 있다. 이미 포함하면 원래 도형을 유지한다.

부모의 기존 각도를 유지하는 좌표계에서 각 도형의 지지점을 계산하여 사각형을 만든다. 이 사각형이 상위 모듈·루트의 실제 도형 또는 이미지 경계를 넘으면 전체 작업을 거부한다. 상위 그룹은 확장하지 않는다. 거부 시 형상·소속·선택·생성 번호·Undo/Redo를 변경하지 않는다. 성공 시 부모 형상과 자식 소속 변경을 하나의 기존 DocumentEdit에 기록한다.

최대4단계, 부모가 있는 ROI 재편입 금지, 그룹 자체의 외부 편입 금지, 다수 부모의 상위 그룹 생성 규칙은 유지한다. ADR-048의 외부 리프 편입 시 부모 형상을 유지한다는 동작은 이번 결정으로 대체한다. 이전 문서에 이미 밖으로 나간 리프를 조용히 이동시키지는 않는다.

## 성능 접근

이전 69.7ms 프레임은 첫 변환 준비를 기다리는 동안 장면이 갱신되지 않은 구간이었다. 해당 프레임의 렌더 CPU는2.27ms, 첫 preview까지88.63ms였다. 이전25.61ms 회전 확정 프레임은 GC 정지9.219ms와 겹쳤다. 해당 프레임은 ROI 패킹0ms, DXGI 준비 대기24.90ms, 렌더 CPU25.16ms였다. 대기 시간 전체를 GPU 계산으로 해석하지 않는다.

수집한 .NET 스택은 변환 준비 중 고정 ROI를 찾는 전체 불변 사전 순회와 확정 시 자료 생성 비용을 보여 준다. 기존 BVH에서 고정 부분을 추출하고, 자식 수를 이용해 작업용 집합·큐 용량을 확보한다. 이력 차이 배열은 후보 수로 용량을 정하고 꽉 찬 버퍼의 소유권을 이전한다. 전체 BVH 경계를 갱신할 때 사용하지 않는 개별 변경 목록도 만들지 않는다.

기존 불변 스냅샷, 정확한 공간 질의, 변경 전후 이력, 렌더 fence·Present(1), 준비 취소 계약을 유지한다. 미리 준비해서 최초 비용을 측정 밖으로 숨기거나 GC를 강제로 끄지 않는다. 새 캐시·의존성·공개 서비스 계약을 도입하지 않는다. [검증과 한계](../group-expansion-validation.md).

## 원칙 검토

| 원칙 | 적용 |
|---|---|
| SRP | Geometry는 확장 계산, GroupEditor는 계층/이미지 검증, DocumentEdit는 이력, BVH는 질의를 맡는다. |
| OCP | 기존 도형의 Support 계약으로 처리하며 도형별 앱 분기를 추가하지 않는다. |
| LSP | 동기/준비 편집의 거부 원자성·성공 결과·이력을 동일하게 검증한다. |
| ISP | 입력·렌더·서비스 인터페이스를 늘리지 않는다. |
| DIP | Geometry/Core는 WPF·DX12를 참조하지 않는다. |
| Information Expert | 도형의 지지점은 기하, 상위 관계는 그룹 편집 책임에 둔다. |
| Creator | 새 ROI를 만들지 않으며 문서가 기존 객체의 불변 새 값을 생성한다. |
| Controller | VM 명령이 기존 EditorSession 편입 경로를 사용한다. |
| Low Coupling | 기존 경계 안에서 동작과 자료 용량만 바꾼다. |
| High Cohesion | 관련 없는 MVVM·검사 코드 변경을 섞지 않는다. |
| Polymorphism | 기존 도형의 Support와 입력 계약을 그대로 사용한다. |
| Pure Fabrication | 기존 이력/BVH의 버퍼 소유권을 유지한다. |
| Indirection | 앱·VM·편집·기하 사이에 새 중계 계층을 만들지 않는다. |
| Protected Variations | 표시 장치와 검사 구현은 이 규칙에 의존하지 않는다. |

설계 원칙 예외 없음. 읽을 수 있는 기존 자료 구조와 분기를 유지한다.
