# ADR-051 — 독립 C# PoseMatch-TDCM과 ONNX

상태: 2026-10-15 사용자 구현 승인.

사용자는 별도 프로젝트, VisionAlgorithm의 프로젝트 참조, 실제 앱 사용, 파라미터 노출, 큰 학습 크기를 포함한 벤치마크와 필요 시 ONNX 사용을 요청했다. 이전 딥러닝 금지와 충돌하는 부분은 이번 명시적 요청을 우선한다. 자체 기하 삭제와 기존 논문 형상/OpenCV 유지 결정은 바뀌지 않는다.

`PoseMatch.Tdcm`은 .NET10, ONNX Runtime CPU1.24.4와 포함된 공식 가중치만 의존한다. WPF/Canvas/영상 파일 로더를 참조하지 않는다. VisionAlgorithm의 Gray8 어댑터가 ProjectReference로 연결한다. VisionInspection이 원본 읽기·회전 ROI 정규화·축소·타일 소유권·전역 중복 제거를 담당한다. App이 서비스 생성/주입, VM이 독립 모델/설정/취소/결과, View가 바인딩을 담당한다.

공식 모델은36×36 템플릿과18~72px 대상 범위를 전제로 한다. 큰 입력을 무조건 큰 신경망 커널로 바꾸면 가중치의 학습 조건과 달라진다. 따라서 원본18~2048px ROI를36×36으로 정규화하고 검색 원본을 면적 평균으로 축소한다. 큰 ROI의 세부가 보존되는 방법이나 원본 정밀 검사라고 표현하지 않는다. 축소는 최대32배, 사각형 비율은1:2~2:1로 제한한다. 마스크/비사각 학습은 명시적 오류다.

공식 공개 모델의 다섯 출력은 PyTorch와 ONNX/C# 간 수치 대조한다. 공식 단일 argmax를 여러 국소 극대점과 예산 제한/중복 제거로 확장한다. 텐서 출력과 달리 다중 검색/타일 결과는 원 구현과 동등하다고 주장하지 않는다. 명암 자세 보정은 같은 코사인 목적함수의 C# bilinear 탐색이며 OpenCV warp/bisection의 비트 단위 복제는 아니다.

ONNX 네이티브 세션은 검사 worker에서 생성하고 using으로 종료한다. 준비 비용을 검사 시간에서 숨기지 않는다. 스레드/창 크기는 사용자 설정으로 제공하고 작업당 세션이므로 검사 종료 후 네이티브 메모리가 남지 않는다. 취소는 RunOptions.Terminate와 타일/후처리 토큰 검사로 전달한다. 예산 초과는 경고이며 신경망 신뢰도로 제품 OK/NG를 단정하지 않는다.

원칙 예외 없음. SRP: 추론/자세 해독/원본 I/O/UI 분리. OCP: 기존 두 알고리즘 수정 없이 독립 모드 연결. LSP: 서비스의 취소/소유권 보존, 미지원 입력 오류. ISP: 학습/검색 두 메서드만. DIP: VM은 서비스 계약에 의존한다. GRASP Information Expert는 자세 해독/영상 좌표 각 소유자, Creator는 App/worker, Controller는 VM, Low Coupling은 중립 픽셀·pose, High Cohesion은 알고리즘 프로젝트, Polymorphism은 검사 서비스, Pure Fabrication은 ONNX 세션, Indirection은 Gray8 어댑터, Protected Variations는 네이티브 런타임의 라이브러리 내부 격리로 확인했다. 편집 이력/그룹 규칙은 이번 변경 대상이 아니다.

재현·성능 한계는 [검증 문서](../posematch-tdcm.md)를 따른다. CPU125ms/CUDA80ms 목표 달성으로 표시하지 않는다.

## 2026-10-15 CUDA 전체 탐색 후속

사용자는 CUDA 구현/RTX3060 실측을 요청했고, 혼합 후보 검색 제안에 대해 **PoseMatch 전체 탐색 유지**를 확정했다. 위 CPU 전용/작업당 세션 종료 설명을 대체한다. ORT GPU1.24.4의 CPU/CUDA 명시 선택, 서비스 소유 세션 재사용, 실행 종료 후 안전한 해제, FP32 head 결합, 원본 Gray8 직접 읽기 및 정규화 중복 계산 제거를 적용한다. 입력 영상/검색 결과의 검사 간 재사용은 없다. 최초 세션/커널 준비도 명령 시간에 포함한다. 검출 신뢰도와 정밀 품질은 구별하고 FP16 정확도 손실 실험은 배포하지 않는다. [CUDA 검증·원칙 검토](../posematch-tdcm-cuda.md)의 FAIL/미검증 범위를 유지한다. 로컬 수정·검증만 승인, 커밋·푸시 없음.
