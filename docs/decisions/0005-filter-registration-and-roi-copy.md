# ADR-005 — ROI별 필터 등록과 복사·붙여넣기

2026-10-02. 사용자 요청에 따라 등록된 ROI 선택 시 필터 자동 표시, 복사·붙여넣기/단축키/Del 및 이미지 반복 교체 검증을 추가했다. 승인된 설계 원칙 예외는 없다.

## 필터와 이력

- ROI가 `FilterSettings` 불변 값(종류, 임계값)을 가진다. Core에는 숫자/열거형만 두고 OpenCV 구현은 기존 영상 어댑터에 격리한다.
- 미등록 ROI는 설정 선택 후 미리보기로 등록한다. 등록된 ROI를 선택하면 저장된 설정으로 자동 계산한다. 다중 선택에서는 각 ROI 설정을 사용하며 미등록 ROI는 원본을 유지한다.
- 설정 등록/변경/해제는 `EditorSession.SetFilters`와 기존 Command/Memento를 사용한다. 명시적으로 선택한 ROI만 변경하고 자손에 설정을 암묵적으로 전파하지 않는다. 형상 편집·삭제 복원·이미지 Undo는 설정도 보존한다.
- 활성 미리보기의 숫자 편집은 WPF LostFocus에서 확정해 중간 문자열마다 이력이 생기지 않게 한다. 다중 선택의 혼합 설정은 문구로 알리고, 대표 설정이 없음이어도 `등록 해제` 명령으로 전체 해제할 수 있다.
- 원본 보기는 현재 선택의 표시만 잠시 끈다. 등록은 보존하며 다른 선택을 거쳐 돌아오면 다시 표시한다. 원본 보기 자체는 문서 이력을 만들지 않는다.
- 처리 결과는 파생 데이터다. 선택/형상/설정 변경마다 최신 요청으로 계산하며 원본 파일과 Undo 기록에 결과 픽셀을 넣지 않는다. 단일 작업/최신 대기 하나/취소 버전 검사와 기존 출력 예산을 유지한다.

## 복제와 계층

- `RoiClipboard`가 선택 루트와 전체 자손의 불변 값 스냅샷을 보관한다. 같은 자손을 중복 복사하지 않으며 원본 삭제나 이미지 교체 후에도 붙여넣을 수 있다. 이미지/타일/미리보기 버퍼와 편집 이력은 보관하지 않는다. OS 클립보드 연동과 파일 저장은 이번 범위가 아니다.
- `EditorSession.Paste`가 새 ID, 새 순서와 이름의 ` 복사` 접미사를 부여한다. 형상·각도·필터·그룹 메타데이터는 복제한다. 앱의 같은 완전 포함 규칙으로 부모를 재평가하므로 복사본과 기존 ROI가 겹치는 경우 기존 ROI도 부모가 될 수 있다. 복제한 부모 ID로 관계를 강제하지 않는다.
- 현재 배율 기준 20 DIP 이동을 반복 붙여넣기마다 누적한다. 전체 회전 꼭짓점의 경계를 이미지 안으로 이동시키고, 이미지보다 크면 복사 집합 전체를 균일 축소한다. 이 보정도 하나의 붙여넣기 Undo에 포함한다.
- 붙여넣기는 하나의 편집이며 Undo/Redo는 같은 새 ID·값·최종 계층·선택을 복원한다. 복사는 문서를 수정하지 않는다. Del은 기존 연쇄 삭제 명령을 사용한다.
- 버튼/단축키는 같은 응용 명령에 연결한다. TextBoxBase에 포커스가 있으면 Ctrl+C/Ctrl+V/Del을 ROI 명령으로 소비하지 않는다.

## 검증 근거

Core 자동 검증은 필터 등록/이력/no-op/잘못된 설정, 부모+자손 중복 선택 복제, 삭제 후 복제, 작은 이미지 경계, 반복 붙여넣기와 ID/Undo/Redo를 검사한다. 영상 테스트는 ROI별 서로 다른 임계값, 재선택/원본/해제/Undo, 혼합 선택 해제와 늦은 네이티브 결과 폐기를 검사한다.

실제 WPF/DX12 smoke는 키 명령 복사/붙여넣기, HWND Del 메시지와 Undo, WPF 숫자 바인딩의 중간 입력 무변경 및 한 번의 Undo를 확인했다. 실제 포인터로 전체 흐름을 수행한 E2E 시험과는 구별한다. 이미지 교체 시험과 소유권 검증은 [메모리 보고서](../memory-replacement-validation.md), 원칙별 검토는 [품질 검토](../quality-review.md)를 따른다.
