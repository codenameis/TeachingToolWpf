# ADR-054: 제한 영역용 독립 CPU 템플릿 매칭 3종

상태: 사용자 요청에 따라 구현, 로컬 검증. 2026-10-15.

## 배경

사용자는 GPU 없는 CPU에서 OpenCV 기본 템플릿 매칭보다 좋은 검출과 성능을 원하며 TDCM은 후보 실험이었다고 정정했다. LINE-2D, Sub-NCC, Directional Chamfer를 각 프로젝트로 구현하고 데이터를 제공하도록 요청했다. 일반 검사는 제한된 구역이고 보정 때 넓게 탐색한다. 이 추가 비교 작업은 과거 PoseMatch 전체 검색 유지 조건에 묶이지 않으며 기존 PoseMatch 구현은 보존한다.

## 결정

세 순수 .NET10 라이브러리와 공통 Core, 독립 솔루션, 테스트/평가 CLI를 추가한다. 별도 프로젝트 참조로 소비할 수 있다. 기존 WPF UI/검사 경로에 강제로 연결하지 않는다. 영상/정답/검색 조건이 같은 테스트를 사용하고, 초기 개발 데이터와 마지막 별도 검증 데이터를 구분한다. 원문 핵심 개념의 구현과 미구현 최적화를 명시한다.

검색 ROI·원본 좌표·시계 방향 각도·균일 배율·후보/출력 초과·취소 계약을 공유한다. 점수는 방법별로 의미가 다르다. CPU 데이터 준비를 Find 안에 포함하고 UI 표시 시간과 혼동하지 않는다. 합성15장 통과는 현장 정확도 보장이 아니며 OpenCV보다 항상 빠르다고 표현하지 않는다.

## 결과와 제약

[구현/측정/사용법/원칙 검토](../cpu-template-matching.md). 제한 영역2Mpx/템플릿512px 보호 예산,1024² 보정 검색까지 실측했다. FDCM 선분 적분·하한 검색 전체와 LINEMOD bitmask 전체는 미구현이다. 별도 구현과 실험 데이터 제공은 완료, 현장 성능·앱 적용은 후속 검증이 필요하다. 원칙 예외 없음.
