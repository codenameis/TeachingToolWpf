# ADR-019 — 기하 형상 매칭의 대응 품질과 검증 기준

날짜: 2026-10-04. 사용자 요청: Cognex PatMax와 같은 용도의 전통적 기하 패턴 매칭을 만든다. 기존 C# 형상 엔진을 확장하며 딥러닝 제외, 알고리즘/Canvas 분리, 검사 원본 좌표와 불완전 검색 정책을 유지한다.

## 공개 기능과 구현 범위

[Cognex 공식 PatMax 설명](https://docs.cognex.com/vpro_980sr1/web/en/help/html/89fbd2bc-12b5-4287-adfc-156b10859424.htm)의 윤곽 특징·위치/각도/배율·coverage/fit/clutter 기능을 요구사항 비교에 사용한다. Cognex 소스, SDK 또는 내부 알고리즘을 사용하지 않는다. 지표 이름이 비슷하더라도 수식·점수·임계값은 호환되지 않는다. 이번 구현의 이름은 **기하 형상 매칭**이다.

기존의 방향 응답맵 피라미드 후보 검색 → 연속 gradient 방향 검증 → robust point-to-line 정밀화 → 중복 검출 제거를 유지하고, 최종 반환 자세에 실제 윤곽 대응 품질을 추가한다. 회전/균일 배율 검색은 기존 기능이다. 비균일 X/Y 배율, affine/shear, 비선형 변형, CAD 학습은 이번 단계에 구현된 것으로 표현하지 않는다. 허용 대응 거리 설정만으로 PatMax의 elasticity를 재현했다고 주장하지 않는다.

## 품질 계약

- `ShapeMatch.Geometry`는 최종 반환 pose의 품질이다. `Verify=false` 또는 거친 피라미드 검색에서는 계산하지 않는다. 큰 영상도 최종 원본 crop에서 계산하며 픽셀 오차 단위는 원본이다.
- `Coverage`는 선택된 학습 윤곽 특징 전체 중 거리와 법선 방향이 대응하는 특징의 비율이다. 가림·영상 밖 특징을 분모에서 제거하지 않는다. 물체 면적 비율이나 전체 연속 윤곽의 검출률로 부르지 않는다.
- `FitErrorPixels`는 대응 특징과 실제 장면 에지 사이 유클리드 거리의 RMS다. 정밀화의 point-to-line 잔차와 구별한다. 무대응이면 양의 무한대이며 UI에는 측정 불가로 표시하고 사용자 확인으로 판정한다.
- `ClutterRatio`는 검출 pose로 변환된 실제 학습 마스크 내부 장면 에지 중 학습 윤곽으로 설명되지 않는 비율이다. 희소 특징 160개만으로 장면의 전체 에지를 평가하면 올바른 윤곽까지 clutter로 계산하므로 학습 당시 NMS 윤곽 전체와 정확한 마스크의 불변 복사본을 별도로 보관한다. 검색 영상 가장자리와 마스크 밖/padding은 유효 장면 에지에 넣지 않는다.
- 극성 정책과 법선 일치 기준을 대응 평가에 적용한다. 기본 허용 거리는 원본 3px다. 큰 허용값은 구별 능력을 낮출 수 있으므로 검색 레시피의 명시적 조건이다.
- 지표 계산과 합격 기준을 분리한다. 기존 방향 점수 `.72`, support `.6`은 보존하며 새 coverage 하한·fit 상한·clutter 상한은 기본 해제다. 현장 정상품/유사 오답/가림 데이터로 기준을 설정해야 한다. 기존 레시피를 임의로 더 엄격하게 바꾸지 않는다.
- 계산 결과가 무대응/비유한 품질이면 사용자 확인으로 판정한다. `Geometry=null`은 미계산으로 표시하고 기존 정밀화 판정 계약을 유지한다. 원본 품질 자료가 없는 축소 모델에 활성 기하 합격 기준을 요청하면 명시적 오류이며 기준을 조용히 생략하지 않는다. 취소·오류·예산 잘림을 OK/제품 NG로 바꾸지 않는다. 품질 필터로 모든 후보가 제외돼도 앞선 검색이 잘렸다면 불완전 경고를 유지한다.

## 자원과 책임

학습 마스크·윤곽 자료는 모델이 소유하며 `EstimatedBytes`에 포함한다. 전체 윤곽 수는 262,144개까지로 제한하고 초과 시 명시적인 학습 실패로 기존 모델을 보존한다. 희소화하여 clutter 지표의 의미를 조용히 바꾸지 않는다. 공간 색인으로 대응 조회를 제한하고 반복문은 취소를 확인한다.

정밀화가 제안한 pose를 거부하고 초기 pose를 반환할 때는 최종 잔차와 대응 개수도 실제 반환 pose에서 다시 계산한다. 거부된 pose의 진단값을 반환 pose 옆에 표시하지 않는다.

공개 `PointToLineRefiner.Refine`에 기존 결과를 재입력하면 이전 `Geometry`는 무효화한다. 상위 matcher가 반환 pose에서 새로 평가하며, 별도로 정밀화만 호출한 소비자는 미계산 상태를 받는다.

오른쪽 패널의 `기하 검증` 영역에 윤곽 특징 비율·허용 거리·평균 위치 오차 상한·불필요 윤곽 상한을 둔다. 형상 방식의 유휴 상태에서만 편집하고 조건 변경은 기존/늦은 검사 결과를 무효화한다. OpenCV의 고정 방향 상관 매칭에는 이 옵션을 적용하지 않는다. Canvas의 역할은 기존 도형·점선·판정색 표시 그대로다.

## 검증과 남은 범위

[단계별 계획](../../tasks/geometric-matching-plan.md)과 [작업 목록](../../tasks/todo.md)에 실제 PASS/FAIL/NOT_RUN 증거를 기록한다. 합성 장면의 정답 위치·각도·배율, 가림, 저대비, clutter, 극성 반전, 유사 오답, 마스크, 취소, 원본 crop, 결과 무효화와 GPU 표시를 검증한다. 정답 검출과 검색 완전성을 별도로 확인한다. 합성 통과를 현장 검출률 또는 PatMax 동등성으로 확대하지 않는다.

## 설계 원칙 검토

| 원칙 | 적용 |
|---|---|
| SRP | 모델 학습/품질 측정/필터/앱 판정/표시 책임 분리 |
| OCP | 결과와 검색 옵션의 명시적 확장, 공급자별 UI 조건은 앱에 유지 |
| LSP | 기존 matcher 입력·취소·최종 원본 좌표 계약과 null 품질의 기존 동작 보존 |
| ISP | 품질 때문에 영상 reader/Canvas 인터페이스에 알고리즘 메서드를 추가하지 않음 |
| DIP | VisionAlgorithm은 관리형 값만 사용, 앱이 연결하며 Core/Canvas 참조 그래프 유지 |
| Information Expert | 학습 마스크와 윤곽을 소유한 모델을 통해 정확한 대응 범위를 판단 |
| Creator | trainer가 모델 자료를 생성하고 모델이 불변 자료 수명을 소유 |
| Controller | WPF는 기존 명령으로 학습/검사를 요청하고 수식은 알고리즘에 유지 |
| Low Coupling | 품질 값과 표시 문자열/판정색을 분리 |
| High Cohesion | 품질 옵션·결과 포맷은 VM partial로 묶고 수식은 전용 계산기에 둠 |
| Polymorphism | 기존 검사 서비스 대역 계약을 유지; 사용처 없는 새 공급자 계층 없음 |
| Pure Fabrication | 대응 평가기는 기하 계산 책임을 소유하며 UI 수명을 갖지 않음 |
| Indirection | 기존 이미지/ROI/결과 typed adapter 유지 |
| Protected Variations | 외부 상용 SDK/렌더링 변경과 자체 지표 수식을 격리 |

설계 원칙의 예외는 적용하지 않는다.
