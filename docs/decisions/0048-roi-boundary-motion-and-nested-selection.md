# ADR-048: 일반 ROI 경계와 빠른 입력·중첩 선택

2026-10-15 사용자 후속. 로컬 수정·검증만 수행하며 [ADR-047](0047-view-responsibilities-and-group-bounds.md)의 일반 리프 자유 이동 설명을 대체한다. 사용자는 **기존처럼 부모 밖 독립 ROI의 편입은 허용**하도록 별도로 확정했다.

## 동작

- 부모 안에 있는 일반 ROI도 이동·회전·크기 변경으로 부모를 벗어날 수 없다. 상위 크기를 줄여 하위 ROI를 밖에 남길 수도 없다. 독립 ROI, 이미지 경계,4단계, 그룹 해제와 통합 이력은 유지한다.
- 밖에 있는 독립 리프는 위치·형상·부모 크기·생성 번호를 바꾸지 않고 기존 부모에 편입한다. 밖에서 편입된 리프는 위치를 유지하며 편집할 수 있다. **부모 안으로 이동을 확정한 뒤부터** 다시 밖으로 나갈 수 없다. 그룹끼리의 편입과 밖의 리프를 그룹으로 승격하는 제한은 유지한다. 기존 문서/Undo를 자동 보정하지 않는다.
- 포인터의 이동·회전은 처음 만나는 경계를 기준으로 제한한다. 오목 부모의 빈 공간을 뛰어넘거나, 회전 중 경계를 넘고 나서 다시 들어오는 각도로 튈 수 없다. 미리보기와 확정은 같은 결과를 사용한다.
- 실제 연결된 계층 위에서 더블클릭하면 작은 ROI → 안쪽 그룹 → 바깥 그룹 순서로 겹친 항목을 순환한다. 현재 선택이 마지막 항목이면 처음으로 돌아온다. 고른 그룹의 내부를 드래그하면 하위 ROI가 선택을 가로채지 않는다. Ctrl/Shift 다중 선택, Alt 순환, 핸들 우선, 반복 셀의 실제 hit 선택은 유지한다.
- 자동 ROI 추가는 폴리곤 부모의 바운딩 사각형 중심이 밖에 있는 경우에도 실제 내부에서 시작 위치를 찾는다. 들어갈 최소 공간이 없으면 문서를 바꾸지 않고 직접 그리기/부모 크기 변경을 안내한다.

## 원인과 구현

이전 제한은 `GroupLevels`에 있는 그룹만 대상으로 해서 일반 ROI를 빠뜨렸다. 또 최종 도형이 포함되면 바로 허용하고, 그렇지 않으면 단순 이분 탐색을 했다. 오목한 도형에서 유효한 이동 구간이 나뉘거나 회전 중 여러 유효 각도 구간이 존재하면 이 탐색의 단조성 가정이 성립하지 않는다. 재현에서는 x70의 도형이 x330으로 홈을 건너뛰고, 좁은 부모 속의 긴 ROI가180도로 도약했다.

`RoiGroupBounds`가 일반 리프까지 판정하되 기존 밖의 리프 편입은 명시적으로 보존한다. 선택한 조상과 함께 움직이는 자손은 따로 경계를 검사하지 않는다. 경계 목록은 선택 루트에서 준비하며 전체 자손 수에 비례하는 추가 순회를 피한다.

순수 기하의 `RoiMotionBounds`는 이동 구간 전체가 포함되는 비율을 찾는다. 볼록 부모는 양 끝의 포함으로 판정하고, 오목 부모는 꼭짓점의 이동 선분과 원의 이동 영역이 부모 경계를 통과하는지 검사한다. 회전은 꼭짓점/변·원 경계의 접촉 각도를 구해 시작 각도와 연결된 허용 구간을 사용한다. 회전 범위는 기존 선택/피벗 캐시에 저장하고 준비 worker에서 계산한다. 시간 간격 샘플링에 의존해 빠른 입력을 생략하지 않는다.

`InteractionController`가 더블클릭 순환과 선택 그룹 드래그를 담당한다. View나 렌더러에 선택 정책을 추가하지 않는다. `RoiPlacement`는 자동 추가 위치를 계산하고 VM은 그 결과로 기존 추가 명령을 호출한다.

이동 미리보기는 직전 허용 위치에서 새 포인터 위치까지 검사한다. 따라서 오목한 부모의 홈을 내부 경로로 돌아 이동할 수 있다. 확정할 때는 이미 검증한 미리보기의 최종 포함을 확인해 그대로 사용한다. 시작점에서 최종점까지 직선으로 다시 제한하여 이전 위치로 되돌리는 처리는 하지 않는다. 동기 확정과 worker의 준비된 확정이 같은 경로를 사용한다.

검증과 설계 원칙 검토는 [실행 기록](../roi-boundary-motion-validation.md)에 둔다. 설계 원칙 예외와 새 패키지는 없다.
