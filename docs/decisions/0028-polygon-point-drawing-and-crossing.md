# ADR-028 — 폴리곤 점 입력과 교차점 자동 완성

날짜: 2026-10-05. 사용자 요청: 오각형 즉시 생성 대신 점을 차례로 찍는 자유 폴리곤 입력. 교차 동작은 사용자 답변 **“교차점에서 폴리곤을 자동으로 닫아 완성하기”**로 확정했다.

## 동작

- 폴리곤 선택 후 부모 추가/부모 그리기는 독립 ROI의 빈 초안, 자식 추가/자식 그리기는 선택한 부모의 빈 초안을 시작한다. 버튼을 누르는 것만으로 ROI·이력을 만들지 않는다. 사각형·원·삼각형 즉시 추가는 유지한다.
- 클릭한 이미지 좌표를 차례로 연결한다. 커서 이동은 미리보기만 바꾸고 클릭으로 새 점을 확정한다. Backspace/점 취소, Esc/취소, 이미지 교체/창 크기/캡처 취소 계약을 유지한다.
- 새 선분이 기존 비인접 변에 닿거나 교차하면 **새 선분의 시작점에서 가장 가까운 교차점**을 선택한다. 해당 교차점을 첫 꼭짓점으로 두고 기존 변의 나머지 경로와 새 선분이 만든 닫힌 영역을 생성한다. 열린 시작 꼬리와 교차점을 지나친 커서 위치는 저장하지 않는다. 기존 꼭짓점에 닿으면 같은 점을 중복 저장하지 않는다.
- 기존 변이 `A → B → C`, 새 선이 `C → D`이고 `A → B`와 `P`에서 만나면 결과는 `P → B → C → P`다. `A → P`와 `P → D`는 제외한다. 여러 변을 통과할 때도 첫 교차점만 사용한다.
- Enter/완료/첫 점 클릭으로 닫는 마지막 선분에도 같은 첫 교차 규칙을 적용한다. 실제 교차가 있으면 화면상 첫 점 근접 스냅보다 우선한다. 원본 좌표와 화면 배율을 섞지 않는다.
- 평행한 선의 겹침은 교차 영역으로 자동 확정하지 않는다. 중복 점·되접힘·일직선·0 면적 등 저장 불변식은 `RoiGeometry.Polygon`의 기존 검증을 통과해야 한다. 실패 시 문서/이력/초안을 먼저 변경하지 않는다.
- 유효 형상을 `AddDrawnRoi`로 한 번 추가한 후 선택 도구로 복귀한다. 명시적 부모, 단일 Undo/Redo, 취소/no-op의 Redo 보존을 유지한다. 자기 교차 폴리곤·복합 영역이라는 새 도메인 형식을 도입하지 않는다.

## 책임과 원칙 검토

`PolygonClosure`는 Core의 교차·닫힌 경로 계산, `InteractionController`는 입력 상태·미리보기·확정, `EditorViewModel.RoiCreation`은 버튼 연결을 담당한다. 기존 Command/Memento와 입력 State를 사용하며 별도 이력이나 WPF 기하 계산을 추가하지 않는다.

| 원칙 | 검토 |
|---|---|
| SRP | 교차 계산, 입력 상태, WPF 버튼 책임 분리 |
| OCP | 기존 형상 전략·생성/렌더 계약으로 새 입력 흐름 연결 |
| LSP | 기존 도형/생성의 검증·취소·오류 계약 유지 |
| ISP | 새 범용 인터페이스나 사용하지 않는 메서드 없음 |
| DIP | 교차 계산은 WPF/DX12 없는 Core에서 수행 |
| Information Expert | 이미지 좌표를 가진 Core 기하가 교차와 경로 계산 |
| Creator | 기존 Session이 ID·부모·선택·이력을 한 번 생성 |
| Controller | UI는 그리기 시작 요청만 전달 |
| Low Coupling | 기존 불변 overlay/ROI 데이터로 렌더와 연결 |
| High Cohesion | 교차 계산을 입력 컨트롤러 안에 늘어놓지 않음 |
| Polymorphism | 기존 ROI 전략 유지, 폴리곤용 GPU/필터 분기 추가 없음 |
| Pure Fabrication | 기존 공통 이력·캐시 소유자를 유지 |
| Indirection | 버튼/포인터를 같은 그리기·생성 경로로 연결 |
| Protected Variations | viewport 배율·24K 좌표·명시적 부모 계약을 회귀로 보호 |

원칙 예외 없음. 새 선분의 교차 검색은 기존 점 수에 비례하며 확정의 단순 폴리곤 검증 비용은 기존 방식이다. 수만 꼭짓점 입력의 별도 성능 목표 달성은 주장하지 않는다.

## 검증

결과와 실행 증거는 [작업 목록](../../tasks/todo.md)의 이번 폴리곤 항목에 기록한다. Core 교차/첫 점/수동 완료/다중 교차/확대율/24K/실패/이력, WPF 부모·자식 추가·취소·다른 도형 회귀와 실제 RTX/DX12 HWND 입력을 구분한다. HWND 메시지 기반 smoke는 물리 마우스 전체 E2E를 대신하지 않는다.
