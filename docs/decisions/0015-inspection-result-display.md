# ADR-015: 검사 판정·위치·특징점 표시

날짜: 2026-10-04. 상태: 적용. 사용자 요청은 검사 위치 표시 복구, 네 가지 판정 색상, 패턴 특징점 표시 옵션이다. 기존 ROI 표시색과 문서·이력은 유지한다.

## 문제와 동작

기존에는 전체 이미지 검사도 ROI 선택이 달라지면 결과를 지웠다. 새 검사 실패 시에는 이전 성공 위치가 남을 수 있었고, 미검출은 위치 마커가 없으므로 캔버스에서 판정을 확인할 수 없었다. 선택 해제 후 2개 마커를 기대하는 회귀 테스트를 먼저 실행해 실제 0개로 실패하는 것을 확인했다.

전체 이미지 검사는 선택·pan·zoom 후 결과를 유지한다. 이미지/세대/라이브 입력, 검색 영역, 점수, 최대 결과 수가 바뀌면 결과와 진행 작업을 무효화한다. 라이브 재시작도 정지 프레임의 결과를 지운다. 새 학습/검사는 이전 위치를 먼저 지운다. 취소를 무시하고 늦게 반환한 결과와 예외도 epoch/token 검사 후 폐기한다. 학습 모델은 이미지 교체·실패·취소 후 유지하고 명시적 모델 해제로 제거한다.

## 판정 정책

현재 정책은 **패턴 존재와 위치 정밀화 검사**다. 치수·공차·결함 종류 또는 기대 개수 검사까지 구현했다고 주장하지 않는다. 최소 최종 점수는 기존 UI에서 설정하며 지지율은 기존 SearchOptions 기본 0.6을 사용한다. 표시 개수는 최대 결과 수로 제한된 반환 개수다.

| 판정 | 색상 | 조건 |
|---|---|---|
| 정상 (OK) | LimeGreen `#32CD32` | 완전한 검색에서 하나 이상 검출, 모든 반환 결과가 정밀화 수렴·각도 관측 가능 |
| 불량 (NG) | Tomato `#FF6347` | 완전한 검색에서 점수·지지 조건을 만족하는 패턴이 없음 |
| 경고 (WARN) | Orange `#FFA500` | 후보/검증 예산 초과, 검색 창 없음, 실행 오류 또는 취소 |
| 사용자 확인 (CHECK) | Gold `#FFD700` | 검출은 있으나 정밀화 미수렴/비활성/거부 또는 각도 관측 불가 |

사용자 표현 `Golden`은 금색 Gold로 해석했다. 불완전 검색이 다른 판정보다 우선하며 모든 부분 검출을 경고색으로 표시한다. 완전한 검색의 혼합 결과는 전체 판정을 사용자 확인으로 표시하고 각 검출은 자신의 판정색을 사용한다. 색과 OK/NG/WARN/CHECK 문구를 함께 제공한다. 경고는 제품 불량으로 처리하지 않는다.

## 표시 계약

- 오른쪽 판정 배지와 캔버스 고정 배너에 현재 판정을 표시한다. 검색 영역 윤곽, 검출 경계, 기준점 십자선, 시계 방향 화살표, 번호·점수·원본 X/Y·절대각을 같은 DX12 화면에서 그린다. 미검출은 검색 윤곽·배너만 표시하며 가짜 검출 위치를 만들지 않는다.
- `검사 위치 표시`는 결과 표시 전체를, `특징점 표시`는 학습 윤곽점을 전환한다. 기본은 위치 켬/특징점 끔이며 재검사·ROI 편집·Undo 기록 없이 적용한다.
- 특징점은 가장 세밀한 모델의 기준점 상대 좌표를 검출 위치·회전·균일 배율로 변환한 점이다. **검출 영상에서 재측정한 대응점/매칭 성공점 또는 실시간 특징 추적 결과가 아니다.** 이 의미는 UI 툴팁에도 명시한다.
- `검출 위치로 화면 맞춤`은 검출 경계 전체로 뷰를 이동·확대하며 문서·선택·이력을 유지한다.
- 특징 좌표 배열은 검사 확정 때 한 번 만든다. 표시 전환과 렌더에서 불변 배열을 공유하고 화면 밖 점은 제출하지 않는다. 3 DIP 사각점으로 그리며 개별 라벨 생성은 기존 지연 라벨 캐시 예산을 따른다.

## 책임과 원칙 검토

새 의존성·설계 예외는 없다. 독립 읽기 전용 리뷰에서 수정이 필요한 확정적 오류는 발견되지 않았다.

| 원칙 | 적용·검토 |
|---|---|
| SRP | InspectionDecision은 판정, InspectionResultPresentation은 표시 변환, VM은 작업 수명, ResultOverlayPainter는 GPU 도형 제출 |
| OCP | 새 표시 값으로 기존 scene을 확장. 매칭 알고리즘이나 ROI 편집 규칙에 UI 분기를 추가하지 않음 |
| LSP | 새 대체 서비스는 없음. 취소 무시·실패·늦은 반환의 기존 비동기 계약을 테스트 대역으로 검증 |
| ISP | 서비스 입력/출력 계약 유지. 캔버스에 검사 실행 메서드를 강제하지 않음 |
| DIP | 앱이 Algorithm과 Canvas를 연결. Canvas/Core에 알고리즘·판정 정책 참조 없음 |
| Information Expert | 판정은 정밀화/완전성 진단, 특징점 변환은 model/pose를 가진 adapter에 둠 |
| Creator | adapter가 불변 표시 결과 생성. GPU 리소스 소유권은 기존 renderer 유지 |
| Controller | WPF 버튼은 VM 명령, VM은 service 호출. MainWindow에 검사 규칙 추가 없음 |
| Low Coupling | ResultOverlay는 문자·색·좌표·옵션 값만 포함 |
| High Cohesion | ScenePainter의 매칭 표시 블록을 전용 painter로 분리 |
| Polymorphism | IShapeMatchingService와 기존 viewport 계약 유지. 사용처 없는 공급자/판정 플러그인 없음 |
| Pure Fabrication | 비동기 수명·판정·표시 변환을 ROI 도메인 밖의 별도 책임으로 유지 |
| Indirection | typed 표시 adapter가 알고리즘과 GPU API 사이를 분리 |
| Protected Variations | 공급자 변경은 앱 adapter, 렌더 변경은 Canvas 내부로 한정 |

검증 결과와 재현 명령은 [작업 목록](../../tasks/todo.md)의 검사 표시 항목을 따른다. 640×400 합성 PNG를 실제 파일 경로로 열어 검증했으며 현장 데이터 검출률, 8K/24K 검사 성능, 최대 결과 수의 GPU 부하는 이번 변경에서 측정하지 않았다.
