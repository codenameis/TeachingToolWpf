# ADR-035: 표시 설정 페이지와 이미지 중심 크로스헤어

- 날짜: 2026-10-06
- 상태: 사용자 구현 승인. 선택 상태와 그룹 관계를 구별한다는 사용자 답변에 따른다.

## 결정

기본 Inspection 레이어를 가져와 Add하는 예제를 제공한다. 기존 결과 전체 교체·수명 계약은 바꾸지 않는다.

사용자는 크로스헤어를 **배경 이미지 중심, Canvas 전체 크기**로 구체화했다. 앱은 Image 레이어의 `ImageCrosshairGraphic`을 사용한다. 렌더 시 현재 이미지 중심을 변환하고 두 선을 캔버스 경계까지 그린다. ROI별 루프나 전체 화면 텍스처를 추가하지 않는다. 이미지 없음/화면 밖 축은 표시하지 않는다. 앞선 ADR-034의 앱 화면 중심 가이드 설명은 이 결정으로 대체하며 짧은 ScreenCenter API 자체는 보존한다.

RoiStrokeStyle에 선택 색과 별도의 MultiSelectedColor를 추가한다. 기존 생성자는 선택적 인수로 호환되며 미지정 시 기존 SelectedColor를 사용한다. 앱 기본 팔레트는 일반/자식/부모 역할을 구별하고 다중 선택은 공통 주황색으로 묶는다. 역할별 세 가지 색·두께를 ConfigPage에서 변경한다. 실제 계층·그룹 생성 의미는 바꾸지 않는다.

설정 창은 앱의 기존 스타일 뷰모델과 새 크로스헤어 설정, 기존 PointSampling을 바인딩한다. 한 창을 재사용하고 닫은 뒤에도 실행 중 상태를 유지한다. 파일 저장·범용 설정 프레임워크·외부 종속성은 도입하지 않는다. ROI 색 입력은 전체 검증 후 팔레트를 한 번 게시한다. 크로스헤어 바인딩은 Guide 레이어 한 항목을 갱신하고 수명 종료 시 구독을 해제한다.

## 경계와 검증

Canvas의 HWND 위에 WPF 설정 패널을 겹치지 않고 별도 소유 Window를 연다. 화면 동작은 [사용 가이드](../configuration-guide.md), 실제 빌드·회귀·GPU/WARP·설계 검토는 [검증 기록](../configuration-validation.md)에 남긴다. GPU 상수 크기와 ROI 캐시를 보존하며 새 설계 원칙 예외는 없다. 기존 60FPS 미달과 별도 검사 시간 목표는 이번 기능 완료와 구별한다.
