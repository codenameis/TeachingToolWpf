# 라이브 이상 감지 UI 시안

화면 구성과 사용 흐름을 비교하는 독립 HTML 두 개다. 각각 브라우저에서 파일을 열면 실행되며 빌드, 설치, 인터넷 연결은 필요 없다. 상단 링크로 다른 시안으로 이동할 수 있다.

| 시안 | 구성 | 적합한 상황 |
| --- | --- | --- |
| [01-control-room.html](01-control-room.html) | 카메라 목록 + 분할 영상 + 알람 목록/상세 + 타임라인 | 여러 카메라를 동시에 보는 운영자 |
| [02-guided-monitor.html](02-guided-monitor.html) | 영상 선택 → 정상 모습 준비 → 감시/확인 | 처음 설정하거나 한 영상을 집중해서 보는 사용자 |

## 체험 순서

관제실형은 처음부터 모의 감시 상태다. 오른쪽 알람을 선택하고 확인 완료 또는 정상 상황으로 기록한다. 아래 버튼으로 제품 하나의 외관 이상과 움직임 이상 구간을 추가한다. 1/4분할, 카메라 검색, 이벤트 기록, 정상 기준 설명, 알람 임계값 설정, 일시정지도 사용할 수 있다.

안내형은 영상을 고르고 정상 예시를 선택한 뒤 모의 준비를 실행한다. 감시를 시작하면 아래 체험 버튼으로 두 종류의 알람을 만든다. 연결 끊김/복구, 일시정지, 설정 변경 후 정상 기준 재준비도 체험할 수 있다. 이전 영상의 미확인 알람은 기록으로 남으며 다시 확인할 수 있다.

## 구성 판단

- 관제실형은 AXIS와 Milestone 문서의 영상 보기·알람 목록·상세 확인·타임라인 조합을 참고했다. 시장 점유율을 조사한 결과나 가장 많이 쓰는 단일 화면이라는 뜻은 아니다. 특정 제품의 화면을 복제하지 않았다.
- 안내형은 한 단계에 하나의 결정을 드러낸다. 점수와 알고리즘 이름보다 무엇이 달랐는지, 이제 무엇을 누르는지를 먼저 보여준다.
- 짧게 나타난 외관 이상과 일정 시간 이어진 움직임 이상을 별도 모의 이벤트로 제공한다. 특정 사고 종류를 미리 분류하는 화면으로 한정하지 않는다.
- 정상·알람·일시정지·연결 끊김을 문구와 색으로 구분한다. 영상이 없거나 감시가 멈추면 정상이라고 표시하지 않는다.
- 알람 확인과 정상 기준 변경을 분리했다. 정상 상황으로 기록해도 자동 재학습하지 않는다.

## 구현 범위

영상은 Canvas 합성 애니메이션이고 점수·이상 위치·시간은 미리 정한 예시다. 정상 기준 준비도 모의 진행률이다. 실제 CCTV/RTSP 연결, 모델 학습·추론, 녹화 재생, 서버 저장, 외부 알림 전송은 포함하지 않는다. 타임라인은 모의 이벤트 선택만 제공한다. 기록은 현재 탭에서만 유지하며 새로고침하면 초기화한다.

이번 결과는 WPF 통합, 이상 감지 정확도, 8K 영상 처리 또는 60FPS 성능을 검증한 것이 아니다.

## 검증

- Edge155.0.4283.45에서 Playwright로 실제 브라우저 실행: **52개 항목 PASS**.
- 320/768/1024/1440px 가로 넘침, 버튼 이름, 키보드 포커스, Escape 모달 닫기를 확인했다. 전체 접근성 인증은 아니다.
- 준비 전 감시 차단, 빈 정상 예시 방지, 알람/강조 표시, 확인·정상 기록, 임계값, 일시정지, 연결 복구, 영상 변경 시 기준 무효화, 이전 미확인 알람 보존·재확인을 검증했다.
- 콘솔 경고·오류 및 런타임 오류0건. 데스크톱과 좁은 화면 캡처 확인.
