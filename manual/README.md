# 신입 개발자 HTML 실습서

브라우저에서 [index.html](index.html)을 열어 시작한다. 본문은 첫 화면·1~9장·부록의11페이지다. 사용하지 않는 이전10·11장 파일은 삭제했다. HTML·수식·SVG 다이어그램·CSS/JavaScript는 오프라인으로 작동한다. 외부 공식 문서 링크만 인터넷이 필요하다. 파일을 옮길 때는 `manual` 전체를 함께 복사한다. 저장소의 검증 문서 링크와 실습 프로젝트 실행까지 쓰려면 저장소 안의 원래 위치를 유지한다. 소스 열람용 코드 자체는 HTML에 들어 있다.

- 픽셀·좌표·필터 → 클래스 관계·설계 원칙 → 입력·ROI 편집·영상 수명 → DX12·검사 → 직접 구축 순서.
- 1~9장은 구체적인 상황 하나, 기억할 문장 하나, 세 단계 설명, 결과 예상과 풀이로 시작한다. 아래 본문에서 먼저 확인할 세 곳을 연결한다. 2장의 드래그 계산을 5장의 확정/취소와 7장의 표시로 이어 읽는다. 기호표·원칙 용어·확장 설명19곳은 필요할 때 펼친다. 수식별 기호 설명은 해당 수식 옆에 그대로 남긴다.
- [5장 ROI 드래그 실습](05-editing.html#roi-drag-lab)은 SVG 사각형을 직접 끌거나 자동 재생/일시정지/다음 단계로 조작한다. 확정 위치와 미리보기를 점선·실선 및 수치로 구별하고, Down·Move·Up·Cancel에 맞춰 클래스 호출 경로와 실제 C# 발췌4개를 표시한다. Escape·캡처 상실·창 비활성화에서 취소하고, 움직임 줄이기 설정에서는 위치를 단계별로 바꾼다. 현재 코드를 설명하는 교육 모형이며 실제 WPF/Core/GPU 실행은 아니다. JavaScript가 없으면 기본 그림과 기존 시퀀스 그림을 읽을 수 있다.
- [4장 class·record 비교](04-design.html#class-and-record)에서 참조/값 형식, 기본 동등성, 불변성과 역할을 구별한다. [5장 실제 ROI 이름 변경](05-editing.html#record-roi-history)은 `with` 후보 → 불변 사전 → `Rename`/`Commit` → `RoiChange`의 Before/After → Undo/Redo로 연결한다. ROI ID·참조 동일성·값 동등성, 얕은 복사·내부 공유·캐시, 새 편집의 Redo 갈래도 설명한다. `labs/RecordsHistory`는 실제 Core를 참조하는 콘솔 실습이며 18개 조건을 검증한다. 실행: `dotnet run --project manual/labs/RecordsHistory/RecordsHistory.csproj -c Release` (저장소 루트).
- 수식 기호·단위·숫자 예·실험5개·정답 풀이·용어 검색 제공.
- 파인만 방식의 학습 순환을 적용한다. 쉬운 질문과 비유 → 기호·단위 → 중간 계산과 검산 → 실제 코드 → 책을 덮고 설명 → 막힌 부분 재학습 순서다. 원리를 설명하는 장마다 자기 설명 과제와 접힌 풀이를 제공한다. 학습 효과가 실제 신입 평가로 입증됐다는 뜻은 아니다.
- NCC의 평균·편차·분자·분모, 회전 행렬의 두 행, Gaussian 가중치 정규화, Sobel, 보간, 타일 올림/내림·LOD 로그·피라미드 메모리를 작은 숫자로 풀어 쓴다. 잘못 계산한 예와 비유의 한계도 함께 설명한다.
- 본문에 소스60곳(전체 파일/연속 발췌)을 포함한다. RenderWorker·Dx12Surface·ScenePainter와 셰이더 등 기존 소스 링크도 해당 설명 자리의 코드창으로 바꿨다. 같은 페이지의 기존 전체 코드가 있으면 그 창을 펼친다. 소스 파일 텍스트 화면으로 이동하는 링크는 없다. 소스 일치 검증 시점과 범위는 검증 기록을 따른다.
- 4장의 클래스 관계는 입력 연결·제스처 상속·문서 구조의 세 그림으로 나누었다. 각 그림의 읽는 방향, 화살표 의미와 실제 멤버를 문장으로 함께 설명한다. 강제 가로 폭 없이 본문 폭에 맞춘다. 5장은 ROI 이동·그리기/취소·비동기 확정 시퀀스를 제공한다. `assets/diagrams`의 SVG는 렌더러 다운로드 없이 보이며 Mermaid 원문도 함께 제공한다. 실제 모든 타입을 한 그림에 넣은 것이 아니라 핵심 입력/문서 관계와 확장 지점을 보여 준다.
- 6장은 타일 주소·가장자리·가시 타일 계산·피라미드/DPI·부분 읽기·캐시·세대·halo를 손계산, 실제 코드, 이동 실험으로 설명한다. 표시용 단계와 검사 원본, 교육용 설계와 현재 구현을 구분한다.
- `labs/Foundations`: GPU 없는 좌표·이력 실습. `labs/InputLifecycle`: 가짜 포인터로 이동·마지막 위치 확정·Undo/Redo·취소를 실행하는 실습. `labs/CanvasHost`: 8K 합성 타일을 표시하는 작은 WPF 호스트.
- NetVips 제거 이후의 자체 raw 피라미드·네이티브 코덱 경로를 설명한다. 독립 합성 호스트와 전체 파일 호스트의 빌드 준비를 구별한다.
- 실행법은 [9장](09-build.html), 변경/검증과 미검증 범위는 [검증 기록](../docs/beginner-manual-validation.md).

본문을 수정할 때는 해당 HTML을 편집한다. 공통 화면/실험은 `assets/manual.css`, `assets/manual.js`, 코드창의 문법 색상과 복사는 `assets/code-blocks.js`에 있다. 서버·CDN·추가 문서 빌드 도구는 필요 없다. 장 제목/경로를 변경하면 모든 페이지의 차례와 JS의 첫 화면 카드 목록도 함께 갱신한다.

ROI 실습의 상태/입력/재생은 `assets/roi-drag.js`에 있다. 단계별 설명과 발췌는5장의 `script[type="application/json"]#roi-demo-stages`에 저장한다. JSON의 `<`는 `\u003c`로 이스케이프한다. C# 원본이 바뀌면 이 발췌도 함께 갱신한다. 모델/DOM 대역 검사와 실제 브라우저 조작·표시 검증을 구별한다.

코드·명령어·다이어그램 원문81곳은 기본으로 접혀 있다. 제목을 클릭하거나 키보드 Enter/Space로 펼치면 본문 안에서 읽을 수 있다. 언어·파일명·줄 수·전체/발췌 표시, 복사 버튼, C#/XML/HLSL 어휘 색상을 제공한다. 긴 코드는 코드창 안에서 스크롤하고 원본 경로는 아래에 텍스트로 표시한다. 본문에 남은 소스 참조21개는 파일을 열지 않고 해당 페이지의 코드창을 펼치며, 그 주소로 다시 들어와도 코드창이 열린다. 클립보드가 차단된 환경에서는 코드를 선택하고 직접 복사하는 방법을 안내한다. 색상은 첫 펼침 때만 추가하며 코드 문자열은 바꾸지 않는다. JavaScript가 꺼져도 기본 접기/펼치기와 코드 읽기는 가능하다. 인쇄 시 기존 인쇄 이벤트가 코드를 펼치고 끝나면 원래 접힘 상태로 되돌린다.

코드 블록은 파일을 실행 시 가져오지 않고 HTML에 직접 저장한다. `code[data-source]`는 원본 상대 경로, `data-kind`는 `full`(파일 전체) 또는 `excerpt`(연속 발췌)다. 원본을 바꾸면 해당 HTML 코드도 함께 갱신하고 HTML 이스케이프를 적용한다. 검증에서는 HTML을 디코딩한 코드와 실제 파일을 비교했다. 3장의 짧은 이진화 코드는 제품 코드 발췌가 아닌 별도 교육 예제다.

새 코드창은 기존 `details.code-example`을 복사해 제목·줄 수·코드와 `data-language`를 함께 갱신한다. 언어 값은 `csharp`, `xml`, `hlsl`, `powershell`, `mermaid`, `text`다. C#/XML/HLSL 색상은 어휘 구분이며 컴파일러나 의미 분석기가 아니다. 기본 접힘을 유지하려면 `open` 속성을 넣지 않는다. 참조 링크는 `href="#코드창ID"`와 `data-code-target="코드창ID"`를 함께 지정한다. 원본 `.cs` 파일로 직접 이동하는 링크를 다시 넣지 않는다.

접힌 참고 설명은 `details.deep-dive`를 사용한다. 소스 참조나 해시 주소로 들어오면 코드창을 감싼 참고 설명도 함께 열린다. 본문 읽기 링크에는 대상 section ID와 `data-reading-target`을 지정한다. 단원 순서를 바꾸더라도 기존 section·코드창 ID를 유지한다.

수식은 HTML 안의 표준 MathML로 작성한다. 분수(`mfrac`), 제곱근(`msqrt`), 상하 첨자(`msub`/`msup`), 합의 범위(`munderover`), 평균 윗줄(`mover`), 행렬(`mtable`)을 사용한다. 기본 시스템 수학 글꼴을 쓰며 CDN·웹 폰트·JavaScript 렌더러 다운로드는 없다. MathML을 지원하는 현대 브라우저를 대상으로 한다. [MDN MathML 안내](https://developer.mozilla.org/en-US/docs/Web/MathML), [행렬과 수식 정렬](https://developer.mozilla.org/en-US/docs/Web/MathML/Tutorials/For_beginners/Tables).

수식 수정 시 표시 구조와 `aria-label`/`annotation`의 선형 설명을 함께 갱신한다. 긴 수식 상자는 키보드로 초점을 맞춰 가로로 읽을 수 있고, 인쇄 스타일은 흰 배경과 작은 수식 크기를 사용한다. 실제 브라우저·보조공학·PDF 결과는 정적 마크업 검사와 구별한다.

설명을 수정할 때는 정답만 추가하지 않는다. 왜 그 계산이 필요한지, 입력 단위가 무엇인지, 중간 값과 실패 경계는 무엇인지 함께 적는다. 교육 예제의 숫자는 실제 장비 성능이나 검출률로 표현하지 않는다. 장 끝의 설명 예시는 기본으로 접어 독자가 먼저 설명할 기회를 유지한다. 산술 검증과 실제 신입 독자의 이해도 평가는 서로 다른 검증이다.
