이진화: 밝기에서 두 가지 상태로

“밝기가 조금씩 다른 부품을 흰색, 배경을 검은색으로 나누고 싶어요.” 이진화는 각 칸에 같은 질문을 하는 과정입니다. ‘이 칸의 밝기가 기준보다 큰가?’라고 물어서 참이면 흰색 255, 거짓이면 검은색 0을 적습니다. 물체를 이해하는 판단이 아니라 정해진 조건의 반복입니다.

임계값 T를 정해 픽셀이 T보다 밝으면 255, 아니면 0으로 바꿉니다. 픽셀값을 외운 것이 아니라 조건문 한 줄을 적용한 것입니다. 아래 실험은 I>TI > T 규칙을 사용합니다.≥. ≥와 >는 경계값에서 결과가 다르므로 API 규칙을 확인해야 합니다.

B⁡(x,y)={255I⁡(x,y)>T0I⁡(x,y)≤TB(x,y) = 255 if I(x,y) > T; 0 if I(x,y) ≤ T

커널: 작은 계산표를 옮겨 가며 적용하기

“혼자 튀는 밝은 점을 주변과 비슷하게 만들려면 어떻게 할까요?” 한 사람의 목소리만 듣는 대신 이웃 아홉 명의 평균을 듣는다고 생각해 보세요. 주변 픽셀을 조금씩 섞으면 혼자 튀는 값이 약해집니다. 얼마나 섞을지 적은 작은 표가 커널입니다.

커널은 픽셀 주변에 곱할 가중치의 작은 표입니다.3×3. 3×3 평균 필터는 9개 픽셀을 더해 9로 나눕니다. ∑시그마: 합(시그마)는 ‘해당 항들을 모두 더한다’는 기호입니다.

J⁡(x,y)=∑v=−11∑u=−11K⁡(u,v)·I⁡(x+u,y+v)J(x,y) = Σ(v=−1..1) Σ(u=−1..1) K(u,v)·I(x+u,y+v)

  2. 안쪽 합에서 u=−1,0,1u=−1,0,1을 돌며 세 픽셀과 각 가중치를 곱해 더합니다.

Gaussian 식의 exp와 σ를 겁내지 않고 읽기

exp(q)는 e를 q제곱한 값이며 C#에서는 Math.Exp(q)입니다. e는 약 2.718입니다. 이 절의 x는 커널 중심으로부터의 거리(px), σ(시그마)는 퍼지는 폭(px)입니다. 거리의 제곱을 σ의 제곱으로 나누므로 지수에는 단위가 남지 않습니다.

σ=1σ=1에서 거리 −1,0,1만 쓰는 교육용 세 칸을 계산해 봅시다. 정규화 전 가중치는 약 [0.6065,1,0.6065], 합은 2.2131입니다. 각 값을 합으로 나누면 약 [0.2741,0.4519,0.2741]입니다. 가운데가 더 큰 몫을 갖고 합은 1입니다. 실제 필터의 커널 크기와 경계 정책은 별도로 정해야 합니다.

‘가로 다음 세로’가 가능한 이유는 2차원 Gaussian 가중치를 두 1차원 가중치의 곱으로 나눌 수 있기 때문입니다. 폭 k의 커널을 직접 적용하면 픽셀당 대략 k2k²개의 항, 두 방향으로 나누면 대략 2k개의 항을 다룹니다. 모든 커널에 가능한 방법은 아닙니다.

Sobel: 밝기가 변하는 방향 찾기

“부품의 테두리는 밝기 값 몇인가요?” 테두리는 특정 밝기 하나가 아니라 이웃 사이의 큰 변화일 수 있습니다. 평평한 길에서는 고도 차이가 작고 절벽에서는 큰 것처럼, 영상에서도 밝기 차이를 계산하면 경계의 후보를 찾을 수 있습니다.

atan2는 두 성분의 부호까지 사용합니다.Gx=−400,Gy=0. Gx=−400, Gy=0이면 왼쪽 방향을 구별합니다. 단순히 Gy/Gx만 사용하면 (0,400)과 (0,−400)의 방향을 구별하기 어렵고 Gx=0Gx=0일 때 나눗셈 문제도 생깁니다. 위 수식의 atan2 인수는 y 성분 먼저, x 성분 나중입니다.

마스크: 계산 대상의 경계

“평균을 낼 때 가려진 픽셀을 0으로 넣으면 될까요?” 시험 결시자를 0점으로 포함한 평균과 응시자만의 평균은 다릅니다. 마스크도 같은 문제입니다. 제외된 칸은 밝기가 0인 칸이 아니라 계산에 참여하지 않는 칸입니다.

마스크는 유효 영역인지 알려 주는 값입니다. 이진 유효 마스크 M이 1인 픽셀만 평균한다면 평균=∑i=1nMi·Ii∑i=1nMi평균 = Σ(i=1..n)(Mi·Ii) / Σ(i=1..n)Mi입니다.ΣM=0. ΣM=0이면 대상이 없다는 오류 또는 빈 결과를 명시해야 합니다. 마스크 밖의 0과 실제 검은 픽셀 0은 같지 않습니다.

이 프로젝트의 ROI 제외 영역은 정규화 로컬 좌표에 저장되어 ROI 이동·회전·resize를 따라갑니다. 제외를1로 표시하는 마스크와 유효한 픽셀을1로 표시하는 마스크는 반대 의미이므로 이름과 계약을 확인합니다. 표시 음영을 껐다고 검사 제외 설정이 사라지지는 않습니다.

namespace VisionGeometry;

public enum MaskShape
{
    Rectangle,
    Ellipse
}

/// <summary>ROI 프레임 좌상단 기준 0–1 좌표. 적용 영역은 실제 ROI 도형과의 교집합이다.</summary>
public sealed record MaskRegion
{
    public MaskShape Shape
    {
        get;
    }
    public BoundsD Bounds
    {
        get;
    }

    public MaskRegion(MaskShape shape, BoundsD bounds)
    {
        if (!Enum.IsDefined(shape) || !double.IsFinite(bounds.Left) || !double.IsFinite(bounds.Top) ||
            !double.IsFinite(bounds.Right) || !double.IsFinite(bounds.Bottom) || bounds.Left < 0 || bounds.Top < 0 ||
            bounds.Right > 1 || bounds.Bottom > 1 || bounds.Width <= 0 || bounds.Height <= 0)
        {
            throw new ArgumentException("마스크는 ROI 프레임 안의 유효한 영역이어야 합니다.", nameof(bounds));
        }
        Shape = shape;
        Bounds = bounds;
    }

    public bool ContainsNormalized(PointD point)
    {
        if (!Bounds.Contains(point))
        {
            return false;
        }
        if (Shape == MaskShape.Rectangle)
        {
            return true;
        }
        var x = (point.X - Bounds.Center.X) * 2 / Bounds.Width;
        var y = (point.Y - Bounds.Center.Y) * 2 / Bounds.Height;
        return (x * x) + (y * y) <= 1;
    }

    public bool Contains(RoiGeometry owner, PointD world)
    {
        var local = owner.ToLocal(world);
        return owner.Shape.ContainsLocal(local, owner.Width, owner.Height, 0) &&
            ContainsNormalized(new((local.X / owner.Width) + .5, (local.Y / owner.Height) + .5));
    }
}

직접 확인: [20,40,200]에서 마지막 픽셀을 제외한 평균은?

(20+40)2=30(20+40)/2=30입니다. 제외 픽셀을 0으로 바꾸고 세 개로 나누면 20이 되어 틀립니다. 분모에서도 제외해야 합니다.

분자와 분모가 함께 바뀌어야 합니다

i는 비교할 칸의 번호, n은 전체 칸 수, Iᵢ는 i번째 밝기, Mᵢ는 유효하면 1·제외하면 0입니다. [20,40,200]에서 마지막 칸을 제외하면 M=[1,1,0]M=[1,1,0]입니다. 분자는 1×20+1×40+0×200=601×20+1×40+0×200=60, 분모는 1+1+0=21+1+0=2이므로 평균은 30입니다.

마지막 밝기만 0으로 바꾸고 3으로 나누면 20이 됩니다. ‘제외’를 ‘검은 픽셀로 바꾸기’로 잘못 구현한 결과입니다. 모든 M이 0이면 000/0으로 계산할 수 없으므로 대상 없음 상태를 처리해야 합니다. 표시 음영을 숨기는 기능은 이 유효성 규칙을 변경하는 기능과 별개입니다.

축소와 보간

“네 픽셀 사이의 위치에는 무슨 밝기를 쓸까요?” 네 꼭짓점의 값을 거리만큼 나누어 받는다고 생각하세요. 왼쪽에 가까우면 왼쪽 값을 많이 받고, 위쪽에 가까우면 위쪽 값을 많이 받습니다. 이것이 bilinear 보간입니다. 넓은 영역을 한 픽셀로 줄이는 문제와는 구별해야 합니다.

2×22×2 픽셀 [0100100200]2행 2열 행렬 [0,100;100,200]을 하나로 줄이는 면적 평균은 100입니다. 왼쪽 위만 가져오면 0이 되어 전혀 다른 밝기가 됩니다. nearest는 가장 가까운 값 하나, bilinear는 인접 네 값을 거리에 따라 섞습니다. 화면 보간과 원본 검사 리샘플링 규칙은 별도입니다.

bilinear=(1−a)(1−b)P00+a(1−b)P10+(1−a)bP01+abP11bilinear = (1−a)(1−b)P₀₀ + a(1−b)P₁₀ + (1−a)bP₀₁ + abP₁₁
