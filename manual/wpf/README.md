# WPF 코드 교육서

[index.html](index.html)을 열어 읽는다. 변수·반복문·메서드·클래스를 배운 고등학생을 대상으로 App 조립, MVVM, 바인딩, 두 카메라 상태 분리, 공통 ROI·입력·타일, 메인 앱의 검사 연결과 수명을 설명한다. WPF는 UI 프레임워크이고 이 프로젝트의 기본 Canvas 렌더러는 DX12다.

실제 코드 발췌, 숫자 계산, 선택 없는 ROI 확대·잠금의 교육용 모형, 실습과 접힌 풀이를 포함한다. 샘플은 `samples/VisionCanvas.MvvmSample`, 메인 앱은 `src/TeachingToolWpf`다.

오프라인 열람에는 `manual` 폴더 전체가 필요하다. 원본 대조와 문서 링크까지 쓰려면 저장소 구조를 유지한다. [검증·관리](../../docs/renderer-code-guides.md).

첫 읽기에서는 앞부분의 일곱 단어와 1~7장의 상황·작은 계산·조작 모형을 따라간다. 8~12장은 실제 구현과 자원 관리의 심화 읽기다. 비유 다음에 실제 클래스와 메서드를 연결하며 코드·수식·검증 한계는 유지한다.
