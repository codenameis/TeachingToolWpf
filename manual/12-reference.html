용어 사전

브라우저 찾기 Ctrl+F 또는 아래 필터로 찾으세요.

ROI
관심 영역. 표시 사각형만이 아니라 ID·실제 형상·선택·계층을 가진 편집 대상.
pixel / channel
영상 한 칸 / 한 칸의 성분. Gray는 밝기 하나, RGBA는 네 성분.
stride / padding
다음 행까지의 바이트 거리 / 정렬 등을 위한 행 끝 여유 공간.
px / DIP / DPI
픽셀 / WPF 논리 단위 / 인치당 픽셀 수. 코드의 Dpi는 보통 96 기준 비율.
bit depth / dynamic range
저장 가능한 값의 비트 수 / 구분 가능한 밝기의 범위. 저장 공간과 실제 센서 품질을 동일시하지 않음.
crop / resize / resampling
일부 잘라 읽기 / 크기 변경 / 새로운 격자 위치의 값을 계산하기.
kernel / convolution
이웃 가중치 표 / 그 표를 뒤집어 입력의 이웃과 곱해 합하는 연산.
gradient / edge
밝기 변화의 크기·방향 / 밝기가 급하게 달라지는 경계.
mask
계산 대상 포함/제외 영역. 1이 포함인지 제외인지는 해당 계약에서 확인.
pose
검출/도형의 위치·각도·배율 등 배치 상태.
AABB / BVH
축과 평행한 외접 상자 / 상자를 계층으로 묶어 공간 후보를 거르는 트리.
tile / pyramid / LOD
영상 조각 / 여러 축소 단계 / 표시 자세함의 단계. 원본 검사를 대체하지 않음.
immutable / snapshot
만든 뒤 바꾸지 않는 값 / 한 시점의 상태. 전체 깊은 복사와 동의어가 아님.
identity / equality
같은 객체인가 / 같은 내용인가. 캐시 키와 문서 비교에서 구별.
preview / commit
조작 중 임시 표현 / 유효성 확인 후 한 편집으로 확정.
Undo / Redo / cursor
이전 편집 되돌리기 / 다시 적용 / 이력 목록에서 현재 위치.
lease / retain / dispose
사용 권한 / 별도 사용 권한 유지 / 사용 종료. 픽셀 복사와 다른 개념.
generation / epoch
이미지·작업 세대를 식별하는 값. 늦게 도착한 결과의 유효성을 판단.
cancellation
협력적 중단 요청. 이미 계산된 결과가 현재 상태에 맞는지는 별도 검증.
HWND / HwndHost
Windows 창 식별자 / WPF 안에 native 자식 창을 넣는 경계.
swap chain / Present
화면 버퍼 전환 관리 / 그린 결과의 표시 제출. 물리 화면 시각과 다름.
fence / barrier
GPU 작업 완료 표식 / GPU 자원의 사용 상태·순서 전환.
WARP / CUDA
Windows의 CPU Direct3D 표시 / NVIDIA GPU 계산 플랫폼. 표시 장치 선택과 검사 계산 선택은 별도.
NCC / NMS
정규화 상관 비교 / 겹치는 후보에서 대표 선택. 합격 확률·실제 도형 포함 판정과 다름.
RMS / p95 / FPS
제곱 평균의 제곱근 / 약 95% 값이 이하인 지점 / 초당 프레임 수.
SOLID / GRASP
변경 영향과 객체 책임 배치를 검토하는 설계 원칙 묶음. 클래스 개수 점수표가 아님.
JIT / IL / GC
실행 시 기계어 컴파일 / .NET 중간 명령 / 관리 메모리 수집. 최초·반복 시간과 할당을 구별.

“식은 본 적 있는데 혼자 계산하려니 막힙니다.” 먼저 기호를 읽는 문제인지, 왜 그 연산을 쓰는지 모르는 문제인지, 좌표와 단위를 섞은 문제인지 나눠 보세요. 아래 색인은 답을 외우는 표가 아니라 해당 계산의 풀이로 돌아가는 길입니다.
