막힐 때 돌아오는 작은 사전

용어 사전

이름을 한꺼번에 외우는 곳이 아닙니다. 본문에서 막힌 단어 하나를 찾아 쉬운 뜻을 읽고, 원래 보던 예제로 돌아가세요. “버퍼는 픽셀을 잠시 담아 두는 메모리”처럼 먼저 내 말로 바꾸면 코드의 이름도 따라 읽기 쉬워집니다.

브라우저 찾기 Ctrl+F 또는 아래 필터로 찾으세요.

ROI
사진에서 관심 있는 부분입니다. 예를 들어 검사할 부품 하나를 둘러싼 영역입니다. 코드의 Roi는 모양뿐 아니라 번호(Id), 이름, 부모 연결도 보관합니다.
pixel / channel
pixel은 그림의 한 칸입니다. channel은 한 칸에 저장하는 값의 종류입니다. Gray는 밝기 하나, RGBA는 빨강·초록·파랑·투명도 네 값을 저장합니다.
stride / padding
stride는 메모리에서 한 행의 시작부터 다음 행의 시작까지 이동할 바이트 수입니다. 실제 픽셀 뒤에 붙은 여유 칸을 padding이라고 합니다. 가로 픽셀 수와 stride를 바로 같다고 생각하면 안 됩니다.
px / DIP / DPI
픽셀 / WPF 논리 단위 / 인치당 픽셀 수. 코드의 Dpi는 보통 96 기준 비율.
bit depth / dynamic range
저장 가능한 값의 비트 수 / 구분 가능한 밝기의 범위. 저장 공간과 실제 센서 품질을 동일시하지 않음.
crop / resize / resampling
일부 잘라 읽기 / 크기 변경 / 새로운 격자 위치의 값을 계산하기.
kernel / convolution
이웃 가중치 표 / 그 표를 뒤집어 입력의 이웃과 곱해 합하는 연산.
gradient / edge
밝기 변화의 크기·방향 / 밝기가 급하게 달라지는 경계.
mask
계산 대상 포함/제외 영역. 1이 포함인지 제외인지는 해당 계약에서 확인.
pose
검출/도형의 위치·각도·배율 등 배치 상태.
AABB / BVH
AABB는 도형을 감싸는, 가로·세로 축에 나란한 상자입니다. BVH는 이런 상자들을 큰 상자 아래에 묶어 찾는 범위를 줄이는 구조입니다. 상자가 겹쳐도 실제 도형은 안 겹칠 수 있습니다.
tile / pyramid / LOD
tile은 큰 사진을 나눈 조각입니다. pyramid는 같은 사진을 여러 크기로 줄여 둔 묶음입니다. LOD는 화면에서 얼마나 자세히 보여 줄지 고르는 단계입니다. 작은 표시 영상을 원본 검사 영상으로 바꿔 쓰는 뜻은 아닙니다.
immutable / snapshot
immutable은 이미 만든 값을 덮어쓰지 않는다는 뜻입니다. snapshot은 한 시점의 상태입니다. 옛 상태와 새 상태가 바뀌지 않은 자료를 공유할 수 있으므로 사진 전체를 복사한다는 말과는 다릅니다.
identity / equality
identity는 같은 대상을 가리키는지, equality는 값이 같은지를 묻습니다. C# 객체 참조가 같은지, record 값이 같은지, 문서의 ROI ID가 같은지는 각각 확인해야 합니다.
preview / commit
preview는 끌고 있는 동안 보여 주는 임시 결과입니다. commit은 규칙을 확인하고 편집 한 건으로 확정하는 일입니다. 손을 놓기 전에 취소한 미리보기와 Undo할 확정 편집을 구별합니다.
Undo / Redo / cursor
Undo는 확정한 편집을 되돌립니다. Redo는 되돌린 편집을 다시 적용합니다. cursor는 이력 목록에서 어디까지 적용했는지 가리키는 현재 위치입니다.
lease / retain / dispose
lease는 자료를 사용할 수 있는 권한입니다. retain은 사용 권한을 별도로 유지하는 일이고 dispose는 내 사용을 끝내는 일입니다. 권한을 유지하는 것과 픽셀을 복사하는 것은 다릅니다.
generation / epoch
작업이나 이미지의 버전을 구별하는 번호입니다. 사진 B를 열었는데 사진 A의 읽기 결과가 늦게 도착하면, 이 번호를 비교해 오래된 결과임을 알 수 있습니다.
cancellation
오래 걸리는 작업에 중단을 요청하는 것입니다. 요청과 동시에 반드시 멈추는 것은 아닙니다. 결과가 도착하면 지금 문서에 맞는 결과인지도 확인해야 합니다.
HWND / HwndHost
HWND는 Windows가 창을 구별하는 번호표입니다. HwndHost는 WPF 창 안에 별도의 Windows 자식 창을 넣는 연결 부품입니다.
swap chain / Present
화면 버퍼 전환 관리 / 그린 결과의 표시 제출. 물리 화면 시각과 다름.
fence / barrier
GPU 작업 완료 표식 / GPU 자원의 사용 상태·순서 전환.
WARP / CUDA
Windows의 CPU Direct3D 표시 / NVIDIA GPU 계산 플랫폼. 표시 장치 선택과 검사 계산 선택은 별도.
NCC / NMS
정규화 상관 비교 / 겹치는 후보에서 대표 선택. 합격 확률·실제 도형 포함 판정과 다름.
RMS / p95 / FPS
제곱 평균의 제곱근 / 약 95% 값이 이하인 지점 / 초당 프레임 수.
SOLID / GRASP
객체들의 일을 나누고 서로 연결하는 방법을 검토하는 원칙입니다. 예를 들어 위치 계산은 좌표를 아는 쪽에 맡깁니다. 이름을 외우거나 클래스를 많이 만든다고 자동으로 좋은 설계가 되지는 않습니다.
JIT / IL / GC
실행 시 기계어 컴파일 / .NET 중간 명령 / 관리 메모리 수집. 최초·반복 시간과 할당을 구별.

수식 색인

수식은 계산 순서를 짧게 적은 문장입니다. 기호부터 외우기 전에 “무엇을 구하려는가?”를 말해 보세요. 예를 들어 평균은 값을 모두 더한 뒤 개수로 나누는 계산입니다. 합을 나타내는 기호는 그 반복 덧셈을 줄여 적은 것입니다.

식에서 막히면 ① 기호의 뜻 ② 단위 ③ 연산 순서 중 무엇이 어려운지 고릅니다. 아래 링크에서 작은 숫자의 풀이로 돌아가세요. 같은 문자의 뜻도 식마다 다를 수 있으니 해당 절의 설명을 기준으로 읽습니다.

  2. 구현 계획보다 먼저 최신 상태의 후속 결정과 미달을 확인합니다.

  4. 기존 독립 샘플의 파일 교체·계층·레이어·smoke를 따라갑니다.
