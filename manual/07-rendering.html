WPF는 도구, DX12는 영상 뷰포트

WPF는 버튼·목록·속성·바인딩을 담당합니다. HwndHost는 WPF 레이아웃 안에 별도 Windows 자식 창(HWND)을 넣습니다. DX12는 그 창의 swap chain에 이미지·ROI·선택 핸들·이름표를 함께 그립니다. ROI마다 WPF Shape를 만들면 많은 객체·레이아웃 비용이 생깁니다.

이 구조의 자식 HWND에는 airspace 제약이 있습니다. WPF 반투명 Canvas나 Adorner를 위에 올려 같은 화면처럼 그릴 수 있다고 가정하지 않습니다. ROI overlay는 같은 GPU 경로에 둡니다. D3DImage를 DX12 texture에 바로 연결하는 설계도 사용하지 않습니다.

세 스레드의 일

“한 스레드에서 파일도 읽고 그리면 더 이해하기 쉽지 않나요?” 창의 입력을 받는 사람이 파일 읽기가 끝날 때까지 기다리면 마우스와 버튼도 기다리게 됩니다. 입력 접수, 오래 걸리는 준비, GPU 제출을 나누되 서로 주고받는 상태가 언제 완성되고 누가 소유하는지 명시해야 합니다.

소유자하는 일전달물
UI 스레드입력·문서 확정·WPF 바인딩불변 RenderScene
영상/편집 worker파일 읽기·타일 준비·대량 편집 준비소유권 있는 버퍼 또는 불변 준비 결과
렌더 스레드GPU 자원·명령 기록·Present·fence표시 상태·진단

렌더가 UI 컬렉션을 동시에 읽으면 사용자가 수정하는 순간 열거가 깨질 수 있습니다. 그래서 완성된 불변 장면을 게시합니다. RenderScene의 불변 껍데기만으로 내부 버퍼의 수명이 자동 해결되는 것은 아니므로 별도 소유권 계약도 필요합니다. 정지 화면은 계속 그리지 않고 요청을 합쳐 기다립니다.

동시 작업에서 ‘같은 장면’의 뜻

렌더러가 ROI 목록 절반을 읽은 순간 UI가 나머지를 바꾸면, 화면은 어느 시점에도 존재하지 않았던 조합이 될 수 있습니다. 그래서 UI가 완성한 장면을 불변 값으로 게시합니다. 작업자가 초안을 수정하는 동안 다른 사람이 그 초안을 인쇄하지 않고, 확정본을 건네는 것과 비슷합니다.

불변 장면을 보낸다고 CPU 픽셀·GPU 리소스의 수명이 자동으로 늘어나지는 않습니다. ‘내용이 바뀌지 않는가’와 ‘사용하는 동안 살아 있는가’를 별도로 확인하세요. 또한 worker가 여러 종류 있으므로 ‘세 스레드’는 세 책임 그룹을 설명하는 말이지 프로세스의 스레드 수가 정확히 세 개라는 보장은 아닙니다.

GPU 명령을 음식 주문서처럼 읽기

device
사용할 그래픽 장치. 자동 모드는 하드웨어를 우선하고 생성할 수 없으면 WARP CPU 표시를 사용합니다.
command list / queue
복사·그리기 명령을 적은 목록과 GPU에 제출하는 줄입니다. 제출은 완료가 아닙니다.
texture / buffer
영상처럼 2차원으로 읽는 저장소와 일반 데이터 저장소입니다.
descriptor
셰이더가 어떤 자원을 어떤 형태로 읽을지 알려 주는 설명입니다.
shader
GPU에서 정점·픽셀 등에 적용할 작은 프로그램입니다. HLSL로 작성합니다.
swap chain / back buffer
그릴 화면 버퍼와 표시 전환을 관리합니다. 현재 구현은 back buffer 두 개입니다.
fence
제출한 작업이 어느 번호까지 끝났는지 확인하는 완료 표식입니다.

한 프레임을 실제 순서로 읽기

  1. 새 장면·영상·타일 요청을 기다립니다. DXGI 표시 준비 신호를 기다립니다.
  2. 유효한 창 크기를 확인하고 필요하면 resize합니다.
  3. Dx12Surface.Begin에서 사용할 슬롯의 이전 GPU 작업 완료를 확인합니다. 그 뒤에만 명령 메모리와 upload 공간을 재사용합니다.
  4. 대기 중 도착한 최신 장면을 가져옵니다. 타일·필터·라벨을 준비합니다.
  5. ScenePainter가 표시 요소를 만들고 각 Pipeline이 그리기 명령을 기록합니다.
  6. 현재 버퍼를 Present 가능한 상태로 바꾸고 제출·Present합니다. 완료 fence를 슬롯과 지연 해제 목록에 연결합니다.

using System.Diagnostics;
using VisionCanvas.Diagnostics;
using VisionCanvas.Imaging;
using VisionImaging.Abstractions;

namespace VisionCanvas.Rendering;

/// <summary>GPU 자원의 단일 소유 스레드. UI 장면과 영상 요청은 최신 값 하나로 합친다.</summary>
public sealed class RenderWorker : IDisposable
{
    private const double BytesPerGibibyte = 1024d * 1024 * 1024;
    private const int MetricsNotificationFrameInterval = 30;
    private readonly AutoResetEvent _wake = new(false);
    private readonly ManualResetEvent _stop = new(false);
    private readonly Thread _thread;
    private readonly nint _hwnd;
    private readonly TileWorker _tiles;
    private readonly ITextRasterizer _textRasterizer;
    private readonly LatestFrameMailbox _frames;
    private readonly IFramePreparer _framePreparer;
    private readonly RenderDevicePreference _devicePreference;
    private sealed record Submission(long Version, RenderScene Scene, long Received);
    private sealed record CaptureRequest(long Version, string Path);
    private Submission? _latestSubmission;
    private CaptureRequest? _captureRequest;
    private long _sceneVersion;
    private volatile bool _stopping;
    private int _width = 1;
    private int _height = 1;
    public event Action<string>? StatusChanged;
    public event Action<RenderMetrics>? MetricsChanged;
    public event Action<OverlayPresentation>? OverlayPresented;

    public RenderWorker(nint hwnd, TileWorker tiles, ITextRasterizer textRasterizer, LatestFrameMailbox frames, IFramePreparer framePreparer)
        : this(hwnd, tiles, textRasterizer, frames, framePreparer, RenderDevicePreference.Automatic)
    {
    }

    public RenderWorker(nint hwnd, TileWorker tiles, ITextRasterizer textRasterizer, LatestFrameMailbox frames,
        IFramePreparer framePreparer, RenderDevicePreference devicePreference)
    {
        if (!Enum.IsDefined(devicePreference))
        {
            throw new ArgumentOutOfRangeException(nameof(devicePreference));
        }
        _hwnd = hwnd;
        _tiles = tiles;
        _textRasterizer = textRasterizer;
        _frames = frames;
        _framePreparer = framePreparer;
        _devicePreference = devicePreference;
        tiles.TileReady += Invalidate;
        frames.Available += Invalidate;
        _thread = new Thread(Run) { IsBackground = true, Name = "DX12 renderer" };
        _thread.SetApartmentState(ApartmentState.STA);
    }

    public void Start() => _thread.Start();

    public void Resize(int width, int height)
    {
        Volatile.Write(ref _width, width);
        Volatile.Write(ref _height, height);
        _wake.Set();
    }

    public void Invalidate()
    {
        if (_stopping)
        {
            return;
        }

        try
        {
            _wake.Set();
        }
        catch (ObjectDisposedException) when (_stopping)
        {
            // 구독 해제 직전에 생산자가 이미 가져간 콜백은 종료 이후 도착할 수 있다.
        }
    }

    public void Submit(RenderScene value)
    {
        var submission = new Submission(Interlocked.Increment(ref _sceneVersion), value, Stopwatch.GetTimestamp());
        Volatile.Write(ref _latestSubmission, submission);
        Invalidate();
    }

    public void Capture(string path)
    {
        var minimumSceneVersion = Volatile.Read(ref _latestSubmission)?.Version ?? 0;
        Interlocked.Exchange(ref _captureRequest, new(minimumSceneVersion, path));
        Invalidate();
    }

    private void Run()
    {
        try
        {
            using var gpu = new Dx12Device(Environment.GetCommandLineArgs().Contains("--gpu-debug"), _devicePreference);
            using var surface = new Dx12Surface(gpu, _hwnd, _width, _height);
            WaitHandle[] frameSignals = [surface.FrameReady, _stop];
            using var pipeline = new SpritePipeline(gpu);
            using var profile = new RenderProfile();
            using var roiPipeline = new RoiPipeline(gpu, profile.Enabled);
            using var maskPipeline = new MaskPipeline(gpu);
            using var repeatedPipeline = new RepeatedRoiPipeline(gpu);
            using var gpuTimer = gpu.IsSoftware ? null : new GpuTimer(gpu);
            using var metrics = new FrameMetrics();
            var painter = new ScenePainter();
            using var labels = new GpuLabelCache(_textRasterizer, gpu);
            using var resultLabels = new GpuResultLabels(_textRasterizer);
            using var images = new GpuImageResources(gpu, pipeline, _tiles, _framePreparer);
            using var filters = new GpuFilterPreview();
            GpuTexture? white = null;
            VideoFrame? retainedFrame = null;
            long frame = 0;
            var frameReady = false;
            RenderScene? presentedScene = null;
            var presentedOverlay = Guid.Empty;
            StatusChanged?.Invoke(gpu.IsSoftware
                ? $"DX12 · CPU (WARP) · {gpu.AdapterName} · Tile cache {gpu.TileBudgetBytes / (1024 * 1024)} MiB · Debug: {gpu.DebugEnabled}"
                : $"DX12 · GPU · {gpu.AdapterName} · VRAM {gpu.DedicatedMemoryBytes / BytesPerGibibyte:F1} GiB · Budget {gpu.LocalMemoryBudget / BytesPerGibibyte:F1} GiB · Debug: {gpu.DebugEnabled}");
            try
            {
                while (!_stopping)
                {
                    _wake.WaitOne();
                    if (_stopping)
                    {
                        break;
                    }

                    var targetWidth = Volatile.Read(ref _width);
                    var targetHeight = Volatile.Read(ref _height);
                    if (targetWidth <= 0 || targetHeight <= 0)
                    {
                        continue;
                    }

                    var submission = Volatile.Read(ref _latestSubmission);
                    var current = submission?.Scene;
                    var nothingChanged = ReferenceEquals(current, presentedScene)
                        && targetWidth == surface.Width && targetHeight == surface.Height
                        && !_frames.HasPending && !_tiles.HasReady && !labels.HasPending && !roiPipeline.HasPendingDetails
                        && Volatile.Read(ref _captureRequest) is null && white is not null;
                    if (nothingChanged)
                    {
                        continue;
                    }

                    // Begin은 프레임 슬롯의 GPU 완료를 기다린다. 이후에만 그 슬롯의 업로드 공간을 재사용한다.
                    var cpuStart = Stopwatch.GetTimestamp();
                    var allocationStart = profile.Enabled ? GC.GetAllocatedBytesForCurrentThread() : 0;
                    var gcPauseStart = profile.Enabled ? GC.GetTotalPauseDuration() : default;
                    var pacingStart = Stopwatch.GetTimestamp();
                    if (!frameReady && WaitHandle.WaitAny(frameSignals, 1000) != 0)
                    {
                        gpu.Device.DeviceRemovedReason.CheckError();
                        Invalidate();
                        continue;
                    }
                    var pacingElapsed = Stopwatch.GetElapsedTime(pacingStart).TotalMilliseconds;
                    if (_stopping)
                    {
                        break;
                    }
                    frameReady = true;
                    targetWidth = Volatile.Read(ref _width);
                    targetHeight = Volatile.Read(ref _height);
                    if (targetWidth <= 0 || targetHeight <= 0)
                    {
                        // 최소화 중에는 획득한 표시 허가를 다음 유효 프레임까지 보존한다.
                        continue;
                    }
                    surface.Resize(targetWidth, targetHeight);
                    surface.Begin();
                    // 표시 대기 중 도착한 최신 불변 스냅샷을 그린다.
                    submission = Volatile.Read(ref _latestSubmission);
                    current = submission?.Scene;
                    var sceneAge = submission is null ? 0 : Stopwatch.GetElapsedTime(submission.Received).TotalMilliseconds;
                    frame++;
                    var gpuElapsed = gpuTimer?.Begin(surface);
                    pipeline.BeginFrame(surface);
                    if (white is null)
                    {
                        using var pixel = new PixelBuffer(1, 1, PixelKind.Rgba32);
                        pixel.Span.Fill(255);
                        white = pipeline.Upload(pixel, surface);
                    }
                    var videoFrame = _frames.Take();
                    if (videoFrame is not null)
                    {
                        retainedFrame?.Dispose();
                        retainedFrame = videoFrame;
                    }
                    if (current?.IsLive == true && retainedFrame is null)
                    {
                        retainedFrame = _frames.RetainLatest();
                    }

                    if (current?.IsLive != true)
                    {
                        retainedFrame?.Dispose();
                        retainedFrame = null;
                    }
                    if (current is not null && current.Width > 0 && current.Height > 0)
                    {
                        if (images.Update(current, retainedFrame, surface, frame))
                        {
                            Invalidate();
                        }

                        filters.Update(current.FilterPreview, pipeline, surface);
                        labels.Begin();
                        resultLabels.Update(current, pipeline, surface);
                        var paintStart = Stopwatch.GetTimestamp();
                        var mesh = painter.Build(current, white, images.Tiles, text => labels.Get(text, current.Dpi, pipeline, surface),
                            text => labels.TryGet(text, current.Dpi, pipeline, surface), images.Live, images.LiveBounds, filters, images.LiveOverview,
                            resultLabels.Get);
                        var submitStart = Stopwatch.GetTimestamp();
                        pipeline.Draw(mesh, surface, painter.RoiBatchBoundary, () =>
                        {
                            maskPipeline.Draw(current, surface);
                            repeatedPipeline.Draw(current, surface);
                            roiPipeline.Draw(current, surface);
                        });
                        var submitEnd = Stopwatch.GetTimestamp();
                        var gcPauseDelta = profile.Enabled ? GC.GetTotalPauseDuration() - gcPauseStart : default;
                        profile.Record(current, cpuStart, paintStart, submitStart, submitEnd, allocationStart, mesh, roiPipeline, labels, gcPauseDelta);
                        labels.End(surface);
                        if (labels.HasPending || roiPipeline.HasPendingDetails)
                        {
                            Invalidate();
                        }
                    }
                    var capture = roiPipeline.HasPendingDetails ? null : TryTakeReadyCapture(submission, images, labels);
                    using var readback = capture is null ? null : new FrameReadback(gpu, surface);
                    gpuTimer?.End(surface);

                        gpu.Wait(completionFence);

                        metrics.Enabled ? surface.ReadPresentationStatistics() : null, pacingElapsed);

                    }

                        gpu.Flush();
                        readback.Save(capture!);
                    }

                }

using Vortice.Direct3D12;
using Vortice.DXGI;

namespace VisionCanvas.Rendering;

/// <summary>렌더 스레드에서만 사용하는 화면 버퍼와 프레임별 GPU 작업의 소유자.</summary>
internal sealed class Dx12Surface : IDisposable
{
    private const int BackBufferCount = 2;
    private const SwapChainFlags Flags = SwapChainFlags.FrameLatencyWaitableObject;
    private readonly Dx12Device _gpu;
    private readonly IDXGISwapChain3 _swapChain;
    private readonly ID3D12DescriptorHeap _renderTargets;
    private readonly ID3D12Resource?[] _buffers = new ID3D12Resource[BackBufferCount];
    private readonly ID3D12CommandAllocator[] _allocators = new ID3D12CommandAllocator[BackBufferCount];
    private readonly ulong[] _frameCompletionFences = new ulong[BackBufferCount];
    private readonly List<IDisposable>[] _resourcesAwaitingGpu = [[], []];
    private readonly uint _descriptorSize;
    private readonly AutoResetEvent _frameReady = new(false);

    public ID3D12GraphicsCommandList Commands
    {
        get;
    }

    public int FrameIndex
    {
        get;
        private set;
    }

    public int Width
    {
        get;
        private set;
    }

    public int Height
    {
        get;
        private set;
    }

    public ID3D12Resource CurrentBuffer => _buffers[FrameIndex]!;

    public double FenceWaitMilliseconds
    {
        get; private set;
    }

    public WaitHandle FrameReady => _frameReady;

    public FrameStatistics? ReadPresentationStatistics()
        => _swapChain.GetFrameStatistics(out var statistics).Success ? statistics : null;

    public Dx12Surface(Dx12Device gpu, nint hwnd, int width, int height)
    {
        _gpu = gpu;
        Width = Math.Max(1, width);
        Height = Math.Max(1, height);
        try
        {
            using var chain = gpu.Factory.CreateSwapChainForHwnd(gpu.Queue, hwnd, new SwapChainDescription1
            {
                Width = (uint)Width,
                Height = (uint)Height,
                Format = Format.B8G8R8A8_UNorm,
                BufferCount = BackBufferCount,
                BufferUsage = Usage.RenderTargetOutput,
                SampleDescription = new SampleDescription(1, 0),
                SwapEffect = SwapEffect.FlipDiscard,
                Scaling = Scaling.Stretch,
                AlphaMode = AlphaMode.Ignore,
                Flags = Flags
            });
            _swapChain = chain.QueryInterface<IDXGISwapChain3>();
            _swapChain.MaximumFrameLatency = 1;
            var frameReady = _swapChain.FrameLatencyWaitableObject;
            if (frameReady == 0)
            {
                throw new InvalidOperationException("DXGI frame latency wait handle is unavailable.");
            }
            _frameReady.SafeWaitHandle.Dispose();
            _frameReady.SafeWaitHandle = new SafeWaitHandle(frameReady, true);
            _renderTargets = gpu.Device.CreateDescriptorHeap(new DescriptorHeapDescription(DescriptorHeapType.RenderTargetView, BackBufferCount));
            _descriptorSize = gpu.Device.GetDescriptorHandleIncrementSize(DescriptorHeapType.RenderTargetView);
            for (var i = 0; i < BackBufferCount; i++)
            {
                _allocators[i] = gpu.Device.CreateCommandAllocator(CommandListType.Direct);
            }
            Commands = gpu.Device.CreateCommandList<ID3D12GraphicsCommandList>(CommandListType.Direct, _allocators[0]);
            Commands.Close();
            CreateBuffers();
        }
        catch
        {
            ReleaseResources();
            throw;
        }
    }

    private CpuDescriptorHandle RenderTargetView(int index) =>
        _renderTargets.GetCPUDescriptorHandleForHeapStart() + (index * (int)_descriptorSize);

    private void CreateBuffers()
    {
        for (var i = 0; i < BackBufferCount; i++)
        {
            _buffers[i] = _swapChain.GetBuffer<ID3D12Resource>((uint)i);
            _gpu.Device.CreateRenderTargetView(_buffers[i]!, null, RenderTargetView(i));
        }
    }

    public void Resize(int width, int height)
    {
        if (width <= 0 || height <= 0 || (Width == width && Height == height))
        {
            return;
        }
        // 화면 크기를 바꿀 때는 이전 크기의 버퍼를 사용하는 모든 GPU 작업이 끝나야 한다.
        _gpu.Flush();
        foreach (var buffer in _buffers)
        {
            buffer?.Dispose();
        }

        _swapChain.ResizeBuffers(BackBufferCount, (uint)width, (uint)height, Format.B8G8R8A8_UNorm, Flags).CheckError();
        Width = width;
        Height = height;
        CreateBuffers();
    }

    public void Begin()
    {
        FrameIndex = (int)_swapChain.CurrentBackBufferIndex;
        // 같은 프레임 슬롯의 명령 메모리와 업로드 버퍼는 fence 완료 후에만 재사용한다.
        var waitStart = Stopwatch.GetTimestamp();
        _gpu.Wait(_frameCompletionFences[FrameIndex]);
        FenceWaitMilliseconds = Stopwatch.GetElapsedTime(waitStart).TotalMilliseconds;
        DisposeRetiredResources(FrameIndex);
        _allocators[FrameIndex].Reset();
        Commands.Reset(_allocators[FrameIndex]);
        Commands.ResourceBarrierTransition(CurrentBuffer, ResourceStates.Present, ResourceStates.RenderTarget);
        Commands.OMSetRenderTargets(RenderTargetView(FrameIndex));
        Commands.ClearRenderTargetView(RenderTargetView(FrameIndex), new Color4(0.045f, 0.06f, 0.085f, 1));
        Commands.RSSetViewport(new Viewport(Width, Height));
        Commands.RSSetScissorRect(new RectI(0, 0, Width, Height));
    }

    /// <summary>이번 프레임까지 제출된 GPU 참조가 끝난 뒤 해제하도록 예약한다.</summary>
    public void Retire(IDisposable resource) => _resourcesAwaitingGpu[FrameIndex].Add(resource);

    private void DisposeRetiredResources(int frameIndex)
    {
        foreach (var resource in _resourcesAwaitingGpu[frameIndex])
        {
            resource.Dispose();
        }

        _resourcesAwaitingGpu[frameIndex].Clear();
    }

    public ulong Present()
    {
        Commands.ResourceBarrierTransition(CurrentBuffer, ResourceStates.RenderTarget, ResourceStates.Present);
        Commands.Close();
        _gpu.Queue.ExecuteCommandList(Commands);
        _swapChain.Present(1, PresentFlags.None).CheckError();
        _frameCompletionFences[FrameIndex] = _gpu.Signal();
        return _frameCompletionFences[FrameIndex];
    }

    public void Dispose()
    {
        try
        {
            _gpu.Flush();
        }
        finally
        {
            ReleaseResources();
        }
    }

    private void ReleaseResources()
    {
        foreach (var frame in _resourcesAwaitingGpu)
        {
            foreach (var resource in frame)
            {
                resource.Dispose();
            }
        }
        foreach (var buffer in _buffers)
        {
            buffer?.Dispose();
        }

        foreach (var allocator in _allocators)
        {
            allocator?.Dispose();
        }

        Commands?.Dispose();
        _renderTargets?.Dispose();
        _swapChain?.Dispose();
        _frameReady.Dispose();
    }
}

static const uint RectangleEdgeCount = 4;
static const uint VerticesPerEdge = 6;
static const uint RootRole = 4;
static const float2 corners[RectangleEdgeCount] = { float2(-1,-1), float2(1,-1), float2(1,1), float2(-1,1) };

float2 ToScreen(float2 localPosition) {
    float2 rotatedPosition = float2(
        localPosition.x*rotation.x-localPosition.y*rotation.y,
        localPosition.x*rotation.y+localPosition.y*rotation.x);
    return rotatedPosition*imageScale + screenOrigin;
}

float2 StrokeCorner(uint corner, float2 edgeStart, float2 edgeEnd, float2 halfWidthNormal) {
    if (corner == 0) return edgeStart + halfWidthNormal;
    if (corner == 1) return edgeEnd + halfWidthNormal;
    if (corner == 2) return edgeEnd - halfWidthNormal;
    return edgeStart - halfWidthNormal;
}

Pixel VSMain(uint vertexIndex : SV_VertexID, uint instanceIndex : SV_InstanceID) {
    Instance roi = instances[instanceIndex];
    uint role = min(roles[instanceIndex], RootRole);
    float strokeWidth = role < 4 ? roleWidths[role] : extraRoleWidths.x;
    Pixel pixel;
    pixel.circleOffset = 0;
    pixel.circleStroke = 0;
    pixel.strokeDistance = 0;
    pixel.color = shadowPass != 0 ? shadowColor : roleColors[role];
    float2 screenPosition;
    if (roi.summary == 3) {
        if (vertexIndex >= VerticesPerEdge) {
            pixel.position = float4(2,2,0,1);
            return pixel;
        }
        float radius = length(roi.axisX)*imageScale;
        float halfWidth = strokeWidth*.5;
        pixel.circleOffset = corners[cornerIndex[vertexIndex]]*(radius+halfWidth+1);
        pixel.circleStroke = float2(radius, halfWidth);
        screenPosition = ToScreen(roi.center) + pixel.circleOffset;
    } else if (roi.summary == 1) {
        if (vertexIndex >= VerticesPerEdge || shadowPass != 0) {
            pixel.position = float4(2,2,0,1);
            return pixel;
        }
        float2 summaryCorner = corners[cornerIndex[vertexIndex]];
        screenPosition = ToScreen(roi.center + roi.axisX*summaryCorner.x + roi.axisY*summaryCorner.y);
        pixel.color.a *= summaryOpacity;
    } else {
        if (roi.summary == 2 && vertexIndex >= VerticesPerEdge) {
            pixel.position = float4(2,2,0,1);
            return pixel;
        }
        uint edgeIndex = vertexIndex / VerticesPerEdge;
        uint strokeCorner = cornerIndex[vertexIndex % VerticesPerEdge];
        float2 localEdgeStart = corners[edgeIndex];
        float2 localEdgeEnd = corners[(edgeIndex+1)%RectangleEdgeCount];
        float2 edgeStart = ToScreen(roi.center + roi.axisX*localEdgeStart.x + roi.axisY*localEdgeStart.y);
        float2 edgeEnd = ToScreen(roi.center + roi.axisX*localEdgeEnd.x + roi.axisY*localEdgeEnd.y);
        if (roi.summary == 2) {
            edgeStart = ToScreen(roi.center);
            edgeEnd = ToScreen(roi.center + roi.axisX);
        }
        float2 edgeDirection = edgeEnd-edgeStart;
        pixel.strokeDistance = (strokeCorner == 1 || strokeCorner == 2) ? length(edgeDirection) : 0;
        float2 halfWidthNormal = float2(-edgeDirection.y,edgeDirection.x)
            * (strokeWidth*.5/max(length(edgeDirection),.00001));
        screenPosition = StrokeCorner(strokeCorner, edgeStart, edgeEnd, halfWidthNormal);
    }
    pixel.position = float4(screenPosition*clipScale + float2(-1,1),0,1);
    return pixel;
}

CPU가 제출을 끝내도 GPU는 아직 그 texture를 읽을 수 있습니다. 마지막 사용의 fence가 완료된 뒤 소유자가 해제해야 합니다. UI 스레드에서 기다리는 방식으로 해결하면 입력이 멈출 수 있어 렌더 소유 경계에서 처리합니다.

NDC 식을 세 단계로 만들기

  1. x를 물리 너비 W로 나누면 왼쪽 0, 오른쪽 1인 비율이 됩니다. 분자와 분모의 단위가 약분됩니다.
  2. 그 비율에 2를 곱하면 0~2가 되고, 1을 빼면 −1~+1이 됩니다.
  3. y는 화면에서 아래로 증가하지만 이 NDC 눈금은 위가 +1입니다. 그래서 1에서 2y/H를 뺍니다.

protected override nint WndProc(nint hwnd, int message, nint wParam, nint lParam, ref bool handled)
{
    var windowMessage = (NativeWindowMessage)message;
    var input = PointerInput ?? Input;
    if (windowMessage == NativeWindowMessage.GetDialogCode)
    {
        handled = true;
        return NativeMethods.WantAllDialogKeys;
    }
    if (windowMessage == NativeWindowMessage.SetCursor && NativeMethods.IsClientCursorMessage(lParam))
    {
        ViewportWindow.UseCursor(input?.Tool switch
        {
            EditorTool.Draw or EditorTool.Mask => NativeCursor.Cross,
            EditorTool.Pan => NativeCursor.Hand,
            _ => NativeCursor.Arrow
        });
        handled = true;
        return 1;
    }
    if (input is null)
    {
        return base.WndProc(hwnd, message, wParam, lParam, ref handled);
    }

    try
    {
        var point = ClientPixelsToDips(NativeMethods.DecodePoint(lParam));
        if ((windowMessage is NativeWindowMessage.LeftButtonDown or NativeWindowMessage.LeftButtonDoubleClick or
            NativeWindowMessage.MiddleButtonDown or NativeWindowMessage.MiddleButtonDoubleClick) &&
            IsInputEnabled && (InputEnabled?.Invoke() ?? true))
        {
            NativeMethods.SetFocus(hwnd);
            NativeMethods.SetCapture(hwnd);
            var pan = windowMessage is NativeWindowMessage.MiddleButtonDown or NativeWindowMessage.MiddleButtonDoubleClick ||
                NativeMethods.IsKeyPressed(NativeVirtualKey.Space);
            if (windowMessage == NativeWindowMessage.LeftButtonDoubleClick && !pan)
            {
                input.DoubleClick(point, Modifiers);
            }
            else
            {
                input.Down(point, Modifiers, pan);
            }
            handled = true;
        }
        else if (windowMessage is NativeWindowMessage.LeftButtonUp or NativeWindowMessage.MiddleButtonUp)
        {
            // ReleaseCapture가 CaptureChanged를 재진입시킬 수 있으므로 먼저 편집을 끝낸다.
            if (input.IsDragging)
            {
                input.Up(point, Modifiers);
            }

            NativeMethods.ReleaseCapture();
            handled = true;
        }
        else if (windowMessage == NativeWindowMessage.MouseMove && IsInputEnabled && (InputEnabled?.Invoke() ?? true))
        {
            input.Move(point, Modifiers);
            handled = true;
        }
        else if (windowMessage == NativeWindowMessage.MouseWheel)
        {
            var wheelPoint = WheelPositionInDips(hwnd, lParam);
            input.Wheel(wheelPoint, NativeMethods.DecodeWheelNotches(wParam));
            handled = true;
        }
        else if (windowMessage == NativeWindowMessage.KeyDown)
        {
            var virtualKey = (int)wParam;
            handled = DispatchKeyAction(virtualKey);
            if (virtualKey == (int)NativeVirtualKey.Escape)
            {
                NativeMethods.ReleaseCapture();
            }
        }
        else if ((windowMessage is NativeWindowMessage.CaptureChanged or NativeWindowMessage.KillFocus) && input.IsDragging)
        {
            input.Cancel();
        }
    }
    catch (Exception ex)
    {
        input.Cancel();
        NativeMethods.ReleaseCapture();
        InputFailed?.Invoke(ex);
    }
    return handled ? 0 : base.WndProc(hwnd, message, wParam, lParam, ref handled);
}
