이 책의 출발점과 도착점

변수, 조건문, 반복문, 메서드, 클래스, 배열을 배운 독자를 가정합니다. 삼각함수·행렬·GPU·WPF·불변 자료구조는 처음이어도 됩니다. 목표는 모든 GPU 코드를 외우는 것이 아니라, 입력과 결과를 설명하고, 올바른 책임에 코드를 놓고, 테스트로 안전을 확인하며 작은 VisionCanvas 호스트를 만드는 것입니다.

예제는 이 저장소의 실제 C# API를 사용합니다. 코드는 본문에서 바로 읽거나 제목을 눌러 펼칠 수 있습니다. 9장에는 실습 두 프로젝트의 전체 파일을 넣었습니다. 수식 옆의 숫자는 교육용 예제이며 벤치마크가 아닙니다. 각 장의 ‘직접 확인’에는 예상 결과와 풀이가 있습니다. 모르는 단어는 용어 사전에서 찾으세요.

차례와 학습 경로

읽는 방법

  1. 1~3장: 계산기를 움직이고 종이에 같은 값을 계산합니다. 픽셀과 화면 좌표를 구분할 수 있으면 다음으로 갑니다.
  2. 4~6장: 본문의 실제 코드에서 누가 데이터를 소유하는지 따라갑니다. 생성한 객체의 마지막 사용과 해제까지 설명해 봅니다. 6장의 창 이동 실험으로 필요한 타일 주소를 직접 계산합니다.
  3. 7~9장: 준비된 작은 호스트를 실행한 뒤 새 프로젝트에 필요한 연결을 순서대로 옮겨 봅니다.
  4. 10~12장: 리뷰 체크리스트로 자신의 변경을 검토하고 실패도 기록합니다.

장마다 권장 시간은 정하지 않았습니다. ‘직접 확인’을 스스로 설명할 수 있을 때 넘어가세요. 한 번에 전체 렌더러를 바꾸는 연습은 하지 않습니다.

현재 구현을 읽을 때의 약속

기준일은 2026-10-13입니다. 실시간 입력 요구는 최소 8K, 파일 입력은 별도의 24K급 완성 이미지입니다. 라인 스캔 수집·조립, 딥러닝은 현재 범위가 아닙니다. 반복 격자 100,020,001개와 일반 ROI 문서는 표현 방법이 다릅니다. 엄격한 60FPS 및 논문 형상 검사 CPU 125ms/CUDA 80ms 목표는 기존 검증에서 미달입니다. 매뉴얼 작성이 그 목표를 통과시킨 것은 아닙니다.

준비물과 첫 실행

Windows x64, .NET 10 SDK와 이 저장소가 필요합니다. 관리자 권한은 일반적인 빌드에 필요하지 않습니다. 명령은 저장소 최상위 폴더의 PowerShell에서 실행합니다.

dotnet restore TeachingToolWpf.slnx
dotnet build TeachingToolWpf.slnx -c Release --no-restore -m:1
dotnet run --project samples/VisionCanvas.Sample -c Release

처음 복원은 패키지 다운로드가 필요합니다. 매뉴얼 자체는 manual/index.html을 브라우저로 열면 됩니다. 서버·CDN·인터넷 없이 본문·수식·실험이 작동합니다. 외부 참고 문서만 인터넷이 필요합니다. .cs 링크는 브라우저에 따라 다운로드될 수 있으므로 같은 경로를 IDE에서 열어도 됩니다.
