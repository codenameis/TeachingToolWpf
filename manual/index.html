  1. 1~3장: 픽셀을 읽고, 좌표를 바꾸고, 밝기를 비교합니다.
  2. 4~7장: 일을 맡길 객체를 정하고, 드래그를 처리하고, 필요한 영상을 화면에 표시합니다.
  3. 8~9장: 검사 결과를 해석한 뒤, 계산·입력·화면 실습을 순서대로 연결합니다.

이 책의 출발점과 도착점

변수, 조건문, 반복문, 메서드, 클래스, 배열을 배운 독자를 가정합니다. 삼각함수·행렬·GPU·WPF·불변 자료구조는 처음이어도 됩니다. 목표는 모든 GPU 코드를 외우는 것이 아니라, 입력과 결과를 설명하고, 올바른 책임에 코드를 놓고, 테스트로 안전을 확인하며 작은 VisionCanvas 호스트를 만드는 것입니다.

예제는 이 저장소의 실제 C# API를 사용합니다. 코드는 본문에서 바로 읽거나 제목을 눌러 펼칠 수 있습니다. 9장에는 실습 세 프로젝트의 전체 파일을 넣었습니다. 수식 옆의 숫자는 교육용 예제이며 벤치마크가 아닙니다. 각 장의 ‘직접 확인’에는 예상 결과와 풀이가 있습니다. 모르는 단어는 용어 사전에서 찾으세요.

차례와 학습 경로

파인만 방식으로 읽기: 설명하다 막힌 곳이 다음 공부할 곳입니다

여기서는 파인만 기법을 쉽게 설명하기 → 빈틈 찾기 → 작은 예로 다시 확인하기 → 더 명료하게 다시 설명하기라는 학습 순환으로 적용합니다. 비유를 읽고 ‘이해한 것 같다’에서 멈추지 않고, 숫자를 바꿔 직접 설명하는 데 초점을 둡니다.

  1. 먼저 질문을 읽습니다. 예를 들어 “화면을 확대했는데 ROI 원본 좌표도 바꿔야 할까?”를 먼저 생각합니다. 수식은 이 질문의 답을 계산하는 도구입니다.
  2. 작은 예를 손으로 계산합니다. 각 기호 옆에 뜻과 단위를 적습니다. 곱셈·덧셈 하나씩 중간 값을 씁니다. 답만 맞히지 말고 왜 그 순서인지 말합니다.
  3. 본문을 가리고 동료에게 설명합니다. 장 끝의 상황에 대해 전문 용어 없이 먼저 설명하고, 그다음 코드의 변수·메서드와 연결합니다. 정답은 펼치기 전까지 숨겨져 있습니다.
  4. 막힌 단계를 찾습니다. ‘정규화니까’, ‘GPU가 알아서’ 같은 말로 건너뛴 부분이 없는지 봅니다. 기호를 몰랐는지, 단위를 섞었는지, 소유자를 몰랐는지 구체적으로 적습니다.
  5. 돌아가서 다시 설명합니다. 장 끝의 ‘막혔다면’ 안내로 돌아가 숫자 하나를 바꿔 재계산합니다. 예시를 닫고 다시 설명할 수 있으면 다음 장으로 갑니다.

설명의 전과 후

아직 부족한 설명: “타일 개수는 ceil을 쓰면 됩니다.” 이 문장은 API 이름만 알고 있어도 말할 수 있습니다.

이유가 있는 설명: “1300픽셀을 512씩 나누면 두 조각 뒤에 276픽셀이 남아요. 남은 것도 보여 줘야 하니 작은 조각 하나를 더 셉니다. 그래서 나눗셈의 몫을 올림해 세 조각으로 잡아요.” 이 설명은 ceil을 쓰는 이유와 경계 타일을 함께 알려 줍니다.

1~3장은 숫자·좌표·필터, 4~6장은 책임·편집·타일과 수명, 7~9장은 렌더링·검사·실제 구축, 부록은 용어와 수식을 다시 찾는 데 씁니다. 모르는 부분을 찾았다고 처음부터 모두 다시 읽을 필요는 없습니다. 막힌 단계만 작게 돌아가 확인하세요.

현재 구현을 읽을 때의 약속

기준일은 2026-10-14입니다. 실시간 입력 요구는 최소 8K, 파일 입력은 별도의 24K급 완성 이미지입니다. 라인 스캔 수집·조립, 딥러닝은 현재 범위가 아닙니다. 반복 격자 100,020,001개와 일반 ROI 문서는 표현 방법이 다릅니다. 엄격한 60FPS 및 논문 형상 검사 CPU 125ms/CUDA 80ms 목표는 기존 검증에서 미달입니다. 매뉴얼 작성이 그 목표를 통과시킨 것은 아닙니다.

준비물과 첫 실행

Windows x64, .NET 10 SDK와 이 저장소가 필요합니다. 관리자 권한은 일반적인 빌드에 필요하지 않습니다. 명령은 저장소 최상위 폴더의 PowerShell에서 실행합니다.

PowerShell준비물과 첫 실행펼치기접기
본문 예제 · 3줄
dotnet restore manual/labs/CanvasHost/CanvasHost.csproj -m:1
dotnet build manual/labs/CanvasHost/CanvasHost.csproj -c Release --no-restore -m:1
dotnet run --project manual/labs/CanvasHost -c Release --no-build

처음 복원은 패키지 다운로드가 필요합니다. 매뉴얼 자체는 manual/index.html을 브라우저로 열면 됩니다. 서버·CDN·인터넷 없이 본문·수식·실험이 작동합니다. 외부 참고 문서만 인터넷이 필요합니다. 소스는 제목을 눌러 본문 안에서 읽습니다. 실제 실행은 9장의 실습 순서를 따르세요.
