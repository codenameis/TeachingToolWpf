# 8K 전체 검색 검증 데이터

`8k-full-eight.png`는8192×8192 원본이다. `template.png`는Kensa의89×52 패키지이며 네 모서리·중앙·4096좌표 양쪽에8개를 알려진 각도로 배치했다. 생성기는 `tools/CpuMatching.Evaluation/FullImageDataset.cs`다. 균일 배경의 합성 데이터이므로 생산 이미지의 밀집 반복 부품/배경 잡음에 대한 합격을 뜻하지 않는다.

1. WPF에서 `template.png`를 열고 중심X44.5/Y26, 가로89/세로52, 각도0의 사각형을 학습한다.
2. `8k-full-eight.png`를 열고 **선택 ROI 범위에서 찾기**를 끈다.
3. 검색각−30~30°, 간격10°, 배율1, 피라미드3, 최소 점수0.75, 후보2048, 결과256, 중복 반경31.2로 검사한다. 알고리즘별 옵션은 기본값이다.

`cases.json`의 X/Y는0부터 시작하는 픽셀 인덱스 중심이다. 앱의 원본 기하 좌표에는 각각0.5를 더한다. 수용 기준은8개 전수, 오검출0, 위치≤1px, 각도≤1°, 배율 오차≤0.03, 후보/출력 잘림 없음이다. CPU/CUDA 두 경로와 실제 버튼→표시 측정은 `--cpu-full8k-comparison`으로 재현한다. [시간·메모리·미달 범위](../../docs/cpu-matching-performance.md).
